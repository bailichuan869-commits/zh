# 中国注册会计师职业道德守则

《中国注册会计师职业道德守则（2020）》是规范注册会计师职业行为的基础规则体系。它解决“注册会计师应当如何保持诚信、客观公正、专业胜任能力、保密、良好职业行为，以及如何识别和应对职业道德威胁”的问题。

## 官方来源

## 体系结构

| 模块 | 解决的问题 | 实务落点 |
|---|---|---|
| 第1号 | 基本原则 | 诚信、客观公正、专业胜任能力、保密、良好职业行为 |
| 第2号 | 概念框架 | 识别、评价和应对职业道德威胁 |
| 第3号 | 提供专业服务 | 客户承接、利益冲突、第二意见、收费、礼品款待等 |
| 第4号 | 审计和审阅独立性 | 已由财会〔2024〕29号独立性准则及 2026 应用指南承接 |
| 第5号 | 其他鉴证业务独立性 | 非审计审阅鉴证业务的独立性判断 |

## 判断框架

| 步骤 | 问题 | 底稿或留痕 |
|---|---|---|
| 识别基本原则 | 是否涉及诚信、客观、胜任、保密或职业行为风险 | 职业道德事项识别表 |
| 识别威胁 | 是否存在自身利益、自我评价、倡导、密切关系、外在压力等威胁 | 威胁清单和事实说明 |
| 评价严重程度 | 理性第三方是否会认为职业判断受损 | 合伙人评价、独立性或职业道德复核 |
| 采取防范措施 | 能否消除威胁或降至可接受水平 | 回避、轮换、复核、退出服务等记录 |
| 得出结论 | 是否承接、保持、调整团队或终止业务 | 承接保持审批、项目复核结论 |

## 高频风险

- 低价承接导致项目资源不足。
- 客户关系过密导致职业怀疑弱化。
- 非鉴证服务形成自我评价威胁。
- 经济利益、礼品款待、收费依赖影响客观公正。
- 保密义务与监管检查、司法程序、法律披露义务发生冲突时未作区分。
