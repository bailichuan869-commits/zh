# 审计典型案例库

## 定义

审计典型案例库用于把法规、准则、职业道德和监管政策放入具体情境，训练“看事实、找风险、定规则、给结论”的综合答题能力。

## 案例分析框架

| 步骤 | 问题 | 输出 |
|------|------|------|
| 事实识别 | 题目中发生了什么，谁参与，涉及哪些交易或报告 | 事实清单 |
| 风险判断 | 哪些事项可能导致重大错报、独立性受损或违法违规 | 风险点 |
| 规则定位 | 对应哪部法律、哪项准则、哪类政策要求 | 规则依据 |
| 程序应对 | 注册会计师应执行哪些程序，获取什么证据 | 审计动作 |
| 结论表达 | 对报告、责任、整改或处罚作出判断 | 答题结论 |

## 案例答题模板

```text
结论：该事项可能构成/不构成……风险。
事实：题目中出现……，说明……。
依据：可联系……法律/准则/政策要求。
程序：注册会计师应当……，获取……证据。
影响：如无法消除影响，可能导致……报告或责任后果。
```

## 常见考点

- 案例题不是单纯背法条，要把事实和规则连接起来。
- 看到“管理层不配合、关键资料缺失”，优先想到审计范围受限和证据充分适当性。
- 看到“上市公司、发行文件、公告、投资者损失”，优先联想到证券法信息披露责任。
- 看到“亲属关系、经济利益、长期合作、收费依赖”，优先联想到独立性威胁。
- 看到“低价竞争、挂名执业、质量控制失效”，优先联想到政策性监管文件。

## 复盘方法

| 方法 | 作用 |
|------|------|
| 一案多链 | 一个案例至少链接法律、准则、职业道德三个页面 |
| 一题多问 | 同一案例分别从注册会计师、事务所、被审计单位、监管机构角度作答 |
| 一错多改 | 错题改答案时，同时补充“缺了哪个事实、错用哪个规则” |
