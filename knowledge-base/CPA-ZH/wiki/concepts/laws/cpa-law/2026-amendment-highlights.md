# 注册会计师法2026年修订要点对照

> 依据：主席令第七十八号《关于修改〈中华人民共和国注册会计师法〉的决定》，2026-06-26 通过，2027-01-01 施行。
> 完整条文见 `raw/laws/注册会计师法-修改决定-2026.md`。本页为要点对照，便于备考速记与实务检索。

## 一、修订主线（五条）

| 主线 | 对应修改决定 |
|---|---|
| 加强党的领导 | 一（新增第二条） |
| 诚信建设与行业健康发展 | 二（新增第七条）、十四（注协职责） |
| 规范执业行为 / 禁止性规定 | 三、六、七、八、九、十一、二十七(二) |
| 完善监管措施（新增“监督管理”章） | 十二（先证后照）、十五（新增第六章 42–46） |
| 加大责任追究力度 | 十六、十七、十八、十九、二十、二十一、二十二、二十三、二十四、二十五 |

## 二、逐条对照（考试 / 实务重点）

| 修改决定 | 变动类型 | 新条文要点 | 关注点 |
|---|---|---|---|
| 一 | 新增第二条 | 注册会计师行业坚持中国共产党的领导 | 政治方向，新增总则条款 |
| 二 | 新增第七条 | 国家支持诚信建设、提高审计质量、拓展服务网络 | 行业发展总要求 |
| 三 | 原六→新八 | 执业须遵循执业准则、恪守职业道德，坚持诚信、客观、独立、公正 | 执业原则法定化 |
| 四 | 原十+十一(二)→新十二 | 不予注册情形增“终身禁止从业”；不予注册须 15 日内书面通知，可复议/诉讼 | 注册负面清单 |
| 五 | 原十三→新十五 | 注销/撤销注册情形；可复议/诉讼、可重新申请 | 注册退出机制 |
| 六 | 原十七→新十九 | 可查阅被审计单位及相关单位资料；被审计单位对资料真实性、完整性负责，不得提供虚假资料 | 资料真实责任前移 |
| 七 | 原二十→新二十二 | 遇示意不实证明、故意不提供资料、不合理要求时，应拒绝出具有关报告或出具非无保留意见 | 拒绝/非无保留意见法定情形 |
| 八 | 原二十一→新二十三 | 不得出具虚假报告；五项禁止行为，**新增“未保持职业怀疑且未履行必要程序/未获取充分适当证据而发表不当意见”为禁止行为** | 职业怀疑写入法条 |
| 九 | 原二十二→新二十四 | “股票、债券”改为“证券”；禁止冒用名义、禁止强迫/欺诈/贿赂招揽 | 禁止行为扩围 |
| 十 | 原二十三→新二十五 | 合伙所须普通合伙或特殊普通合伙 | 组织形式 |
| 十一 | 原二十四→新二十六 | 有限责任所条件；**有限责任所不得从事证券服务业务等特定业务** | 限责所业务禁区 |
| 十二 | 原二十六→新二十八 | **“先照后证”改为“先证后照”**；批准之日起 60 日内办理登记；名称须标明“会计师事务所” | 准入前置 |
| 十三 | 新增第三十二条 | 财政部会同有关部门对上市公司审计等金融活动审计服务实施准入管理 | 证券服务专项准入 |
| 十四 | 原三十六→新三十九 | 注协应加强行业发展规划、人才队伍建设、行业自律监督 | 注协职能强化 |
| 十五 | 新增第六章 42–46 | **新增“监督管理”章**：财政部门监督检查权；监管谈话/警示函/责令限期整改；底稿档案境内留存、不得擅自出境；信息化建设 | 监管工具箱 |
| 十六 | 原三十九→新四十七 | 违规出具报告罚则：违法所得 50 万以上处 1–10 倍罚款，不足处 500 万以下；情节严重暂停 1–12 月或吊销；故意犯罪终身禁业 | 处罚加码 |
| 十七 | 新增第四十八条 | 违反禁止性规定（第三十五条）罚则；注册会计师违反第二十四条（冒用名义等）参照处理 | 禁止行为罚则 |
| 十八 | 新增第四十九条 | **委托人/被审计单位等串通、唆使出具虚假报告的，最高罚 500 万** | 追责链条延伸 |
| 十九 | 原四十→新五十 | 未经批准承办业务罚则；暂停期间继续承办从重处罚 | 无证执业 |
| 二十 | 新增第五十一条 | 被审计单位等提供虚假会计资料，依有关法律行政法规处罚 | 资料造假责任 |
| 二十一 | 新增第五十二条 | 违反协助检查义务（第四十三条）罚则 | 阻碍检查 |
| 二十二 | 新增第五十三条 | 擅自携带/传递底稿档案出境罚则（单位 200 万、个人 50 万，情节严重吊证） | 底稿出境红线 |
| 二十三 | 新增第五十四条 | 监管/协会工作人员渎职、泄密的处分 | 公权力约束 |
| 二十四 | 原四十一→新五十五 | 复议/诉讼、逾期不履行可申请法院强制执行 | 救济程序 |
| 二十五 | 新增第五十七条 | 构成犯罪的，依法追究刑事责任 | 行刑衔接 |
| 二十六 | 删去原第四十三条 | 原“注册审计师”条款删除 | 审改注过渡条款退出 |
| 二十七 | 措辞修订 | 十八→二十“委托人”改“委托人或者被审计单位”；十九→二十一保密范围扩至国家秘密/工作秘密/个人隐私/个人信息并增“不得泄露或非法提供”；二十五→二十七“负有限责任的”改“有限责任”等 | 表述与技术衔接 |

## 三、高频考点速记

- **施行时间**：2027-01-01（尚未生效，现行仍为 2014 修正版）。
- **处罚上限跃升**：违规出具报告由最高违法所得 5 倍 → **10 倍**；无违法所得情形事务所最高 **500 万**、责任人最高 **200 万**。
- **资格罚梯度**：警告/通报→暂停业务 1–12 月→吊销执业许可/证书；故意犯罪 **终身禁业**。
- **先证后照**：会计师事务所设立由“先照后证”改为资质审批前置。
- **新增监督管理章**：监管谈话、警示函、责令限期整改；底稿档案须境内留存。
- **责任主体扩展**：委托人、被审计单位串通唆使造假同步担责；提供虚假会计资料另行处罚。
- **职业怀疑法定化**：未保持职业怀疑且未履行必要程序/未获取充分适当证据出具不当报告，列为禁止行为。

## 四、与实务衔接

- 审计底稿管理：新增底稿档案境内留存、不得擅自出境要求（衔接 [[concepts/law-cpa]] 审计实务连接）。
- 独立性/职业道德：禁止冒用名义、禁止不正当招揽，与 [[concepts/ethics-code]]、[[concepts/independence-standard-1]] 联动。
- 证券服务：限责所禁入证券服务、上市公司审计专项准入，与 [[concepts/law-securities]] 证券服务机构责任衔接。
