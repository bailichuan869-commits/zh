## 第0章：课程导引

### 如何使用本课程

这一门课解决的是 CPA 会计中最核心的一件事：**业务事实如何进入财务报表**。

很多初学者学会计准则时会陷入两个误区：

第一，把准则当成分录模板。看到“长期股权投资”就急着问借什么、贷什么；看到“合并报表”就急着背抵销分录。这样学会很快，但也忘得很快，因为没有理解分录背后的事实判断。

第二，把准则当成目录。知道 CAS 2 是长期股权投资、CAS 33 是合并财务报表、CAS 14 是收入，但遇到案例时仍然不会判断。目录只能告诉你资料在哪里，不能告诉你结论怎么来。

本课程采用另一种学法：每一个会计知识点都要走完整判断链。

```text
业务事实 -> 会计问题 -> 适用准则 -> 判断条件 -> 报表影响 -> 披露要求 -> 审计证据
```

比如“甲公司取得乙公司 30% 股权”这句话本身还不是会计结论。你至少要继续追问：

- 甲公司是否能参与乙公司的财务和经营决策？
- 是否有董事会席位？
- 其他股东是否高度集中？
- 是否存在一致行动安排？
- 是否有潜在表决权？
- 是否只是财务投资？
- 个别报表和合并报表分别怎么处理？
- 相关判断有什么证据支持？

只有这些问题回答清楚，才谈得上长期股权投资、权益法、金融工具、合并范围和披露。

### 学习方法建议

#### 1. 先画结构图，再看准则

遇到投资、合并、重组、处置、关联方、股权激励、特殊目的主体等事项，先画结构图。

结构图至少包括：

- 投资方；
- 被投资方；
- 中间持股主体；
- 持股比例；
- 表决权比例；
- 董事会或决策机构安排；
- 协议控制或合同权利；
- 交易前后变化。

不画结构图，直接看文字，脑子很容易把 A 公司、B 公司、C 公司、D 公司搅成一锅粥。会计判断一旦主体错了，后面分录再漂亮也没有意义。

#### 2. 每个判断都要区分个别报表和合并报表

个别报表是一个法律主体自己的报表。合并报表是把母公司和其控制的子公司作为一个经济整体来表达。

同一事项在两个层面可能完全不同：

- 母公司个别报表中，对子公司的投资可能是一项长期股权投资；
- 集团合并报表中，母公司对子公司的长期股权投资要与子公司所有者权益抵销；
- 母公司处置子公司部分股权，个别报表可能看投资处置，合并报表要先判断是否丧失控制权。

所以本课程中，凡是出现投资、合并、处置、重组，都默认问一句：这是个别报表问题，还是合并报表问题？

#### 3. 每个会计结论都要能被审计证据支持

CPA 考试不是纯会计考试。综合阶段尤其会把会计处理和审计证据放在一起考。

比如你说“甲公司对乙公司具有重大影响”，审计上不能只接受管理层一句话。你需要证据：

- 投资协议；
- 公司章程；
- 董事会席位；
- 股东会、董事会会议记录；
- 重大经营财务决策参与记录；
- 与其他股东的协议安排；
- 历史表决情况；
- 被投资单位财务资料。

没有证据支持的会计判断，是站不住的判断。

## 第1章：会计准则学习方法：从业务事实到报表表达

### 学习目标

- [ ] 理解会计准则不是分录手册，而是财务报表表达规则。
- [ ] 能把业务事实拆成确认、计量、列报、披露四类问题。
- [ ] 能区分准则正文、解释、应用案例、实施问答、其他规定和索引资料的作用。
- [ ] 能把会计判断连接到审计证据。
- [ ] 能识别“目录式学习”和“判断式学习”的区别。

### 核心内容

#### 1. 会计准则到底解决什么问题

会计准则解决的是财务报表如何表达业务事实。

这句话有三个关键词。

第一个关键词是**业务事实**。会计不是凭空做分录，而是企业发生了交易、事项或情况。例如购买股权、签订合同、提供服务、发行债券、发生诉讼、获得政府补助、出租资产、处置子公司。

第二个关键词是**财务报表**。会计准则最终要落到资产负债表、利润表、现金流量表、所有者权益变动表和附注。一个判断如果不能说明对报表项目或披露的影响，就还没有完成。

第三个关键词是**表达**。同一个业务事实可能有不同表达方式。例如一项投资可能表达为长期股权投资，也可能表达为金融资产；一项政府补助可能递延确认，也可能计入当期损益；一项诉讼可能确认预计负债，也可能只披露或不处理。

会计学习的核心不是“这题分录是什么”，而是：

```text
这个事实应该以什么身份进入报表？
进入哪个报表项目？
金额是多少？
什么时候确认？
附注要不要说明重大判断和风险？
```

#### 2. 四个基本动作：确认、计量、列报、披露

**确认**，就是判断一个事项是否进入财务报表。  
比如某项诉讼是否确认预计负债，某项投资是否确认长期股权投资，某项收入是否确认收入。

**计量**，就是判断进入报表的金额。  
比如按成本、账面价值、公允价值、摊余成本、现值，还是按可收回金额和账面价值孰低。

**列报**，就是判断放在报表哪里。  
比如金融负债和权益工具的区分、合同资产和应收账款的区分、递延收益和其他收益的列示。

**披露**，就是判断附注中要解释什么。  
比如重大会计估计、关键判断、风险暴露、或有事项、关联方关系、合并范围变化。

这四个动作有先后关系，但不是机械顺序。很多复杂事项要来回推敲。例如合并范围判断中，控制判断影响确认范围，合并抵销影响计量，非控制性权益影响列报，结构化主体风险影响披露。

#### 3. 为什么不能从准则编号开始学

准则编号是很好的索引，但不是学习重点。

例如：

- CAS 2 是长期股权投资；
- CAS 33 是合并财务报表；
- CAS 14 是收入；
- CAS 22 是金融工具确认和计量；
- CAS 37 是金融工具列报。

知道这些当然有用，但它只解决“资料在哪里”。考试和实务真正考的是：

- 这个事项是否适用 CAS 2；
- 什么时候从 CAS 2 转到金融工具准则；
- CAS 2 和 CAS 33 在个别报表和合并报表中如何衔接；
- 长投处置是否确认投资收益；
- 合并范围是否遗漏结构化主体；
- 合并抵销是否完整。

目录式学习会停在“知道名称”。判断式学习要继续追问“为什么适用、怎么适用、证据是什么、错在哪里”。

#### 4. 会计判断的七步法

建议以后所有会计事项都按七步法处理。

**第一步：定主体。**  
先明确是哪一个主体在做判断。是母公司个别报表、子公司个别报表，还是集团合并报表？主体不同，结论可能不同。

**第二步：定事实。**  
把交易事实列清楚。谁持股多少，谁控制谁，合同怎么写，交易前后发生了什么变化。

**第三步：定准则。**  
判断适用哪个准则。股权投资可能是长期股权投资，也可能是金融工具；合并事项可能涉及企业合并、合并报表、长期股权投资、非货币性资产交换。

**第四步：定条件。**  
看准则适用条件是否满足。比如控制、共同控制、重大影响；商业实质；公允价值能否可靠计量；是否丧失控制权。

**第五步：定金额。**  
确定初始计量、后续计量、处置损益或调整金额。

**第六步：定列报披露。**  
判断报表项目、附注披露、重大判断说明和风险披露。

**第七步：定证据。**  
列出支持判断的资料。没有证据支持的会计判断，在审计和考试案例中都很脆。

#### 5. 准则资料的层级和使用方式

CPA-ZH 会计准则体系中有很多资料类型。学习时要清楚各自的作用。

**准则正文**是规则主干。它告诉你基本原则、适用范围、确认计量要求和披露要求。

**应用指南**帮助解释准则正文。它通常会给出一些应用场景，但不能脱离正文单独使用。

**准则解释**用于解决准则执行中的特定问题。解释往往很重要，因为它针对实践中的争议点。

**应用案例**更像示范题。它展示事实如何被拆解，规则如何被应用。

**实施问答**通常针对非常具体的问题，实务口径强，但使用时必须比对事实是否一致。

**其他规定**处理某些特定专题、格式或过渡安排。

**索引、下载状态、校准资料**只帮助找资料，不直接构成判断依据。

#### 6. 会计判断为什么要连接审计证据

CPA 会计学习如果完全不管审计，会出现一个问题：你会写结论，但不知道结论是否能被证明。

例如，企业说对被投资单位有重大影响。会计上你可能想到权益法。但审计上要问：

- 有没有董事会席位？
- 有没有参与财务和经营政策决策的会议记录？
- 有没有重大交易安排？
- 其他股东是否能单独控制？
- 是否只是被动投资？

又如，企业说一个结构化主体不需要纳入合并范围。审计上要问：

- 谁设计了这个主体？
- 谁决定相关活动？
- 谁享有主要收益？
- 谁承担主要风险？
- 企业是否提供资金支持或担保？

会计结论和审计证据之间要有桥。没有桥，结论就是悬空的。

### 示例说明

#### 示例1：30% 持股不一定等于重大影响

甲公司持有乙公司 30% 股权。初学者容易说：超过 20%，所以有重大影响，用权益法。

正确判断要继续看：

- 甲公司是否有董事会席位；
- 是否参与重大财务和经营政策；
- 乙公司其他股东是否高度集中并控制董事会；
- 甲公司是否有实质性表决权；
- 是否存在协议限制甲公司参与决策；
- 历史上甲公司是否实际参与决策。

如果甲公司没有董事席位，不参与经营决策，其他股东集中控制乙公司，那么 30% 也不一定构成重大影响。

#### 示例2：内部重组不一定确认投资收益

A 公司控制 C 公司和 D 公司。C 公司吸收合并 D 公司，A 公司原持有 D 的投资转换为对 C 的投资。交易价格经评估确定。

如果只看形式，会觉得 A 公司用 D 股权换了 C 股权，好像可以按公允价值确认投资收益。

但判断重点是：

- C、D 是否在交易前后都处于 A 控制范围内；
- A 对相关业务的控制是否发生实质变化；
- 未来现金流风险、时间分布和金额是否实质改变；
- 评估价格是否只是少数股东保护或换股定价需要。

如果实质是同一控制范围内内部重组，通常不宜仅因评估价格公允确认投资收益。

### 记忆辅助

#### 对比表格：目录式学习 vs 判断式学习

| 学习方式 | 典型表现 | 问题 | 正确替代 |
|---|---|---|---|
| 目录式学习 | CAS 2 是长投，CAS 33 是合并 | 知道名称但不会做题 | 学判断条件和证据 |
| 分录式学习 | 先背借贷 | 容易忽略适用前提 | 先判断事实和准则 |
| 摘抄式学习 | 把准则文字复制进笔记 | 没有转化为能力 | 改写成判断步骤 |
| 判断式学习 | 事实、规则、证据、结论连起来 | 能应对案例 | 本课程采用 |

#### 对比表格：确认、计量、列报、披露

| 动作 | 回答的问题 | 长投示例 | 合并示例 |
|---|---|---|---|
| 确认 | 是否进入报表 | 是否确认为长期股权投资 | 是否纳入合并范围 |
| 计量 | 金额是多少 | 成本法、权益法、减值 | 合并抵销、非控制性权益 |
| 列报 | 放在哪里 | 长期股权投资、投资收益 | 合并资产负债表、利润表 |
| 披露 | 说明什么 | 重大投资、减值、处置 | 合并范围变化、结构化主体 |

| 易错点 | 正确做法 |
|---|---|
| 看到准则编号就以为会了 | 要能解释适用条件、判断步骤和证据 |
| 看到持股比例就下结论 | 持股比例只是线索，不是全部事实 |
| 只看个别报表 | 投资和合并事项必须同步看合并报表 |
| 只看会计处理 | 要补上列报披露和审计证据 |

### 本章小结

1. 会计准则解决的是业务事实如何进入财务报表。
2. 会计判断至少包括确认、计量、列报、披露四个动作。
3. 学准则不能停在编号和目录，要掌握适用条件和判断路径。
4. 会计判断必须连接审计证据。
5. 本课程后续所有章节都按“事实 -> 规则 -> 判断 -> 报表 -> 证据”的方式展开。

## 第2章：长期股权投资与合营安排

### 学习目标

- [ ] 能说明长期股权投资的入口判断：控制、共同控制、重大影响。
- [ ] 能区分子公司、合营企业、联营企业和普通权益投资。
- [ ] 能理解成本法、权益法和金融工具路径的选择逻辑。
- [ ] 能处理长期股权投资与合并报表、内部交易、处置转换之间的关系。
- [ ] 能使用 CPA-ZH 长期股权投资案例分析内部重组是否确认投资收益。

### 核心内容

#### 1. 为什么长期股权投资是 CPA 会计重点

长期股权投资是 CPA 会计中最容易和其他章节串联的知识点之一。它连接：

- 企业合并；
- 合并财务报表；
- 金融工具；
- 非货币性资产交换；
- 资产减值；
- 所有者权益；
- 关联方；
- 报表列报和披露；
- 审计中的控制判断、集团审计、投资减值和证据评价。

它难，不是因为“分录很多”，而是因为它要求你先判断关系。

投资方和被投资单位之间到底是什么关系？

- 是控制？
- 是共同控制？
- 是重大影响？
- 还是普通财务投资？

关系判断错了，后续准则路径就会错。

#### 2. 长期股权投资的入口判断

长期股权投资准则的入口不是“买股权”，而是“买股权后产生了特定影响”。

可以用以下判断树：

```text
取得权益性投资
  |
  |-- 是否控制被投资单位？
  |      |-- 是：对子公司投资，个别报表通常成本法，合并报表纳入合并范围
  |      |-- 否：
  |
  |-- 是否共同控制某项安排？
  |      |-- 是：判断合营安排，通常涉及合营企业权益法
  |      |-- 否：
  |
  |-- 是否具有重大影响？
  |      |-- 是：联营企业，通常权益法
  |      |-- 否：通常进入金融工具准则路径
```

这个判断树是学习长期股权投资的核心地图。

#### 3. 控制：不只是持股超过 50%

**控制**是指投资方能够主导被投资方的相关活动，享有可变回报，并有能力运用权力影响回报。

通俗说，控制不是“股份多”这么简单，而是“能决定关键活动，并且自己的收益会受这些决定影响”。

判断控制要看三件事：

1. **权力**：谁能主导相关活动。相关活动通常是对被投资方回报影响最大的活动，例如生产经营、投融资、预算、重大资产处置、关键管理人员任免。
2. **可变回报**：投资方是否因参与被投资方而享有不固定的收益或承担风险。回报可以是股利、管理费、协同效应、成本节约，也可以是损失风险。
3. **权力与回报的联系**：投资方是否能用自己的权力影响自己的回报。

持股比例很重要，但不是唯一证据。以下情况都可能让持股比例失灵：

- 其他股东高度分散；
- 存在一致行动协议；
- 存在委托投票安排；
- 存在潜在表决权；
- 通过合同控制关键活动；
- 投资方只是代理人而不是主要责任人；
- 重大决策需要特定方同意。

#### 4. 共同控制：一致同意是关键

**共同控制**是合同约定的控制。它的重点是：相关活动必须经分享控制权的参与方一致同意。

共同控制不是“大家都有点影响力”。如果某一方可以单独决定相关活动，就不是共同控制。如果所有参与方都能参与讨论，但最终不需要一致同意，也不一定是共同控制。

判断共同控制时要看：

- 合同或章程是否明确需要一致同意；
- 哪些事项属于相关活动；
- 是否只有特定参与方共同控制，而不是所有投资方共同控制；
- 是否存在僵局解决机制；
- 该机制是否改变一致同意的实质。

#### 5. 重大影响：20% 只是线索

**重大影响**是指对被投资单位的财务和经营政策有参与决策的权力，但不能控制或共同控制。

常见证据包括：

- 在董事会或类似权力机构中派有代表；
- 参与财务和经营政策制定；
- 与被投资单位发生重要交易；
- 向被投资单位派出管理人员；
- 提供关键技术资料。

持股 20% 通常是一个推定线索，但不是绝对规则。低于 20% 也可能有重大影响，高于 20% 也可能没有重大影响。

考试和实务中，最重要的是用证据打破机械比例思维。

#### 6. 子公司、合营企业、联营企业、普通权益投资

| 类型 | 关系本质 | 会计路径 | 常见证据 |
|---|---|---|---|
| 子公司 | 投资方控制 | 个别报表成本法，合并报表纳入合并 | 表决权、董事会控制、合同权利、实际决策 |
| 合营企业 | 投资方与其他方共同控制 | 权益法 | 合营协议、一致同意条款 |
| 联营企业 | 投资方具有重大影响 | 权益法 | 董事席位、参与决策、重大交易 |
| 普通权益投资 | 无控制、共同控制、重大影响 | 金融工具准则 | 投资目的、持股比例、无参与决策证据 |

#### 7. 成本法、权益法和金融工具路径

**成本法**可以先理解为：投资账面价值一般不随着被投资单位日常净利润波动而调整。对子公司投资在母公司个别报表中通常采用成本法。

**权益法**可以先理解为：投资方把被投资单位净资产变动中属于自己的份额反映到长期股权投资中。它不是简单“净利润乘比例”，还要考虑：

- 被投资单位会计政策和会计期间是否一致；
- 投资时点公允价值调整；
- 被投资单位其他综合收益；
- 利润分配；
- 投资方与联营/合营企业之间未实现内部交易损益；
- 被投资单位执行新准则的衔接调整；
- 减值迹象。

**金融工具路径**适用于不具有控制、共同控制、重大影响的权益性投资。此时重点转向金融资产分类、公允价值变动、减值或其他综合收益列报等问题。

#### 8. 个别报表和合并报表的不同

长期股权投资一定要分报表层次。

母公司对子公司的投资：

- 在母公司个别报表中，是长期股权投资；
- 在集团合并报表中，母公司对子公司的长期股权投资和子公司所有者权益要抵销；
- 子公司利润不通过母公司个别报表权益法反映，但会进入合并利润表。

对联营企业和合营企业：

- 个别报表中通常用权益法；
- 合并报表中通常仍以权益法列示，不纳入逐项合并；
- 但未实现内部交易损益需要按规则抵销或调整。

#### 9. 内部交易和权益法调整

权益法的难点之一是内部交易。

投资方与联营企业、合营企业之间发生投出或出售资产交易，如果该交易不构成业务，产生的未实现内部交易损益不能简单全额确认。需要按投资方享有的比例抵销相关未实现损益。

这类问题的实质是：你不能通过和自己有重大影响关系的企业交易，把还没有对外实现的利润提前确认。

审计上要关注：

- 交易是否真实；
- 是否构成业务；
- 交易价格是否公允；
- 未实现损益是否正确抵销；
- 对合并报表是否有进一步影响。

#### 10. 投资处置和转换

长期股权投资处置和转换是高频难点。

常见转换包括：

- 控制转为重大影响；
- 控制转为无重大影响；
- 重大影响转为控制；
- 重大影响转为金融资产；
- 金融资产转为重大影响或控制；
- 集团内部重组导致投资标的变化。

处理转换时，不要先背分录，先问：

1. 原来是什么关系；
2. 现在是什么关系；
3. 控制是否丧失；
4. 是否形成对外交易；
5. 是否具有商业实质；
6. 个别报表和合并报表分别如何处理；
7. 是否产生投资收益或资本公积调整；
8. 是否需要披露重大判断。

#### 11. 案例精讲：A 公司持有 D 公司投资转换为 C 公司投资

CPA-ZH 案例中，A 公司为集团母公司，直接持有 D 公司 16.67% 股权，并通过子公司 B 间接持有 D 公司 83.33% 股权，因此控制 D 公司。C 公司也是 A 公司子公司。后来 C 公司吸收合并 D 公司，A 公司原持有 D 的长期股权投资转为对 C 的投资。

争议问题是：A 公司是否应按公允价值重新计量，并确认投资收益？

表面看，A 公司用 D 公司股权换成 C 公司股权，好像是资产交换。并且换股价格经过审计评估和股东协商，公允价值看起来可靠。

但核心不是公允价值是否可靠，而是交易是否具有商业实质。

判断商业实质要看：交易是否实质改变企业未来现金流量的风险、时间分布或金额。

本案中：

- C 公司和 D 公司交易前均在 A 公司控制范围内；
- 交易后 A 公司仍控制 C 公司；
- D 的业务只是换了 C 这个承载主体；
- A 对相关业务的控制和收益风险格局没有实质变化。

因此，更合理的理解是同一控制范围内内部重组。A 公司原持有 D 的投资转为对 C 的投资时，应按原账面价值结转，不宜按公允价值重新计量，也不应确认投资收益。

这个案例要记住一句话：

> 公允定价不等于商业实质，内部重组不等于对外处置。

#### 12. 审计证据和底稿收口

长期股权投资的底稿不能只有科目余额表。至少要覆盖：

- 投资协议；
- 章程；
- 股东名册；
- 工商信息；
- 董事会席位；
- 表决权安排；
- 一致行动或委托代理协议；
- 重大决策会议记录；
- 被投资单位财务报表；
- 权益法调整表；
- 内部交易抵销测算；
- 减值测试资料；
- 处置或转换事项专项备忘录。

底稿结论要能回答：

1. 为什么适用长期股权投资准则；
2. 为什么是成本法或权益法；
3. 为什么没有适用金融工具准则；
4. 个别报表和合并报表分别如何处理；
5. 是否存在减值；
6. 是否存在通过内部交易调节利润的风险。

### 记忆辅助

#### 判断树

```text
权益性投资
  -> 控制？是：子公司路径
  -> 共同控制？是：合营企业路径
  -> 重大影响？是：联营企业路径
  -> 都不是：金融工具路径
```

#### 对比表格：三种影响程度

| 项目 | 控制 | 共同控制 | 重大影响 |
|---|---|---|---|
| 决策能力 | 主导相关活动 | 相关活动需共同控制方一致同意 | 参与政策决策 |
| 典型对象 | 子公司 | 合营企业 | 联营企业 |
| 个别报表常见路径 | 成本法 | 权益法 | 权益法 |
| 合并报表影响 | 纳入合并范围 | 通常不逐项合并 | 通常不逐项合并 |
| 关键证据 | 董事会控制、表决权、合同权利 | 合营协议、一致同意机制 | 董事席位、参与决策 |

#### 易错警示卡

| 易错判断 | 正确理解 |
|---|---|
| 持股超过 50% 必然控制 | 通常是强证据，但仍需看权力是否实质存在 |
| 持股超过 20% 必然重大影响 | 只是推定线索，仍需看实际参与决策证据 |
| 权益法就是净利润乘比例 | 还要调整其他综合收益、分红、内部交易、政策差异等 |
| 公允价值可靠就能确认收益 | 还要看交易是否具有商业实质 |
| 个别报表处理等于合并报表处理 | 两者报告主体不同，处理可能完全不同 |

### 本章小结

1. 长期股权投资的入口判断是控制、共同控制、重大影响。
2. 子公司、合营企业、联营企业和普通权益投资对应不同会计路径。
3. 成本法、权益法和金融工具路径不能混用。
4. 个别报表和合并报表必须分开分析。
5. 集团内部重组中，公允定价不等于商业实质，不应轻易确认投资收益。
6. 长期股权投资审计要形成控制关系、权益法调整、减值和处置转换的证据链。

## 第3章：企业合并与合并财务报表

### 学习目标

- [ ] 理解合并报表不是简单相加，而是把集团作为一个报告主体表达。
- [ ] 能掌握控制三要素：权力、可变回报、运用权力影响回报。
- [ ] 能识别结构化主体、委托代理、潜在表决权和合并范围遗漏风险。
- [ ] 能理解合并抵销、非控制性权益、处置子公司和丧失控制权的基本逻辑。
- [ ] 能说出合并范围审计需要哪些证据。

### 核心内容

#### 1. 合并报表要解决什么问题

如果一家公司控制了另一家公司，只看母公司个别报表会低估整个集团的资源和风险。

例如，母公司可能只在个别报表中列示一项长期股权投资，但被控制的子公司实际拥有大量资产、负债、收入、费用和现金流。如果不编制合并报表，报表使用者看不到集团整体状况。

合并财务报表的目标是：把母公司和其控制的子公司作为一个经济整体来表达。

这里有两个重点。

第一，合并报表不是法律主体报表，而是经济整体报表。  
第二，合并报表不是简单相加，而是要抵销集团内部影响。

#### 2. 为什么合并报表不是简单相加

如果母公司卖商品给子公司，母公司确认收入，子公司确认存货。站在集团整体看，这只是左手卖给右手，并没有真正对外实现收入。合并报表要抵销内部销售和未实现利润。

如果母公司借款给子公司，母公司有应收款，子公司有应付款。站在集团整体看，集团并没有对外新增债权债务。合并报表要抵销内部往来。

如果母公司持有子公司股权，母公司个别报表有长期股权投资，子公司报表有所有者权益。站在集团整体看，不能既确认对子公司的投资，又确认子公司的净资产，否则会重复。合并报表要抵销长期股权投资和子公司所有者权益。

所以合并报表至少涉及：

- 合并范围判断；
- 报表项目汇总；
- 内部交易抵销；
- 内部往来抵销；
- 长期股权投资与所有者权益抵销；
- 非控制性权益列报；
- 合并调整和披露。

#### 3. 合并范围的核心是控制

合并报表最先问的问题不是“怎么抵销”，而是“谁该纳入合并”。

纳入合并范围的核心标准是控制。控制有三个要素：

1. 投资方拥有对被投资方的权力；
2. 投资方因参与被投资方相关活动而享有可变回报；
3. 投资方有能力运用对被投资方的权力影响其回报金额。

这三个要素要同时存在。

#### 4. 权力：谁能主导相关活动

权力不是泛泛的影响力，而是主导相关活动的现实能力。

相关活动是对被投资方回报产生重大影响的活动。不同企业相关活动不同，例如：

- 制造企业：生产计划、采购、销售、定价、产能安排；
- 投资基金：投资决策、资产处置、风险管理；
- 房地产项目公司：土地开发、融资、销售策略；
- 研发企业：研发方向、预算、知识产权安排；
- 平台公司：核心算法、客户数据、服务规则。

判断权力要看：

- 表决权；
- 董事会控制；
- 任免关键管理人员的权利；
- 合同安排；
- 潜在表决权；
- 事实上的主导能力；
- 其他股东是否分散；
- 保护性权利和实质性权利的区分。

保护性权利通常只是保护持有人利益，不能赋予控制。例如贷款人限制借款人重大资产处置，可能只是保护贷款安全，不一定说明贷款人控制借款人。

#### 5. 可变回报：收益和风险都算

可变回报不是只有分红。

可变回报可以包括：

- 股利；
- 公允价值变动；
- 管理费；
- 业绩报酬；
- 协同效应；
- 成本节约；
- 税务利益；
- 信用支持带来的风险；
- 亏损承担；
- 声誉风险。

因此，判断合并范围时不能只看“有没有分红”。有些结构化主体不分红，但企业通过管理费、劣后级份额、担保或流动性支持承担了主要风险和收益，也可能存在可变回报。

#### 6. 运用权力影响回报：权力和回报要连起来

有权力，也有回报，还不够。还要看投资方能否运用权力影响自己的回报。

例如，一家资产管理公司管理基金，能决定投资活动，也收取管理费。但它是代理人还是主要责任人，要看：

- 决策权范围；
- 其他方是否有罢免权；
- 管理费是否只是市场化报酬；
- 管理人是否持有重大权益；
- 是否承担重大风险。

如果只是代理人，可能不控制基金。如果是主要责任人，可能控制。

#### 7. 为什么不能只看持股比例

持股比例是重要线索，但不是控制判断的全部。

低持股也可能控制：

- 其他股东高度分散；
- 投资方掌握董事会多数席位；
- 投资方通过合同主导相关活动；
- 投资方持有实质性潜在表决权；
- 投资方承担主要风险并获得主要收益。

高持股也不一定控制：

- 表决权被限制；
- 重大活动需要其他方批准；
- 投资方只是代理人；
- 相关活动由合同指定的另一方主导；
- 权利不是实质性权利。

考试题最爱考的就是“不能只看比例”。

#### 8. 结构化主体是合并范围高风险区

结构化主体通常指表决权或类似权利不是决定控制的主导因素的主体。比如某些基金、理财产品、信托计划、资产管理计划、专项计划、项目公司。

结构化主体难在：法律形式上可能看不出谁控制，但经济实质上可能某一方主导相关活动并享有可变回报。

判断时要看：

- 谁发起设立；
- 谁设计交易结构；
- 谁决定投资或运营活动；
- 谁享有剩余收益；
- 谁承担劣后风险；
- 谁提供担保、回购、流动性支持；
- 其他投资者是否只是被动出资；
- 决策权是否实质性。

#### 9. 合并抵销的基本逻辑

合并抵销可以先不背复杂分录，先理解经济实质。

| 抵销事项 | 为什么抵销 |
|---|---|
| 母公司长期股权投资与子公司所有者权益 | 集团不能既确认投资又确认被投资方净资产 |
| 内部应收应付 | 集团内部债权债务不是对外权利义务 |
| 内部销售收入和成本 | 集团内部交易没有对外实现 |
| 内部存货未实现利润 | 商品未卖给集团外部，利润未真正实现 |
| 内部固定资产交易未实现利润 | 资产仍在集团内使用，内部利润要调整 |
| 内部现金流 | 集团内部资金流动不是对外现金流 |

抵销的根本原则是：从集团整体看，自己和自己交易不能创造对外利润、资产或负债。

#### 10. 非控制性权益

如果母公司没有 100% 持有子公司，子公司净资产和利润中有一部分属于其他股东。这部分在合并报表中称为非控制性权益。

非控制性权益不是负债，因为少数股东不是集团债权人。它是权益的一部分，但不归属于母公司股东。

学习时先记住：

- 合并报表纳入子公司全部资产、负债、收入、费用；
- 再把不属于母公司的部分列为非控制性权益和少数股东损益；
- 不能只按母公司持股比例合并资产负债。

#### 11. 处置子公司和丧失控制权

处置子公司时，最关键的问题是是否丧失控制权。

如果没有丧失控制权，仍然是母子公司关系，合并范围不变，通常作为权益交易处理。

如果丧失控制权，就要终止纳入合并范围，并重新考虑剩余股权的会计处理。剩余股权可能成为联营企业、合营企业或金融资产。

CPA-ZH CAS 33 页面中特别提示：报告期内处置唯一子公司并丧失控制权，处置当期是否仍需要编制合并报表、后续年度以什么报表基础编制，是需要关注的问题。

这类问题的判断链是：

```text
报告期内是否曾控制子公司
  -> 处置时点是否丧失控制
  -> 处置前损益是否纳入合并
  -> 剩余股权如何计量
  -> 后续期间是否仍有合并范围
  -> 比较信息和披露如何处理
```

#### 12. 合并范围审计证据

合并范围错报通常很隐蔽，因为管理层可能不是把子公司金额算错，而是直接把一个主体排除在合并范围外。

审计证据应包括：

- 集团架构图；
- 股权穿透图；
- 工商登记信息；
- 投资协议；
- 公司章程；
- 董事会席位和表决权安排；
- 一致行动协议；
- 委托代理协议；
- 潜在表决权资料；
- 结构化主体设立文件；
- 资金支持、担保、回购安排；
- 重大经营财务决策记录；
- 合并范围清单；
- 未纳入合并范围主体的排除理由；
- 合并抵销分录和复核记录；
- 组成部分审计资料。

### 示例说明

#### 示例1：45% 持股也可能控制

甲公司持有乙公司 45% 股权。其他股东均很分散，没有单一股东持股超过 5%。甲公司有权任命乙公司董事会多数成员，乙公司经营预算、融资和重大投资均由董事会批准。

虽然甲公司持股低于 50%，但甲公司通过董事会主导相关活动，并享有可变回报。如果没有其他限制，甲公司可能控制乙公司。

#### 示例2：60% 持股也要继续分析

甲公司持有乙公司 60% 股权，但协议约定乙公司重大经营、预算、融资、人事任免均需另一投资方同意。另一投资方拥有实质性否决权，不只是保护性权利。

这种情况下，不能机械认为甲公司一定控制。需要分析相关活动决策机制，判断是否存在共同控制或其他安排。

#### 示例3：结构化主体不能只看份额比例

甲公司持有某资管计划 30% 份额，但该计划由甲公司发起设计，甲公司担任管理人，决定投资活动，并持有劣后级份额承担主要亏损风险，同时享有超额收益。

虽然份额只有 30%，但甲公司可能同时拥有权力、可变回报以及运用权力影响回报的能力。是否纳入合并范围不能只看份额比例。

### 记忆辅助

#### 控制三要素表

| 要素 | 通俗理解 | 常见证据 | 常见陷阱 |
|---|---|---|---|
| 权力 | 谁说了算 | 表决权、董事会、合同权利 | 把保护性权利当控制 |
| 可变回报 | 谁赚谁亏 | 分红、管理费、劣后风险、协同效应 | 只看分红不看风险 |
| 运用权力影响回报 | 能否用权力影响自己收益 | 决策记录、管理安排、风险承担 | 把代理人当控制方 |

#### 合并抵销理解表

| 集团内部事项 | 个别报表看到 | 合并报表看法 |
|---|---|---|
| 母公司对子公司投资 | 长期股权投资 | 与子公司权益抵销 |
| 内部销售 | 收入和成本 | 未对外实现，抵销 |
| 内部往来 | 应收和应付 | 集团内部债权债务，抵销 |
| 内部利润存货 | 存货含利润 | 未对外出售部分利润抵销 |

#### 口诀

合并先问控不控，控制三看权回用；比例只是第一眼，合同实质要看清；内部交易不造利，集团整体看对外。

### 本章小结

1. 合并报表把母公司和受控制子公司作为一个经济整体表达。
2. 合并报表不是简单相加，必须抵销集团内部交易和余额。
3. 合并范围判断核心是控制三要素：权力、可变回报、运用权力影响回报。
4. 持股比例只是线索，结构化主体、委托代理、潜在表决权等需要实质判断。
5. 处置子公司时，是否丧失控制权决定合并报表处理方向。
6. 合并范围审计要重点防止遗漏受控制主体。

情景判断参考：不可以。应根据权力、可变回报和运用权力影响回报的能力综合判断。甲公司设计并主导投资活动，同时承担主要风险和享有主要收益，可能存在控制。  
简答题参考：合并报表把集团作为一个整体。集团内部交易只是同一经济整体内部资源转移，不能创造对外收入、利润、债权债务或现金流，因此需要抵销。

</details>

## 第4章：金融工具确认、计量、减值与列报

### 学习目标

- [ ] 能区分金融资产、金融负债和权益工具，理解金融工具不是“银行理财、债券、股票”的简单名称集合。
- [ ] 能用“业务模式 + 合同现金流量特征”判断金融资产分类。
- [ ] 能理解摊余成本、公允价值计量、其他综合收益和当期损益之间的关系。
- [ ] 能掌握预期信用损失模型的基本逻辑，知道为什么它不是“已经坏账才计提”。
- [ ] 能识别金融负债与权益工具区分中的实质义务，尤其是永续债、回售权、保护性条款和特殊条款。
- [ ] 能把金融工具判断连接到审计证据：合同条款、估值模型、参数、信用风险阶段、管理层覆盖调整和披露。

### 核心内容

#### 1. 金融工具先不要按名字学，要按权利义务学

金融工具的名字很容易迷惑人。股票、债券、理财产品、结构性存款、应收账款、贷款、永续债、可转债、资产支持证券，看起来都不一样，但准则真正关心的是：一方形成金融资产，另一方形成金融负债或权益工具。

**金融资产**可以先理解为“收钱或换金融工具的权利”。例如应收账款、债权投资、贷款、持有的债券、部分理财产品、对其他企业的权益工具投资。

**金融负债**可以先理解为“交钱或交出其他金融资产的合同义务”。例如借款、应付债券、应付票据、某些带强制赎回条款的优先股或永续债。

**权益工具**可以先理解为“扣除所有负债后对企业净资产的剩余权益”。普通股通常是权益工具，但带特殊回售、强制付息、强制赎回或现金结算条款的工具，不能只因名称叫“股”或“永续”就列为权益。

金融工具学习的第一条规则是：

```text
看合同产生了什么权利和义务，不看产品名称好不好听。
```

例如，一项“结构性存款”可能包含本金保障、浮动收益、衍生工具等安排。不能因为银行叫它“存款”，就机械按普通存款处理；也不能因为它带浮动收益，就马上按高风险交易性金融资产处理。要看合同现金流量是否符合基本借贷安排，企业管理它的业务模式是什么，是否包含需要分拆或整体公允价值计量的特征。

#### 2. 金融资产分类的主线：业务模式 + 合同现金流量特征

金融资产分类是金融工具章节的核心。很多错题不是算错，而是第一步分类错了。

判断金融资产分类，要问两个问题。

第一个问题：企业管理这项金融资产的**业务模式**是什么？

- 如果企业持有金融资产主要是为了收取合同现金流量，例如持有贷款或债券到期收本收息，倾向于摊余成本计量。
- 如果企业既收取合同现金流量，也会出售金融资产，例如流动性管理中持有债券，倾向于以公允价值计量且其变动计入其他综合收益。
- 如果企业主要为了交易、短期获利、管理公允价值波动，倾向于以公允价值计量且其变动计入当期损益。

第二个问题：合同现金流量是否仅为对本金和以未偿付本金金额为基础的利息的支付，通常简称 SPPI 特征。

这里的“利息”不是合同写了“利息”两个字就可以，而是要反映货币时间价值、信用风险、其他基本借贷风险、成本和合理利润。若合同现金流量暴露于权益价格、商品价格、指数杠杆、非基本借贷风险，就可能不符合 SPPI。

分类结果可以先这样记：

| 业务模式 | 合同现金流量特征 | 常见分类方向 | 损益影响直觉 |
|---|---|---|---|
| 收取合同现金流量 | 符合 SPPI | 摊余成本 | 利息收入、减值、终止确认损益进损益 |
| 收取合同现金流量并出售 | 符合 SPPI | 公允价值计量且变动计入其他综合收益 | 利息和减值进损益，公允价值变动进其他综合收益 |
| 交易或其他公允价值管理 | 不要求 SPPI 或不满足前两类 | 公允价值计量且变动计入当期损益 | 公允价值变动直接影响当期损益 |

一个常见误区是：只要企业“偶尔卖出”，就不能是摊余成本。这个说法太粗。业务模式看的是如何管理金融资产以及如何评价业绩，不是看有没有发生过一次出售。偶发出售、信用风险显著上升后的处置、接近到期的小额出售，不一定改变业务模式。但如果企业经常通过出售实现收益，并以公允价值变动评价业绩，就不能硬说是“持有收息”。

#### 3. 摊余成本不是历史成本，它是实际利率法下的账面金额

初学者容易把摊余成本理解为“买入成本不动”。这是错的。

摊余成本是一种后续计量思路：初始确认金额扣除已偿还本金，加减实际利率法形成的累计摊销，再扣除损失准备。它的核心是实际利率法。

实际利率法的意思是：金融资产或金融负债整个存续期预计现金流量折现到初始账面金额的利率，用这个利率确认利息收入或利息费用。

举个简化例子。企业折价买入一项债券，票面利率低于市场利率。如果只按票面利息确认收益，会低估实际收益。实际利率法会把折价部分在持有期间逐步摊入利息收入。反过来，如果溢价买入债券，实际利息收入会低于票面利息，溢价部分会逐步摊销。

所以摊余成本的学习重点不是背公式，而是理解：

```text
摊余成本 = 用实际利率把未来现金流量“摊回”到每一期的账面价值。
```

#### 4. 公允价值计量要看估值层次、输入值和模型，不是管理层说多少就是多少

金融工具中的公允价值，是 CPA 考试和审计实务的高风险区。因为很多金融工具没有活跃市场报价，管理层需要用模型估值。

公允价值估值通常要关注三个层次：

- 第一层次：活跃市场中相同资产或负债的报价。证据最直接。
- 第二层次：除第一层次报价以外可观察输入值，例如类似工具报价、收益率曲线、信用利差。
- 第三层次：重大不可观察输入值，例如未来现金流、违约率、提前还款率、波动率、流动性折价。

层次越低，估计不确定性越高，管理层偏向风险越高，审计程序越不能停留在“拿到估值报告”。

审计上要追问：

- 模型适不适合这个产品？
- 参数来自哪里？
- 参数是否可观察？
- 第三方估值机构是否独立、胜任？
- 管理层有没有覆盖调整？
- 敏感性分析显示估值对哪些参数最敏感？
- 披露有没有说明估值技术、输入值和风险？

金融工具估值不是数学表演，它最终要落到财务报表真实性和披露充分性。

#### 5. 预期信用损失：不是等坏账发生，而是提前反映信用风险

旧式思维容易认为：债务人真的违约了，才计提坏账。预期信用损失模型不是这样。

预期信用损失关注的是未来可能发生的信用损失，并要求结合过去事项、当前状况和前瞻性信息。它的核心不是“已经损失”，而是“预期损失”。

可以把它理解为三个层次：

| 阶段 | 信用风险状态 | 损失准备思路 | 利息收入基础 |
|---|---|---|---|
| 第一阶段 | 信用风险未显著增加 | 12个月预期信用损失 | 总账面金额 |
| 第二阶段 | 信用风险显著增加但未发生信用减值 | 整个存续期预期信用损失 | 总账面金额 |
| 第三阶段 | 已发生信用减值 | 整个存续期预期信用损失 | 摊余成本，即扣除损失准备后的净额 |

这里最关键的是“信用风险是否显著增加”。它不是简单看是否逾期，也不是简单看是否已经诉讼。企业应综合考虑内部评级、外部评级、逾期天数、经营环境、宏观经济、担保情况、债务人财务状况、重组迹象等。

对于应收账款和合同资产，实务中常用简化方法，按整个存续期预期信用损失计量。简化不等于随便。账龄组合、客户信用等级、历史损失率、前瞻性调整、单项重大风险客户，都要有依据。

金融工具减值的常见错法包括：

- 只用账龄表，不考虑客户信用风险变化。
- 只看历史损失率，不做前瞻性调整。
- 把关联方资金借贷视为“肯定没风险”，不计提或少计提。
- 对已逾期、展期、违约客户仍停留在第一阶段。
- 管理层用一句“客户会还款”替代可验证证据。
- 合同资产减值和应收账款减值口径不一致。

#### 6. 金融资产终止确认：看风险报酬和控制是否真的转移

企业转让应收账款、贷款、票据、资产支持证券基础资产时，经常涉及金融资产终止确认。

判断不能只看法律形式上的“转让合同已经签了”。要看金融资产现金流量权利是否转移，以及相关风险和报酬是否实质转移。如果企业保留了几乎所有风险和报酬，通常不能终止确认；如果既没有转移也没有保留几乎所有风险和报酬，还要看是否保留控制。

例如，企业把应收账款转让给保理商，但约定债务人不付款时企业要无条件回购或补足，企业可能仍承担主要信用风险。这种安排不能只因收到保理款就把应收账款完全转出。

资产证券化、不良贷款转让、清仓回购条款等，更要关注回购权是否按公允价值、是否具有重大经济动因、是否导致企业继续控制或保留主要风险。

#### 7. 金融负债与权益工具区分：核心是发行人有没有交付现金等金融资产的合同义务

金融负债和权益工具区分，是金融工具列报的难点。它对资产负债率、利润分配、利息费用、每股收益、资本结构都有影响。

判断时先站在发行人角度问：

```text
发行人是否存在交付现金或其他金融资产的合同义务？
发行人是否必须以可变数量自身权益工具结算？
发行人能否无条件避免交付现金或其他金融资产？
```

如果发行人不能无条件避免交付现金或其他金融资产，通常存在金融负债成分。名称叫“优先股”“永续债”“可续期债”，不决定列报。决定列报的是合同义务。

常见条款判断：

- 强制赎回：通常指向金融负债。
- 投资者有回售权且发行人不能无条件避免现金结算：通常指向金融负债。
- 发行人有自主决定是否付息的权利，且没有间接强制义务：可能支持权益分类。
- 保护性条款：不一定导致金融负债，要看是否只是保护投资者利益，而不是赋予投资者要求现金结算的实质权利。
- 补充协议改变发行人义务：要重新评估分类。

这里最容易错的是“形式上能递延，实质上不能递延”。例如合同没有写强制付息，但如果不付息会触发强制赎回、交叉违约、重大经济惩罚或其他实质约束，发行人未必能无条件避免现金流出。

#### 8. 指定为其他综合收益的权益工具投资：不是利润调节工具

对于非交易性权益工具投资，企业可以在初始确认时作出不可撤销选择，将其指定为以公允价值计量且其变动计入其他综合收益。

这个选择有两个关键点：

第一，通常应在初始确认时作出，不能事后因为利润不好看再改变。

第二，相关公允价值变动计入其他综合收益，处置时累计利得或损失通常不能转入当期损益，而是转入留存收益。这与债务工具的其他综合收益处理不同。

所以它不是“把亏损藏到其他综合收益，未来卖出再转回利润”的工具。考试和实务都很喜欢考这个边界。

#### 9. 金融工具披露：复杂性越高，披露越不能薄

金融工具披露至少要帮助报表使用者理解：

- 金融工具对财务状况和经营成果的影响；
- 信用风险、流动性风险、市场风险；
- 风险管理政策；
- 公允价值层次和估值技术；
- 重大不可观察输入值和敏感性；
- 预期信用损失模型、阶段划分和关键假设；
- 金融负债与权益工具分类中的重大判断；
- 金融资产转移和继续涉入。

如果企业持有复杂金融工具，却只在附注里写“按准则进行计量”，这不是有效披露。披露不是重复准则，而是解释本企业面临的具体风险和具体判断。

#### 10. 金融工具审计证据：一张清单串到底

金融工具审计最怕分散：合同在一个底稿，估值报告在另一个底稿，减值模型在第三个底稿，报表列示在第四个底稿，最后没人能说明分类、计量、减值、披露是一条链。

更好的底稿思路是建立金融工具清单，至少包括：

- 工具名称和合同编号；
- 初始确认日期和金额；
- 合同现金流量特征判断；
- 业务模式判断；
- 分类和计量属性；
- 公允价值层次、模型和参数；
- 预期信用损失阶段和损失准备；
- 是否存在终止确认、重分类、修改合同条款；
- 负债权益区分结论；
- 报表列示和附注披露；
- 关键审计证据索引。

这样做的好处是，审计结论可以回到证据链，而不是散落在一堆附件里。

### 示例说明

#### 示例1：一项债券为什么不能只按“准备持有到期”判断

甲公司购入一项债券，合同现金流量为固定本金和固定利息。管理层说准备持有到期，所以按摊余成本计量。

这句话还不够。需要继续看：

- 公司内部投资政策是否以收取合同现金流量为目标；
- 管理层业绩评价是否基于利息收益还是公允价值变动；
- 过去是否频繁出售类似资产；
- 出售原因是否与信用风险管理、流动性管理或短期获利有关；
- 合同现金流量是否真的只有本金和利息。

如果企业历史上频繁买卖该类债券以赚取价格差，并按公允价值变动考核投资部门，即便管理层口头说“准备持有到期”，也未必支持摊余成本分类。

#### 示例2：应收账款未逾期，也可能需要提高损失准备

乙公司主要客户为房地产企业。年末应收账款尚未逾期，管理层按历史账龄损失率计提较低坏账准备。

审计上不能只看“未逾期”。如果房地产行业信用环境恶化，客户债券违约、项目停工、融资受限，即使应收账款账龄未明显增加，也可能说明信用风险显著上升。预期信用损失模型要求考虑前瞻性信息，因此需要调整历史损失率或进行单项评估。

#### 示例3：永续债不一定是权益

丙公司发行永续债，合同写明没有固定到期日，发行人可以递延付息。但补充条款约定，如果发行人递延付息，将触发其他债务交叉违约，并导致投资者有权要求赎回。

此时不能只看“永续”和“可递延付息”。要看发行人是否能无条件避免交付现金。如果递延付息会触发实质性强制赎回或重大经济后果，发行人可能并不能无条件避免现金流出，该工具可能具有金融负债特征。

### 记忆辅助

#### 金融资产分类对比表

| 分类 | 判断入口 | 后续计量 | 公允价值变动去向 | 减值要求 | 常见易错点 |
|---|---|---|---|---|---|
| 摊余成本 | 收取合同现金流量 + 符合 SPPI | 实际利率法 | 通常不确认公允价值变动 | 适用预期信用损失 | 把“偶尔出售”等同于不能摊余成本 |
| 债务工具 FVOCI | 收取现金流量并出售 + 符合 SPPI | 公允价值 | 其他综合收益 | 适用预期信用损失 | 忽略利息和减值仍进损益 |
| FVTPL | 交易性或不满足前两类 | 公允价值 | 当期损益 | 通常不按 ECL 计提 | 把复杂产品硬塞进摊余成本 |
| 权益工具 FVOCI | 非交易性权益工具初始指定 | 公允价值 | 其他综合收益 | 通常不适用 ECL | 误以为处置时可转入损益 |

#### 金融负债与权益工具对比表

| 判断点 | 更像金融负债 | 更像权益工具 |
|---|---|---|
| 现金交付义务 | 发行人必须或可能被要求交付现金，且不能无条件避免 | 发行人能无条件避免交付现金 |
| 赎回条款 | 强制赎回或持有人实质回售权 | 发行人自主赎回选择权 |
| 利息或股利 | 强制支付或不支付触发重大后果 | 发行人可自主决定分配 |
| 结算方式 | 可变数量自身权益工具或现金结算 | 固定数量自身权益工具换固定金额现金 |
| 条款实质 | 补充协议形成现金义务 | 保护性条款不改变剩余权益属性 |

#### 口诀

金融资产三问清：怎么管、收什么、变动进哪里。  
减值不是等爆雷，历史当前加未来。  
负债权益看义务，名字再美不算数。

#### 易错警示卡

| 易错说法 | 为什么错 | 正确理解 |
|---|---|---|
| “债券就是摊余成本” | 债券也可能为交易持有或不符合业务模式 | 分类看业务模式和 SPPI |
| “未逾期就不用多计提” | 预期信用损失要考虑前瞻性信用风险 | 未逾期也可能信用风险显著增加 |
| “永续债没有到期日，所以是权益” | 可能存在强制付息、赎回或间接义务 | 看发行人能否无条件避免现金流出 |
| “估值报告拿到了就够了” | 估值报告也要评价模型、参数和专家胜任能力 | 审计要复核估值过程和关键假设 |
| “其他综合收益以后都能转损益” | 权益工具 FVOCI 处置时通常转留存收益 | 不同工具 OCI 后续处理不同 |

### 本章小结

1. 金融工具判断要从合同权利义务出发，不能按产品名称机械分类。
2. 金融资产分类核心是业务模式和合同现金流量特征。
3. 摊余成本不是成本不动，而是实际利率法下的后续计量。
4. 公允价值估值要关注层次、模型、输入值、敏感性和管理层偏向。
5. 预期信用损失要求提前反映信用风险，并结合前瞻性信息。
6. 金融负债与权益工具区分的核心是发行人是否能无条件避免交付现金或其他金融资产。
7. 金融工具审计应以清单方式串联分类、计量、减值、列报和披露。

## 第5章：收入确认与合同资产负债

### 学习目标

- [ ] 能理解收入确认的核心不是开票、发货或收款，而是客户取得商品或服务控制权。
- [ ] 能掌握收入五步法：识别合同、识别履约义务、确定交易价格、分摊交易价格、履约时确认收入。
- [ ] 能区分某一时点确认收入和某一时段确认收入。
- [ ] 能理解合同资产、应收账款和合同负债的区别。
- [ ] 能识别可变对价、重大融资成分、主要责任人和代理人、售后回购、销售退回等特定交易风险。
- [ ] 能把收入准则判断连接到审计证据：合同、发货、验收、服务记录、结算、回款、期后退货和函证。

### 核心内容

#### 1. 收入确认的核心问题：客户什么时候取得控制权

收入是 CPA 会计和审计共同的高风险区域。原因很简单：利润表里收入最显眼，企业也最有动机通过提前确认、虚构交易、循环交易、隐藏退货、改变总额净额等方式影响业绩。

学习收入准则，第一句话要记牢：

```text
收入确认不是看开票，不是看收款，也不是只看发货，而是看客户是否取得商品或服务的控制权。
```

**控制权**可以理解为客户能够主导该商品或服务的使用，并从中获得几乎全部经济利益。它比“风险报酬转移”更强调客户是否真正能使用、出售、消耗、抵押、限制他人使用该资产或服务成果。

例如，企业把设备发到客户仓库，但客户还没有验收，合同约定验收前设备不符合定制规格可以退回，且企业仍负责重大调试。如果调试是设备可使用的关键步骤，客户可能尚未取得控制权。相反，如果验收只是例行检查，设备已按合同交付且客户能自主使用，收入确认可能已经具备基础。

#### 2. 收入五步法：每一步都可能出错

收入准则的五步法是：

```text
识别合同 -> 识别履约义务 -> 确定交易价格 -> 分摊交易价格 -> 履约时确认收入
```

这五步不是考试口号，而是一条判断链。

**第一步：识别与客户订立的合同。**  
合同要有商业实质，双方批准并承诺履行，权利义务清楚，支付条款明确，对价很可能收回。没有商业实质的循环交易、虚构合同、没有真实客户需求的安排，不能因为有纸面合同就确认收入。

**第二步：识别合同中的单项履约义务。**  
履约义务是企业向客户转让可明确区分商品或服务的承诺。判断“可明确区分”要看客户能否从该商品或服务本身或与其他易于获得资源一起受益，以及企业转让该商品或服务的承诺在合同中是否可单独区分。

**第三步：确定交易价格。**  
交易价格不是合同总价的机械复制。要考虑可变对价、重大融资成分、非现金对价、应付客户对价等。可变对价要受到限制：只有在相关不确定性消除时累计已确认收入极可能不会发生重大转回，才纳入交易价格。

**第四步：将交易价格分摊至各单项履约义务。**  
如果合同包含多项履约义务，通常按单独售价相对比例分摊。不能为了提前确认收入，把价格随意分给已经完成的部分。

**第五步：在履约义务满足时确认收入。**  
履约义务可能在某一时点满足，也可能在某一时段内满足。判断时段确认要看客户是否同时取得并消耗企业履约带来的经济利益、客户是否控制企业履约过程中在建商品、企业履约是否产生不可替代用途且企业有权就累计已完成履约部分收款。

#### 3. 识别合同：纸面合同不是免死金牌

收入确认首先要有真实、可执行、有商业实质的合同。实务中风险最大的不是合同缺页，而是合同看起来完整但交易实质不成立。

常见风险包括：

- 客户没有真实采购需求，交易只是为了冲收入。
- 上下游循环交易，商品并未真正流向最终使用方。
- 合同约定价格明显偏离商业逻辑，后续通过返利、补贴、服务费回流。
- 客户付款能力明显不足，对价收回不具有可能性。
- 合同签订时间、发货时间、验收时间、开票时间异常集中在期末。
- 补充协议或口头承诺改变退货、回购、验收、付款条件。

因此审计上不能只抽合同首页。要把合同、订单、物流、签收、验收、发票、回款、期后退货、客户访谈和函证串起来看。

#### 4. 履约义务：一份合同不等于一项收入

一份合同里可能有多个承诺。比如销售设备并提供安装服务、销售软件并提供后续升级、销售商品并赠送积分、出口定制化产品并负责现场调试。

判断是否拆分履约义务，核心问两个问题：

第一，客户能否从该商品或服务本身受益，或者与其他容易取得的资源一起受益？

第二，该商品或服务在合同中是否可以和其他承诺分开识别？

如果设备本身不能独立使用，安装调试是让设备达到合同约定功能的关键步骤，那么设备和安装可能是一项组合履约义务。如果设备交付后客户已经能独立使用，安装只是辅助服务，则可能拆分为设备销售和安装服务。

CPA-ZH 的海外销售定制化产品案例就体现了这个判断。产品出口和组装调试能否拆分，不看企业想不想提前确认供货收入，而看供货部分是否已经独立转移控制权，组装调试是否只是附带服务，补充协议和实际执行是否真正支持拆分。

#### 5. 某一时点确认收入：控制权转移证据要够硬

多数商品销售在某一时点确认收入。判断控制权转移时，常见证据包括：

- 企业已经就商品取得现时收款权利；
- 客户已经拥有商品法定所有权；
- 企业已经将商品实物转移给客户；
- 客户已经承担商品主要风险和报酬；
- 客户已经接受商品；
- 客户能够主导商品使用并获得经济利益。

这些指标要综合看，不是机械打勾。比如货物已经发出，但客户没有验收，且验收不是例行程序，控制权可能尚未转移。又如客户已经签收，但合同存在实质回购安排，客户可能没有真正控制商品。

收入截止测试也围绕这个问题展开。期末前后几天的发货、签收、验收、报关、提单、客户上线、服务完成记录，是判断收入归属期间的关键证据。

#### 6. 某一时段确认收入：不是“做了一点就确认一点”那么简单

某一时段确认收入要求满足特定条件，不能因为项目周期长就分期确认。

常见三类条件：

第一，客户在企业履约的同时即取得并消耗企业履约所带来的经济利益。典型如保洁、运输、部分持续服务。

第二，客户能够控制企业履约过程中在建的商品。例如在客户土地上建造客户控制的资产。

第三，企业履约过程中所产出的商品具有不可替代用途，且企业有权就累计至今已完成的履约部分收取款项。例如高度定制化产品，企业不能轻易转作他用，且合同保障企业对已完成部分有收款权。

如果不满足时段确认条件，哪怕企业投入了大量成本，也不能仅因“项目已经做了一半”确认收入，而应在控制权转移的时点确认。

#### 7. 交易价格：合同金额不一定等于收入金额

交易价格要反映企业因向客户转让商品或服务而预期有权收取的对价金额。它可能受到以下因素影响：

**可变对价。**  
折扣、返利、退款、奖励、罚款、业绩奖金、价格折让、销售退回，都可能导致对价可变。企业估计可变对价时，要受到“重大转回限制”。如果未来很可能发生重大转回，就不能提前把这部分收入确认得太满。

**重大融资成分。**  
如果客户付款时间和商品服务转让时间之间存在显著间隔，合同可能包含融资成分。预收款可能体现客户向企业提供融资；延期收款可能体现企业向客户提供融资。是否重大，要看付款安排、市场利率、合同目的和行业惯例。

**非现金对价。**  
客户用非现金资产支付对价时，要考虑公允价值计量。

**应付客户对价。**  
企业向客户支付或应付的款项，可能是收入抵减，也可能是购买客户提供的明确可区分商品或服务。不能简单计入销售费用来抬高收入。

#### 8. 合同资产、应收账款和合同负债：三者不是同一回事

收入准则下，合同资产、应收账款和合同负债非常容易混。

| 项目 | 通俗理解 | 关键条件 | 常见例子 |
|---|---|---|---|
| 应收账款 | 企业已经有无条件收款权 | 只需时间流逝即可收款 | 已交付并验收，客户到期付款 |
| 合同资产 | 企业已履约但收款权还取决于其他条件 | 除时间流逝外还受履约等条件限制 | 已完成一个阶段，但需完成后续节点才有权结算 |
| 合同负债 | 企业已收款或有权收款但尚未履约 | 收了钱或形成收款权，但还欠客户商品或服务 | 预收货款、预售卡、未履行服务 |

最重要的区别是：应收账款是无条件收款权，合同资产是有条件收款权。合同负债则是企业欠客户履约。

合同资产也要考虑预期信用损失。它不是因为叫“合同资产”就没有信用风险。CPA-ZH 中 CAS 14 和 CAS 22 的连接点就在这里：收入确认形成的合同资产，后续减值要回到金融工具减值逻辑。

#### 9. 主要责任人和代理人：总额还是净额

平台业务、贸易业务、代理销售中，经常出现总额法和净额法判断。

如果企业在特定商品或服务转让给客户之前控制该商品或服务，通常是主要责任人，按总额确认收入。如果企业只是安排另一方提供商品或服务，通常是代理人，按净额确认佣金或手续费收入。

判断指标包括：

- 企业是否承担向客户转让商品或服务的主要责任；
- 企业是否在商品转让前承担存货风险；
- 企业是否有自主定价权；
- 企业是否承担信用风险；
- 企业是否有能力主导商品或服务的使用。

不能为了做大收入规模，把代理业务按总额确认。也不能因为企业没有生产商品，就当然按净额。核心仍然是控制权：企业在转给客户前是否控制指定商品或服务。

#### 10. 售后回购、销售退回和质保：看客户是否真的取得控制权

售后回购条款是收入确认中的典型陷阱。企业销售商品后，如果同时承诺或有义务回购，要判断客户是否真正取得控制权。

如果回购安排使客户不能主导商品使用，交易可能不是销售，而可能是融资安排或租赁安排。如果回购条款只是质保属性，触发条件偏质量或功能缺陷，且客户没有重大经济动因要求回购，则可能更接近附有销售退回条款的销售。

CPA-ZH 的骨科手术导航设备案例就体现了这一点。设备销售附带回购条款，不能直接说“有回购就不能确认收入”，也不能说“已交付验收就一定确认全部收入”。要判断回购条款实质：是保护客户免受质量缺陷影响，还是让客户保留把设备退回给企业的实质权利，甚至让企业继续承担商品主要风险。

销售退回则要在确认收入时估计预期退回，确认退款负债，并相应确认收回商品权利相关资产或调整成本。估计要有历史退货率、产品质量、客户结构、期后退货等证据支持。

质保也要区分保证类质保和服务类质保。保证类质保是保证商品符合约定规格，通常按或有事项等处理相关预计负债；服务类质保向客户提供额外服务，可能构成单项履约义务并分摊交易价格。

#### 11. 海外销售：出口不等于收入完成

海外销售中，企业常把报关、提单、装船、出口日期作为收入确认节点。但这些证据只说明货物流转，不必然说明控制权已经转移。

需要继续看：

- 贸易术语下风险和控制权何时转移；
- 客户是否有验收权；
- 商品是否高度定制；
- 安装调试是否关键；
- 尾款是否取决于最终客户验收；
- 货权单据是否已交付；
- 是否存在退货、换货、回购、补偿安排；
- 境外客户是否真实存在并具备付款能力。

对于定制化产品出口，如果供货部分和组装调试可以明确区分，供货部分在交付时已转移控制权，调试只是附带服务，则供货收入和调试收入分拆可能合理。但如果产品未调试前不能使用，最终客户验收是实质控制权转移条件，就不能为了提前确认收入而人为拆分。

#### 12. 收入审计证据链：合同、履约、结算、回款、期后五件套

收入审计不能只查发票。发票是税务和结算证据，不一定证明履约完成。

更完整的证据链包括：

- 合同和补充协议：确认交易条款、履约义务、验收、退货、回购、付款条件。
- 订单和客户确认：确认客户需求真实。
- 发货、物流、报关、提单、签收：确认商品流转。
- 验收、上线、服务记录、调试报告：确认控制权或服务成果。
- 结算单、发票、回款、期后回款：确认收款权和商业真实性。
- 期后退货、红字发票、销售折让：识别收入转回风险。
- 函证和访谈：从客户侧验证交易真实性和余额。
- 毛利率、单价、客户集中度、期末集中确认：识别异常。

收入错报往往不是单一凭证能发现的，而是证据之间不一致：合同说需验收，收入凭发货确认；客户说未上线，企业说服务已完成；期后大量退货，年末收入却确认充分；回款来自第三方，合同客户却不同。

### 示例说明

#### 示例1：设备已交付，但回购条款需要实质判断

A 公司向客户销售设备，客户再将设备出租给医院使用。合同约定如果因设备功能原因导致项目终止，A 公司需回购设备。

判断时不能简单套公式。要问：

- 回购触发条件是质量/功能缺陷，还是客户可自由要求回购？
- 客户是否有重大经济动因行使回购权？
- 设备交付后客户是否能自主使用、出租或处置？
- 回购价格是否接近原售价、固定价格还是公允价值？
- 回购安排是否使 A 公司继续承担设备主要风险？

如果回购条款更像质保或销售退回安排，客户没有重大经济动因要求回购，且控制权已转移，可按附有销售退回条款的销售处理，确认预期有权收取的收入，并对预期退回确认相关负债。若回购安排实质上限制客户取得控制权，则可能不能按普通销售确认。

#### 示例2：海外定制产品供货和调试能不能拆分

B 公司向海外客户销售定制化产品，并提供组装调试服务。原合同约定最终客户完成组装调试后支付尾款，后续补充协议将合同拆分为供货部分和调试服务。

判断不能只看补充协议。要看：

- 产品出厂后是否具备独立使用价值；
- 客户是否能从供货本身受益；
- 调试是否改变产品核心功能；
- 供货和调试是否可分别定价和验收；
- 尾款条件是付款安排还是控制权转移条件；
- 实际执行是否按补充协议分开履约。

如果供货部分已独立交付并转移控制权，调试只是附带服务，则分拆确认有一定基础。若调试是产品达到合同功能的关键步骤，未调试前客户不能受益，则供货和调试可能构成一项履约义务，应等控制权转移条件满足后确认收入。

#### 示例3：预收款不是收入

电商平台销售预付卡，客户先付款，未来持卡消费。企业收到款项时不能直接确认收入，因为企业还没有向客户转让商品或服务。此时更像合同负债。只有客户消费、商品或服务控制权转移，企业才根据履约情况确认收入。

如果预付卡存在到期未使用金额，还要判断客户是否会行使权利、未行使权利金额是否可合理估计，以及何时确认相关收入。不能把“钱已经收到”当成收入确认理由。

### 记忆辅助

#### 收入五步法判断表

| 步骤 | 核心问题 | 典型证据 | 常见错法 |
|---|---|---|---|
| 识别合同 | 合同是否真实、可执行、有商业实质 | 合同、订单、客户确认、审批记录 | 有合同就确认收入 |
| 识别履约义务 | 承诺的商品或服务是否可明确区分 | 合同条款、技术方案、客户受益方式 | 一份合同一项履约义务 |
| 确定交易价格 | 企业预期有权收取多少对价 | 价格条款、返利、退货、罚款、融资安排 | 合同总价直接等于收入 |
| 分摊交易价格 | 多项义务如何分配价格 | 单独售价、报价单、市场价格 | 随意把价格分给已完成部分 |
| 履约时确认收入 | 控制权何时转移 | 发货、签收、验收、上线、服务记录 | 开票或收款即确认收入 |

#### 合同资产、应收账款、合同负债对比表

| 项目 | 企业状态 | 收款权/履约状态 | 报表直觉 | 易混点 |
|---|---|---|---|---|
| 应收账款 | 已履约 | 无条件收款权 | 别人欠我钱 | 不能把仍需继续履约的权利列为应收 |
| 合同资产 | 已部分或全部履约 | 收款权仍有条件 | 我做了，但还没到无条件收款 | 也要考虑减值 |
| 合同负债 | 已收款或有权收款 | 尚未履约 | 我收了钱，但还欠客户 | 预收款不能直接进收入 |

#### 时点与时段确认对比表

| 判断 | 某一时点 | 某一时段 |
|---|---|---|
| 核心 | 某个时点客户取得控制权 | 履约过程中客户逐步取得利益或控制成果 |
| 常见证据 | 交付、验收、货权、风险转移 | 服务记录、进度确认、客户控制在建资产、收款权 |
| 常见业务 | 普通商品销售、标准化软件交付 | 运输服务、持续服务、部分定制开发 |
| 易错点 | 发货不一定等于控制权转移 | 做了成本不一定能按进度确认 |

应收无条件，合同资产有条件，预收未履约是负债。

#### 易错警示卡

| 易错说法 | 为什么错 | 正确理解 |
|---|---|---|
| “开票了就能确认收入” | 发票不代表控制权转移 | 看客户是否取得控制权 |
| “收到钱就是收入” | 可能只是合同负债 | 履约后才确认收入 |
| “发货了就一定确认收入” | 可能仍需验收、调试或保留控制 | 看合同条款和客户接受 |
| “有回购条款就一定不能确认收入” | 回购可能是质保或销售退回属性 | 看回购实质和客户经济动因 |
| “合同拆分了就能分开确认” | 补充协议不能替代履约义务判断 | 看商品服务是否可明确区分 |
| “平台交易都按总额” | 可能只是代理人 | 看转让前是否控制指定商品或服务 |

### 本章小结

1. 收入确认的核心是客户取得控制权，而不是开票、收款或形式发货。
2. 五步法每一步都可能导致收入金额、时点或列报错误。
3. 履约义务拆分要看商品或服务是否可明确区分，不能为了提前确认收入而人为拆分。
4. 时点确认和时段确认的区别在于客户取得控制权的方式不同。
5. 合同资产、应收账款、合同负债分别对应有条件收款权、无条件收款权和未履约义务。
6. 可变对价、重大融资成分、主要责任人与代理人、售后回购和销售退回都是收入高风险判断点。
7. 收入审计应把合同、履约、结算、回款和期后事项串成证据链。

### 易混概念总对比

| 概念A | 概念B | 核心区别 |
|---|---|---|
| 控制 | 重大影响 | 控制是主导相关活动，重大影响是参与决策 |
| 共同控制 | 重大影响 | 共同控制要求相关活动一致同意，重大影响不要求共同决定 |
| 个别报表 | 合并报表 | 个别报表看单个法律主体，合并报表看集团整体 |
| 成本法 | 权益法 | 成本法不随日常净资产变动调整，权益法反映被投资单位净资产变动份额 |
| 公允价值可靠 | 商业实质 | 前者是金额可靠，后者是现金流风险、时间、金额是否实质改变 |
| 保护性权利 | 实质性权利 | 保护性权利保护利益，通常不赋予控制；实质性权利可能影响控制 |
| 结构化主体 | 普通经营主体 | 前者通常不能只靠表决权判断控制 |
| 摊余成本 | 公允价值 | 前者按实际利率法反映合同现金流量，后者反映计量日市场价格 |
| FVOCI 债务工具 | FVOCI 权益工具 | 债务工具利息和减值进损益且处置可转损益；权益工具处置通常转留存收益 |
| 金融负债 | 权益工具 | 核心看发行人是否能无条件避免交付现金或其他金融资产 |
| 合同资产 | 应收账款 | 合同资产收款权有条件，应收账款是无条件收款权 |
| 合同负债 | 收入 | 合同负债是已收款但未履约，收入是履约义务已经满足 |
| 主要责任人 | 代理人 | 前者转让前控制商品或服务，后者只是安排他人提供商品或服务 |
| 时点确认收入 | 时段确认收入 | 前者在某一时点转移控制权，后者在履约过程中客户逐步取得利益或控制成果 |

| 计量 | 判断事项以什么金额进入财务报表。 | 第1章 |
| 列报 | 判断事项在报表中如何呈现。 | 第1章 |
| 披露 | 判断附注中需要说明的重大判断、风险和不确定性。 | 第1章 |
| 控制 | 投资方拥有权力、享有可变回报，并能运用权力影响回报。 | 第2章、第3章 |
| 共同控制 | 合同约定的共同控制，相关活动需共同控制方一致同意。 | 第2章 |
| 重大影响 | 对被投资单位财务和经营政策有参与决策权但不控制或共同控制。 | 第2章 |
| 成本法 | 长期股权投资后续计量方法之一，一般不随被投资单位日常净资产变动调整。 | 第2章 |
| 权益法 | 根据被投资单位净资产变动中投资方享有份额调整投资账面价值的方法。 | 第2章 |
| 合并范围 | 应纳入合并财务报表的主体范围。 | 第3章 |
| 可变回报 | 投资方因参与被投资方而取得的不固定收益或承担的风险。 | 第3章 |
| 结构化主体 | 表决权或类似权利通常不是决定控制主导因素的主体。 | 第3章 |
| 非控制性权益 | 子公司权益中不归属于母公司股东的部分。 | 第3章 |
| 金融资产 | 企业收取现金或其他金融资产、交换金融工具等合同权利。 | 第4章 |
| 金融负债 | 企业交付现金或其他金融资产等合同义务。 | 第4章 |
| 权益工具 | 扣除所有负债后表明对企业资产剩余权益的合同。 | 第4章 |
| 业务模式 | 企业管理金融资产以产生现金流量的方式，如收息、出售或两者兼有。 | 第4章 |
| 合同现金流量特征 | 金融资产合同现金流量是否仅为本金和利息支付等特征。 | 第4章 |
| 摊余成本 | 初始确认金额经本金偿还、实际利率法摊销和减值调整后的金额。 | 第4章 |
| 实际利率法 | 用实际利率计算金融资产利息收入或金融负债利息费用的方法。 | 第4章 |
| 公允价值 | 市场参与者在计量日有序交易中出售资产可收到或转移负债需支付的价格。 | 第4章 |
| 预期信用损失 | 以违约风险为权重的信用损失加权平均金额，需考虑前瞻性信息。 | 第4章 |
| 控制权转移 | 客户取得主导商品或服务使用并获得几乎全部经济利益的能力。 | 第5章 |
| 履约义务 | 企业向客户转让可明确区分商品或服务的承诺。 | 第5章 |
| 交易价格 | 企业因向客户转让商品或服务而预期有权收取的对价金额。 | 第5章 |
| 合同资产 | 企业已向客户转让商品或服务而有权收取对价，但该权利取决于时间流逝以外的其他因素。 | 第5章 |
| 合同负债 | 企业已收或应收客户对价而应向客户转让商品或服务的义务。 | 第5章 |
| 应收账款 | 企业拥有的无条件收款权。 | 第5章 |
| 可变对价 | 因折扣、返利、退款、奖励、罚款等导致金额不固定的对价。 | 第5章 |
| 主要责任人 | 在商品或服务转让给客户前控制该商品或服务的一方，通常按总额确认收入。 | 第5章 |
| 代理人 | 安排他方向客户提供商品或服务的一方，通常按净额确认收入。 | 第5章 |
