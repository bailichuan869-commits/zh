# workspace 目录说明

`workspace/` 用来存放当前工作过程中的辅助材料，不作为主知识库或正式资料库。

## 子目录

- `docs/`
  - 工作区说明、检查记录、安装审计、复核记录等过程文档。
- `outputs/`
  - 一次性生成结果或人工交付物。
- `tmp/`
  - 临时文件、旧临时目录、程序运行中间产物。

## 使用建议

- 需要长期维护的知识内容，不放在这里，放入 `knowledge-base/`。
- 法规原文和法规整理稿，不放在这里，放入 `regulations/`。
- 已经完成且不再活跃处理的项目，移入 `archived/`。
