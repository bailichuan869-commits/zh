# VBA第07课：把按钮收进菜单

## 这一节要做什么

前面我们已经在功能区里添加过大按钮和小按钮。

当按钮越来越多时，如果全部平铺在功能区上，界面会变得很挤，也不方便用户查找。

这一节我们开始使用“菜单”控件，把一类功能收进一个下拉菜单里。

本节案例是：

```text
新建一个“公式处理”菜单
  ↓
把“添加 ROUND”放进菜单
  ↓
在菜单里新增“添加 IFERROR”
  ↓
让 AI 实现 IFERROR 功能
```

## 本节你会学到

- 菜单控件适合解决什么问题。
- 怎么在功能区设计器中添加菜单。
- 怎么把按钮放到菜单里面。
- 怎么给菜单和按钮配置图标。
- 怎么使用阿里巴巴矢量图标库下载 PNG 图标。
- 新增按钮后，为什么要重新保存并导出设计。
- 怎么确认 AI 已经看到新增按钮的需求和回调信息。
- 怎么让 AI 实现“添加 IFERROR”按钮。

## 为什么要用菜单

如果功能区里只有一两个按钮，可以直接放在分组里。

但当按钮越来越多，例如：

- 添加 ROUND；
- 添加 IFERROR；
- 添加 SUM；
- 添加 VLOOKUP；
- 其他公式处理工具；

如果全部铺开，会让功能区变得很乱。

菜单的作用是把同一类功能收起来。

例如：

```text
公式处理
  添加 ROUND
  添加 IFERROR
```

这样界面会更清爽，也更像一个真正的工具箱。

## 第一步：打开项目

打开之前创建的功能区设计器项目。

你应该已经有一个分组，里面放过：

- 一个大按钮；
- 一个小按钮；
- 已经实现过的“自动排序”；
- 已经实现过的“添加 ROUND”。

这一节要在原来的项目基础上继续添加菜单。

## 第二步：添加菜单控件

在设计器里添加一个“菜单”控件。

菜单是可以下拉的。

添加后，选中这个菜单，把它改名为：

```text
公式处理
```

这个菜单后面专门用来收纳公式相关的按钮。

## 第三步：把添加 ROUND 放进菜单

之前“添加 ROUND”可能是一个单独按钮。

现在可以把它移动到“公式处理”菜单下面。

层级变成：

```text
公式处理
  添加 ROUND
```

这样用户点击“公式处理”菜单后，才会看到“添加 ROUND”。

## 第四步：在菜单里新增添加 IFERROR

选中“公式处理”菜单，再在菜单里面添加一个按钮。

按钮名称：

```text
添加 IFERROR
```

`IFERROR` 是 Excel 里的公式函数，常用于处理错误值。

例如：

```excel
=IFERROR(A1/B1,"")
```

它的意思是：

- 如果 `A1/B1` 正常计算，就返回计算结果；
- 如果计算结果是错误值，就返回空值。

本节我们要让按钮对选中的公式添加 `IFERROR` 包裹。

## 第五步：给菜单和按钮配置图标

设计器里可以给菜单或按钮选择图标。

你可以先用内置图标。

比如搜索：

```text
formula
```

选择一个和公式相关的图标。

对于“公式处理”菜单，可以选公式相关图标。

对于“添加 ROUND”和“添加 IFERROR”，也可以继续使用公式类图标。

图标不用一开始就追求完美，先保证功能跑通。

## 使用自定义图标

如果觉得内置图标不够好看，可以使用外部图标。

可以搜索：

```text
阿里巴巴矢量图标库
```

进入图标库后，搜索你想要的关键词。

例如：

```text
公式
猫
工具
数据
```

下载 PNG 图标时，可以先选：

```text
64 x 64
```

一般情况下：

- 大图标用 64 像素就够了；
- 小图标通常会显示得更小；
- PNG 更适合直接导入设计器使用。

下载后，在设计器里选择图片，就可以把自定义图标放到按钮上。

## 第六步：填写 IFERROR 按钮说明

新增按钮后，要给它写清楚提示和 AI 功能说明。

短提示可以写：

```text
添加 IFERROR
```

详细提示可以写：

```text
对选中的区域添加 IFERROR 公式，遇到错误则返回空值。
```

给 AI 的功能说明可以写：

```text
对选中的区域添加 IFERROR 公式。
如果单元格为空，则跳过。
如果公式计算错误，则返回空值。
不要影响未选中的区域。
```

这一步很重要。

后面 AI 要根据这里的说明，知道这个按钮到底要实现什么功能。

## 第七步：保存并导出设计

配置完成后，先保存项目。

然后点击：

```text
导出设计
```

注意：

> 导出设计前，一定要关闭 `final.xlsm`。  
> 如果 `final.xlsm` 正在 Excel 里打开，设计器可能无法成功导出。

导出后，新的菜单、按钮、回调信息都会写入最终工作簿和项目说明文件。

## 第八步：确认按钮信息已经写入项目手册

导出完成后，用 VS Code 打开项目文件夹。

检查：

```text
CLAUDE.md
AGENTS.md
```

在文件下方的功能清单里，应该能看到新增的“添加 IFERROR”按钮。

你需要重点确认：

- 按钮名称是不是“添加 IFERROR”；
- 它是否在“公式处理”菜单下面；
- 控件类型是不是 `button`；
- 回调函数名称是否已经生成；
- 核心过程名称是否已经生成；
- 功能需求是否包含刚才写的 IFERROR 说明。

只要这些信息存在，AI 就能知道：

```text
这个按钮在哪里
它叫什么
它的回调是什么
它要实现什么功能
```

## 第九步：让 AI 实现添加 IFERROR

确认 `final.xlsm` 已经关闭。

在项目根目录启动 Claude Code 或 WorkBuddy。

可以这样说：

```text
帮我实现“添加 IFERROR”功能。
先用 plan 模式确认你的实现计划。
```

AI 的计划里应该能看到：

- 它识别到了“添加 IFERROR”按钮；
- 它知道这个按钮位于“公式处理”菜单下；
- 它知道按钮对应的回调函数；
- 它知道核心过程当前还没有实现；
- 它会参考之前“添加 ROUND”的实现方式；
- 它会遍历当前选区；
- 它会跳过空单元格；
- 它会把公式包裹成 `IFERROR(...,"")`；
- 它会构建并验证 `final.xlsm`。

确认计划没问题后，让 AI 开始执行。

## 第十步：手动验证 IFERROR 功能

AI 完成后，打开：

```text
workbooks/final.xlsm
```

在单元格里输入一个会报错的公式，例如：

```excel
=1/0
```

选中这个单元格，点击：

```text
公式处理 → 添加 IFERROR
```

正常情况下，公式会被改成类似：

```excel
=IFERROR(1/0,"")
```

这个公式再遇到错误时，就会返回空值。

你还可以按：

```text
Alt + F11
```

进入 VBA 编辑器，检查代码是否已经写入 `AI_Generated` 模块。

同时确认：

- 回调函数存在；
- 核心函数存在；
- 按钮点击后能运行到核心函数；
- 功能效果正确。

## 本节完整流程

以后按钮多了，可以按这个流程整理：

```text
新增菜单
  ↓
把同类按钮放进菜单
  ↓
新增菜单内按钮
  ↓
配置名称、图标、提示、AI 功能说明
  ↓
关闭 final.xlsm
  ↓
保存并导出设计
  ↓
检查 CLAUDE.md / AGENTS.md 是否出现新按钮
  ↓
让 AI 实现功能
  ↓
打开 final.xlsm 手动验证
```

## 常见问题

### 菜单里看不到按钮

检查按钮是不是放在了菜单下面。

菜单和按钮是有层级关系的：

```text
菜单
  按钮
```

如果按钮不在菜单下面，就不会出现在这个菜单里。

### AI 没识别到新增按钮

先检查是否已经重新导出设计。

如果只在设计器里加了按钮，但没有导出，`CLAUDE.md` / `AGENTS.md` 里可能还没有这个按钮信息。

### 导出设计失败

先确认 `final.xlsm` 是否正在打开。

如果打开了，先关闭，再重新导出。

### IFERROR 包裹后效果不对

检查几类情况：

- 单元格是不是空的；
- 单元格是不是公式；
- 公式是否已经被 `IFERROR` 包过；
- 返回值是不是你想要的空值 `""`。

## 本节记住这四点

1. 按钮多了以后，要用菜单把同类功能收纳起来。
2. 菜单里面可以继续放按钮。
3. 新增按钮后，一定要写清楚给 AI 的功能说明。
4. 每次改完界面，都要保存并导出设计，再让 AI 实现功能。

## 课后练习

在“公式处理”菜单里继续新增一个按钮：

```text
添加 SUM
```

给 AI 的功能说明可以写：

```text
对当前选中的每一行数据，在右侧空白列添加 SUM 求和公式。
空行跳过。
不要覆盖已有内容。
运行前提示用户确认。
```

完成标准：

1. 按钮放在“公式处理”菜单下面。
2. 填写短提示、详细提示和给 AI 的功能说明。
3. 保存并导出设计。
4. 确认 `CLAUDE.md` / `AGENTS.md` 里能看到按钮。
5. 让 AI 用 plan 模式实现。
6. 打开 `final.xlsm` 手动验证。
