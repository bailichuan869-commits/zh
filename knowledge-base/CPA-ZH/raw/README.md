# CPA-ZH 原始资料区

本目录用于保存不可变的原始资料。建议按以下目录放置：

- `laws/`：法律法规原文或官方发布件
- `standards/`：企业会计准则、中国注册会计师执业准则、应用指南、解释等
- `policies/`：行业政策性文件
- `ethics/`：职业道德、独立性准则与应用指南
- `practice/`：审计实务操作资料、底稿样例、程序模板
- `cases/`：监管案例、审计案例、综合执业能力案例
- `tools/`：RPA、数据清洗、智能化财务应用等工具资料
- `outlines/`：知识范围、学习清单、目录型材料
- `assets/`：图片、表格、附件等
