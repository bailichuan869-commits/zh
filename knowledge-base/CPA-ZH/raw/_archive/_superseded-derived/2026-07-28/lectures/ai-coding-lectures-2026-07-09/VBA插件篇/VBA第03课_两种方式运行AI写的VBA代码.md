# VBA第03课：两种方式运行 AI 写的 VBA 代码

## 这一节要做什么

这一节先不做加载项。我们先用最简单的方式，让 AI 写一段 VBA，然后把它放进 Excel 里跑起来。

这节课你会完成一个小功能：

> 选中一批单元格后，点击按钮，给有值的单元格自动加连续编号。

这一节的重点不是写复杂代码，而是打通最小闭环：

```text
描述需求 → AI 写 VBA → 放进 Excel → 运行 → 保存为 .xlsm
```

## 本节你会学到

- 怎么让 AI 生成一个 VBA 模块文件。
- `.bas` 文件是什么。
- 怎么把 AI 写的代码放进 VBA 编辑器。
- `Sub` 和 `Function` 在运行入口上的区别。
- 怎么用工作表按钮运行宏。
- 怎么用快速访问工具栏运行宏。
- 为什么必须保存成 `.xlsm`。

## 本节案例：连续编号

准备一列或一片单元格，里面有一些文本。

我们要实现：

```text
选中单元格区域后，对有值的单元格依次添加序号。
空单元格跳过。
```

效果示例：

| 原始内容 | 处理后 |
| --- | --- |
| 张三 | 1. 张三 |
| 李四 | 2. 李四 |
| 王五 | 3. 王五 |

## 第一步：创建练习文件

先新建一个文件夹，例如：

```text
VBA study
```

再新建一个 Excel 文件，例如：

```text
第一个功能按钮.xlsx
```

注意：

- 一开始是 `.xlsx` 没关系。
- 只要后面加入 VBA 代码，最后就要另存为 `.xlsm`。
- 如果你用 WPS，并且 `Alt + F11` 打不开 VBA，通常需要安装 WPS 的 VBA 插件，然后重启 WPS。

## 第二步：让 AI 写 VBA

在刚才的文件夹里用 VS Code 打开，然后启动 Claude Code 或 WorkBuddy。

可以把下面这段需求发给 AI：

```text
我要写一个 VBA 代码。

需求：
对选中的单元格进行编辑。
如果单元格有值，则在值的前面增加序号。
如果单元格为空，则跳过。

细节：
1. 序号格式为“1. 原值”。
2. 遍历顺序为先行后列。
3. 如果单元格已经有类似序号格式，请替换旧序号，不要叠加。
4. 写成标准模块里的 Public Sub 过程。
5. 输出一个 .bas 模块文件，方便导入到 VBA。
```

AI 可能会追问一些细节，例如：

- 序号格式用 `1. 值` 还是 `1、值`；
- 先按行编号还是先按列编号；
- 已经有编号时是跳过、替换还是叠加。

这些问题都可以按你的真实需求回答。

## 第三步：把代码放进 VBA

打开 Excel，按：

```text
Alt + F11
```

进入 VBA 编辑器。

右键当前工作簿：

```text
插入 → 模块
```

接下来有两种方式。

### 方式一：复制粘贴

打开 AI 生成的 `.bas` 文件，把里面的代码复制出来，粘贴到刚才新建的模块里。

### 方式二：导入 .bas 文件

在 VBA 编辑器左侧项目窗口中右键：

```text
导入文件 → 选择 AI 生成的 .bas 文件
```

`.bas` 就是 VBA 的标准模块文件。

如果导入后中文乱码，可以让 AI 帮你把 `.bas` 转成适合 VBA 导入的编码，再重新导入。

## 第四步：先手动运行一次

在 AI 生成的代码里，找到主过程。

它通常长这样：

```vb
Public Sub AddNumberToSelection()
    ' 这里是具体逻辑
End Sub
```

把光标放到这个 `Sub` 过程里面，点击运行按钮，或按：

```text
F5
```

这里要注意：

- `Sub` 通常是可以直接运行的过程。
- `Function` 常常是辅助函数，用来被 `Sub` 调用。
- 你真正要运行的入口，一般是 `Public Sub ... End Sub`。

先手动运行一次，是为了确认代码本身能工作。

## 第五步：用工作表按钮运行宏

手动运行太麻烦了。更适合普通使用者的方式，是在工作表上放一个按钮。

回到 Excel，打开：

```text
开发工具 → 插入 → 按钮（窗体控件）
```

在工作表上画一个按钮。

Excel 会弹出“指定宏”，选择刚才的主过程。

之后你就可以：

```text
选中区域 → 点击按钮 → 自动编号
```

如果以后想换按钮绑定的宏：

```text
右键按钮 → 指定宏
```

如果宏列表里出现很多过程，通常是因为你同时打开了其他带宏的工作簿或加载项。关闭其他文件后，列表会变少。

## 第六步：用快速访问工具栏运行宏

还有一种更轻量的方式，是把宏放到 Excel 顶部的快速访问工具栏。

操作路径：

```text
快速访问工具栏 → 其他命令 → 从下列位置选择命令：宏
```

找到刚才的宏，点击添加。

你还可以点击“修改”，给它换一个图标。

如果这个宏在快速访问工具栏排第一个，就可以按：

```text
Alt + 1
```

直接运行。

这种方式适合自己常用的小工具。

## 第七步：保存为 .xlsm

这是本节最容易踩坑的地方。

如果当前文件还是 `.xlsx`，你按保存时，Excel 会提示类似：

```text
无法在未启用宏的工作簿中保存 VBA 项目。
```

这时不要直接点“是”。

如果继续保存为 `.xlsx`，VBA 代码可能会被删除。

正确做法是：

```text
另存为 → Excel 启用宏的工作簿（.xlsm）
```

常见格式区别：

| 格式 | 是否能保存 VBA | 说明 |
| --- | --- | --- |
| `.xlsx` | 不能 | 普通工作簿 |
| `.xlsm` | 能 | 启用宏工作簿，最常用 |
| `.xlsb` | 能 | 二进制格式，体积可能更小，但不如 `.xlsm` 直观 |

保存后，关闭再重新打开，按 `Alt + F11` 检查代码是否还在。

## 本节记住这三种运行方式

1. 在 VBA 编辑器里，把光标放进 `Sub`，点击运行或按 `F5`。
2. 在工作表上画一个按钮，把按钮绑定到宏。
3. 把宏添加到快速访问工具栏，用图标或 `Alt + 数字` 运行。

这三种方式都不需要正式做加载项，适合先把 AI 写出来的小功能快速用起来。

## 课后练习

找一个简单功能，让 AI 写成 VBA，并自己跑通。

可以选：

- 连续编号；
- 批量加边框；
- 自动调整列宽；
- 给选区添加 `ROUND` 公式。

完成标准：

1. AI 生成 `.bas` 或 VBA 代码。
2. 代码能放进模块。
3. 能手动运行。
4. 能绑定到工作表按钮。
5. 能添加到快速访问工具栏。
6. 文件保存为 `.xlsm` 后，关闭重开仍然有效。
