# 法规模块说明

本目录已从顶层 `regulations/` 归档到 `archived/regulations/`，后续默认不继续维护，仅作为历史法规资料留存。

## 目录结构

- `markdown/`
  - 存放整理后的法规 Markdown 版本，便于检索、引用和继续加工。
- `source_docs/`
  - 存放法规原始文件，例如 `.docx`，便于回溯版本来源。

## 当前收录

- `中华人民共和国会计法`
- `中华人民共和国注册会计师法`
- `中华人民共和国公司法`
- `中华人民共和国证券法`

## 使用建议

- 新增法规 Markdown 文件放入 `markdown/`
- 新增原始法规文档放入 `source_docs/`
- 如果同一法规存在多个历史版本，建议在文件名中保留日期
