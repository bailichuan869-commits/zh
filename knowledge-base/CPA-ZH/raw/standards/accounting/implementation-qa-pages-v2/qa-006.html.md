# 问：企业对于当期直接减免的增值税，应当如何进行会计处理？

答：对于当期直接减免的增值税，企业应当根据《增值税会计处理规定》（财会〔 2016 〕 22 号）的相关规定进行会计处理，借记“应交税金——应交增值税（减免税款）”科目，贷记“其他收益”科目。
