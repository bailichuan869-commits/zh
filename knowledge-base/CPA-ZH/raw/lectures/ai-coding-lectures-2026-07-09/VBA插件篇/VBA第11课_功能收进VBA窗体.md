# VBA第11课：功能收进 VBA 窗体

## 这一节要做什么

前面我们把很多控件都放在功能区上：

- 下拉框；
- 输入框；
- 复选框；
- 按钮；
- 菜单。

这样虽然能用，但如果控件越来越多，功能区会变得很臃肿。

这一节讲另一种组织方式：

```text
功能区只放一个按钮
  ↓
点击按钮弹出 VBA 窗体
  ↓
把复杂控件放到窗体里
```

本节案例是把之前的“插入行列”功能收进一个 VBA 窗体。

## 本节你会学到

- 什么是 VBA 窗体，也就是 `UserForm`。
- 为什么复杂功能不一定都要堆在功能区上。
- 怎么让 AI 创建一个插入行列窗体。
- 窗体里可以放哪些控件。
- 遇到 VBA 编码乱码时怎么处理。
- 怎么手动调整窗体布局。
- 什么是模态窗体和非模态窗体。
- 怎么让窗体打开后仍然可以编辑单元格。

## 使用前注意版本

这一节需要功能区设计器支持窗体相关能力。

请先检查版本。

要求：

```text
功能区设计器 1.5 或以上
```

如果版本太低，可能无法按本节流程生成和注入窗体。

## 为什么要用窗体

之前的“插入行列”功能，功能区上可能有：

- 行列下拉框；
- 数量输入框；
- 复制插入复选框；
- 插入按钮。

如果每个功能都这样放一堆控件，功能区很快会很挤。

更清爽的方式是：

```text
功能区：插入行列按钮
窗体中：行列选择、数量输入、复制插入、确定按钮
```

也就是说：

> 功能区负责入口，窗体负责复杂交互。

## 第一步：在功能区添加入口按钮

打开设计器项目。

新增一个分组，也可以使用已有分组。

添加一个按钮，名称可以写：

```text
插入行列
```

给 AI 的功能说明可以写：

```text
打开一个插入行列的 VBA 窗体。
这个窗体中有下拉框，可以选择行或列。
有数量输入框。
有复制插入的复选框。
整体逻辑和之前功能区上的插入行列逻辑一致。
```

配置好后，保存并导出设计。

## 第二步：让 AI 规划窗体

用 VS Code 打开项目根目录。

启动 AI 终端。

可以这样说：

```text
帮我实现“插入行列”的 VBA 窗体。
先用 plan 模式，先规划，不要直接写代码。
```

AI 的计划里会出现一个关键词：

```text
UserForm
```

以后看到 `UserForm`，就知道这是 VBA 窗体。

它通常会规划：

- 创建一个窗体；
- 在窗体里放下拉框；
- 在窗体里放数量输入框；
- 在窗体里放复制插入复选框；
- 放确定和取消按钮；
- 点击确定后执行插入行列逻辑；
- 尽量复用之前功能区版本的核心代码。

## 第三步：理解窗体和功能区的关系

AI 可能会把窗体和功能区做成共享状态。

例如：

- 功能区里的“行列”状态；
- 功能区里的“数量”状态；
- 功能区里的“复制插入”状态；
- 窗体里的这些控件；

都使用同一套变量或同一套核心函数。

这样做的好处是：

> 功能区和窗体只是不同入口，底层逻辑可以复用。

你不需要太纠结具体代码细节，但要知道它在复用之前的插入逻辑。

## 第四步：查看项目结构变化

AI 实现后，项目中可能会出现：

```text
src/forms/
```

里面放的是 VBA 窗体相关文件。

你可能会看到类似：

```text
InsertRowsColumnsForm.frm
InsertRowsColumnsForm.frx
```

可以简单理解为：

- `.frm`：窗体代码和控件定义；
- `.frx`：窗体相关的二进制资源。

这些文件一般不需要手动编辑，让 AI 注入即可。

## 第五步：处理乱码问题

有时打开 `final.xlsm` 测试时，VBA 会报错，或者窗体/代码里出现乱码。

这通常是编码问题。

VBA 对模块文件和窗体文件的编码比较敏感。

如果 AI 生成的文件是 UTF-8，而 VBA 导入时需要兼容本地编码，就可能乱码。

遇到这种情况，不要慌。

直接把报错或乱码内容复制给 AI，说：

```text
出现乱码了，请修复 VBA 导入文件的编码，再重新注入。
```

AI 通常会把相关 `.bas` / `.frm` 文件转换成 VBA 更容易识别的编码，然后重新注入。

## 第六步：测试窗体能否打开

打开：

```text
workbooks/final.xlsm
```

进入自定义功能区。

点击：

```text
插入行列
```

正常情况下，会弹出一个 VBA 窗体。

窗体里应该有：

- 行列选择；
- 数量输入；
- 复制插入；
- 确定按钮；
- 取消按钮。

测试：

1. 在工作表中输入一个参考数字，例如 `555`。
2. 打开窗体。
3. 选择插入行。
4. 数量输入 `5`。
5. 点击确定。

如果成功插入 5 行，说明窗体逻辑已经跑通。

## 第七步：手动调整窗体布局

第一次生成的窗体可能比较丑。

这是正常的。

VBA 自带窗体本身就比较朴素，很难做成现代 UI。

你可以按：

```text
Alt + F11
```

进入 VBA 编辑器。

在左侧找到窗体，双击打开。

你会看到窗体设计界面。

可以手工调整：

- 把窗体拉大；
- 调整按钮位置；
- 调整输入框宽度；
- 增加分组框；
- 调整控件间距；
- 修改控件显示文字。

## 常见窗体控件

VBA 窗体里也有一些常见控件。

| 控件 | 用途 |
| --- | --- |
| Label | 文本标签，用来显示说明文字 |
| TextBox | 文本框，用来输入文本或数字 |
| ComboBox | 下拉/组合框，用来选择或输入 |
| CheckBox | 复选框，用来勾选选项 |
| Frame | 分组框，用来把控件框在一起 |
| CommandButton | 按钮，用来执行确定、取消等动作 |

例如可以加一个 `Frame`，标题写：

```text
插入行列
```

然后把行列选择、数量输入、复制插入这些控件放进去。

这样窗体会比一堆控件散在外面更清楚。

## 注意控件的 Name 和 Caption

在 VBA 窗体属性里，经常会看到两个类似的东西：

```text
Name
Caption
```

区别是：

| 属性 | 含义 |
| --- | --- |
| Name | 代码内部用的名称，不要随便乱改 |
| Caption | 显示给用户看的文字，可以修改 |

比如一个分组框的 `Caption` 可以改成：

```text
插入行列
```

但 `Name` 是代码识别它的名称，改错可能导致代码找不到控件。

## 第八步：理解模态窗体

第一次打开窗体时，你可能会发现：

> 窗体不关掉，就不能继续编辑工作表。

这种窗体叫：

```text
模态窗体
```

模态窗体会挡住当前 Excel 操作。

你必须先关闭窗体，才能继续选择单元格或编辑工作表。

这有时不是我们想要的。

例如插入行列工具，用户可能希望一边选单元格，一边调整窗体参数。

## 第九步：改成非模态窗体

如果你希望窗体打开后，还能继续操作 Excel，可以让 AI 修改为非模态窗体。

直接说：

```text
这个窗体我不想让它是模态的。
我需要一边编辑单元格，一边使用这个窗体。
请把它改成非模态窗体。
```

AI 通常会把窗体显示代码从类似：

```vb
UserForm.Show
```

改成：

```vb
UserForm.Show vbModeless
```

`vbModeless` 就表示非模态。

改完后再打开窗体，就可以一边操作窗体，一边选择或编辑工作表。

## 第十步：再验证一次

重新打开 `final.xlsm`。

点击“插入行列”按钮。

确认：

- 窗体能正常弹出；
- 可以切回工作表选择单元格；
- 可以在窗体中设置行列、数量、复制插入；
- 点击确定后能执行插入。

如果这些都正常，说明窗体入口已经可用。

## 关于用 AI 调整窗体布局

如果你使用的 AI 模型支持看图，可以截图发给它，让它帮你调整窗体布局。

例如：

```text
这是当前 VBA 窗体截图。
请帮我把控件布局整理得更清楚，按钮放到底部，输入项左对齐。
```

如果模型不支持图片，就可以用文字描述：

```text
把窗体宽度调大。
把确定和取消按钮放到底部右侧。
把行列、数量、复制插入放进一个 Frame，标题为“插入行列”。
```

VBA 窗体不用追求特别好看，重点是清楚、能用、不挡操作。

## 什么时候用窗体

适合用窗体的场景：

- 一个功能需要很多设置项；
- 功能区放不下太多控件；
- 需要在一个窗口里集中配置参数；
- 需要确定/取消这样的操作流程；
- 希望把复杂功能包装成一个入口按钮。

不一定要用窗体的场景：

- 只有一个简单按钮；
- 只是执行一个固定动作；
- 控件很少，放在功能区上更方便。

## 本节记住这五点

1. VBA 窗体叫 `UserForm`。
2. 功能区可以只放入口按钮，复杂控件放进窗体。
3. 窗体文件通常在 `src/forms/` 里，由 AI 生成和注入。
4. 遇到乱码，把报错或乱码内容发给 AI，让它修复编码。
5. 默认窗体可能是模态的，需要时可以改成 `vbModeless` 非模态。
