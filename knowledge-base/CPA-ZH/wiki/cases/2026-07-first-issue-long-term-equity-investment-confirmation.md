# A公司持有D公司长期股权投资转换为C公司投资的确认

## 一句话结论

个人意见：A 公司原持有 D 公司的长期股权投资转为对 C 公司的长期股权投资时，应按原账面价值结转，不宜按公允价值重新计量，也不应确认投资收益。

## 事实背景

A 公司为集团母公司，直接持有 D 公司 16.67% 股权，并通过子公司 B 间接持有 D 公司 83.33% 股权，因此控制 D 公司。C 公司也是 A 公司子公司，主营封装和测试业务；D 公司为 B 公司子公司，主营研发与小批量封装测试。

本次交易安排为 C 公司吸收合并 D 公司。交易前后主要变化如下：

| 主体 | 合并前 | 合并后 |
|---|---|---|
| A 公司 | 直接持有 D 公司 16.67% 股权；同时通过集团结构控制 D 公司 | 持有 C 公司 57% 股权，继续控制 C 公司 |
| B 公司 | 持有 D 公司 83.33% 股权，成本法核算并纳入合并范围 | 持有 C 公司 9% 股权，因具有重大影响改按权益法核算 |
| C 公司 | A 公司子公司 | 吸收合并 D 公司 |
| D 公司 | A 公司控制范围内孙公司 | 被 C 公司吸收合并 |

D 公司和 C 公司均构成业务，C 公司规模明显大于 D 公司。因吸收合并涉及外部少数股东，换股价格基于审计评估结果并经股东协商确定，价格具有公允性。

## 争议问题

吸收合并完成后，A 公司原持有 D 公司的长期股权投资转为对 C 公司的长期股权投资部分时：

1. 入账价值应按公允价值还是账面价值确定；
2. 是否应确认投资收益。

## 判断过程

### 1. 形式上可以联想到非货币性资产交换

A 公司原直接持有 D 公司股权，吸收合并后取得或增加对 C 公司的股权。站在 A 公司个别报表角度看，存在以一项长期股权投资转换为另一项长期股权投资的形式，因此需要考虑 [[concepts/accounting-standards/cas-07]] 的计量逻辑。

非货币性资产交换要以公允价值为基础计量，通常需要同时满足两个条件：

1. 交换具有商业实质；
2. 换入或换出资产的公允价值能够可靠计量。

本案中，换股价格经过审计评估和股东协商，公允价值可靠性较强。但这只解决了第二个条件，不能替代商业实质判断。

### 2. 商业实质判断是核心

商业实质的重点不在于交易价格是否公允，而在于交易是否实质改变企业未来现金流量的风险、时间分布或金额。

本案中，C 公司和 D 公司在吸收合并前均处于 A 公司控制范围内；吸收合并后，A 公司仍控制 C 公司，集团内部相关业务仍在 A 公司控制之下。A 公司原享有的对 D 公司经济利益，转换为通过 C 公司承载的经济利益，并未实质改变 A 公司对相关业务的控制和收益风险格局。

因此，A 公司层面更应将该事项理解为同一控制范围内的内部重组，而不是一次具有实质外部交换效果的资产处置。

### 3. 公允定价不等于确认处置收益

本案存在外部少数股东，换股价格需要公允，这是交易安排和少数股东保护的要求。但对 A 公司个别报表而言，公允定价并不当然导致原 D 公司股权视同对外处置并确认投资收益。

如果仅因评估价值公允就确认收益，容易把集团内部重组形成的估值差异提前计入损益，和实质重于形式及谨慎性原则不协调。

## 会计处理建议

A 公司个别报表中，对原持有 D 公司 16.67% 股权转为对 C 公司投资的部分，建议按原长期股权投资账面价值结转：

```text
借：长期股权投资——C公司
贷：长期股权投资——D公司
```

金额按 A 公司原持有 D 公司长期股权投资的账面价值确定，不确认投资收益。

如果实际换股金额、评估价值或工商登记资本份额与账面价值存在差异，应进一步分析差异的法律性质和权益归属。没有明确对外交易损益实质的，不宜简单计入投资收益。

## 审计关注点

| 关注点 | 审计动作 |
|---|---|
| 控制关系是否连续 | 获取吸收合并前后股权结构图、章程、董事会安排、表决权安排和合并范围判断底稿 |
| 是否属于同一控制下内部重组 | 核对 C、D 在交易前后是否均处于 A 公司控制范围，复核交易目的和重组方案 |
| 是否具有商业实质 | 分析 A 公司未来现金流量风险、时间分布、金额是否因转换发生实质变化 |
| 换股价格公允性 | 获取评估报告、审计报告、股东会或董事会决议、少数股东协商记录 |
| 个别报表与合并报表影响 | 区分 A 公司个别报表、B 公司个别报表、集团合并报表的不同会计后果 |
| 投资收益确认风险 | 检查是否存在通过内部重组确认收益或调节利润的风险 |

## 底稿留痕建议

1. 保存吸收合并协议、换股方案、股东会或董事会决议。
2. 保存交易前后股权结构图，并标明 A、B、C、D 的控制链条。
3. 保存评估报告和定价协商资料，但单独说明“公允价值可靠”不等于“具有商业实质”。
4. 编制商业实质判断备忘录，重点分析未来现金流量风险、时间分布和金额是否变化。
5. 分别形成 A 公司个别报表、B 公司个别报表、集团合并报表的会计影响分析。
6. 对不确认投资收益的理由形成复核结论，避免仅引用“内部重组”四个字。

## 易错点

| 易错判断 | 风险 |
|---|---|
| 只要评估价格公允，就按公允价值确认投资收益 | 忽略商业实质条件，可能提前确认内部重组收益 |
| 将 A 公司和 B 公司的处理混同 | A 公司继续控制 C，B 公司由控制 D 变为持有 C 9%，个别报表判断不完全相同 |
| 只看个别报表，不看合并报表 | 可能遗漏集团内部交易抵销和权益结构变化影响 |
| 把同一控制下内部重组当作普通对外处置 | 可能高估损益，影响利润质量 |

## 可复用经验

集团内部重组中，判断长期股权投资转换是否确认损益，不能只看法律形式和评估价格。应先看控制关系是否发生实质变化，再看未来现金流量风险、时间分布和金额是否发生实质改变。若只是同一控制范围内承载主体变化，通常更适合账面价值结转，不确认处置损益。
