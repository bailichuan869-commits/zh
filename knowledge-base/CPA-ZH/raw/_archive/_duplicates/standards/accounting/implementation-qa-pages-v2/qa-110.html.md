# qa-110

答：根据《企业会计准则解释第4号》（财会〔2010〕15号），对于企业集团（由母公司和其全部子公司构成）内发生的股份支付交易，接受服务企业没有结算义务的，应当将该股份支付交易作为权益结算的股份支付处理。
因此，该国内企业应当将其员工享有的股权激励计划作为权益结算的股份支付处理。
