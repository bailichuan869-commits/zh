# CPA-ZH 知识库总览

CPA-ZH 是面向中国注册会计师行业的专业知识库。它不是简单保存资料目录，而是把法规、准则、政策、职业道德、独立性要求和审计实务经验整理成可追踪、可交叉引用、可持续扩展的知识网络。

## 知识主线

当前知识库分为四条主线：

| 主线 | 解决的问题 | 入口 |
|---|---|---|
| 行业重要法规与准则 | 注册会计师执业的上位规则和专业标准是什么 | [[concepts/regulations-and-standards]] |
| 行业重要政策性文件 | 财会监督、行业治理、考试注册、事务所监管的政策导向是什么 | [[concepts/policy-documents]] |
| 行业史与职业道德 | 行业如何发展、职业伦理和独立性如何约束执业判断 | [[concepts/history-ethics-independence]] |
| 实务技能与案例分析 | 如何把规则转化为审计计划、底稿、抽样、数据分析和复杂场景应对 | [[concepts/practice-skills-cases]] |

## 维护原则

1. **先建骨架，再摄入原文**：目录型材料用于搭框架，法规准则原文后续逐份摄入并注明版本。
2. **每个判断尽量回到来源**：法规、准则、政策类结论应链接到对应来源页或原始文件。
3. **规则要连接实务**：每个重要法规或准则页面都应逐步补充适用场景、审计程序、底稿证据和案例。
4. **动态文件要标注核验日期**：政策、考试、注册、监管口径可能更新，应记录最近核验日期。

## 后续扩展路线

- 第一阶段：补齐四部核心法律和七份政策文件的来源摘要。
- 第二阶段：搭建企业会计准则和注册会计师执业准则的分层索引。
- 第三阶段：建立职业道德、独立性、审计实务与监管案例之间的交叉引用。
- 第四阶段：沉淀智能化工具应用、数据分析程序和复杂案例处理模板。
