# 问：社会资本方执行《企业会计准则解释第14号》时，社会资本方在PPP项目建造期间形成的合...

答：根据《企业会计准则第 14 号 —— 收入》（财会〔 2017 〕 22 号）和《关于修订印发 2019 年度一般企业财务报表格式的通知》（财会〔 2019 〕 6 号）的相关规定， 对于社会资本方将相关 PPP 项目资产的对价金额或确认的建造收入金额确认为无形资产的部分，在相关建造期间确认的合同资产应当 在资产负债表 “ 无形资产 ” 项目中列报； 对于其他 在建造期间确认的合同资产 ，应当 根据其 预计是否自资产负债表日起一年内变现， 在资产负债表 “ 合同资产 ” 或 “ 其他非流动资产 ” 项目中列报 。
