# 审计流程操作——计划、底稿与抽样

## 定义

审计流程操作是把审计准则转化为具体执业动作的过程，核心包括审计计划编制、审计底稿撰写和审计抽样应用。

## 说明

准则是“应该做什么”，流程是“具体怎么做”。这三项是审计实务的基本功：计划决定方向，底稿记录证据，抽样决定覆盖。竞赛把它列为实务技能第一项，说明理论到操作的转化是考察重点。

## 核心原则

1. **风险导向贯穿全程**：计划、执行、记录都以风险评估为起点。
2. **底稿是证据载体**：没有底稿等于没有审计。
3. **抽样须有依据**：不是随意选样，而是基于风险和重要性。

## 审计计划编制

| 阶段 | 内容 | 准则依据 |
|------|------|----------|
| 初步业务活动 | 评价独立性、接受保持客户、签订业务约定书 | CSA 1110 |
| 总体审计策略 | 确定范围、时间、方向，分配资源 | CSA 1201 |
| 具体审计计划 | 风险评估程序、进一步程序性质时间范围 | CSA 1201 |
| 计划变更 | 重大变化时更新计划 | CSA 1201 |

**要点**：总体审计策略是“宏观安排”，具体审计计划是“详细清单”，两者不可混淆。计划应是动态的，随风险评估结果更新。

## 审计底稿撰写

| 要素 | 说明 |
|------|------|
| 完整性 | 涵盖所有重要审计证据和结论 |
| 清晰性 | 他人在无口头解释下能理解 |
| 及时性 | 执行同时记录，不得事后补造 |
| 索引归档 | 统一编号，便于复核和检索 |
| 复核 | 经验较多者复核经验较少者工作 |

**底稿通常包括**：审计标识、索引、审计程序、证据、结论、复核记录。CSA 1131对审计工作底稿的编制、归档（60天内）和保管作出规定。

## 审计抽样

| 类型 | 说明 | 适用 |
|------|------|------|
| 统计抽样 | 运用概率论，可量化抽样风险 | 控制测试、细节测试 |
| 非统计抽样 | 基于判断，不量化风险 | 控制测试、细节测试 |
| 属性抽样 | 评估控制偏差率 | 控制测试 |
| 变量抽样 | 评估金额错报 | 细节测试 |

**关键概念**：抽样风险（信赖过度/信赖不足、误拒/误受）、非抽样风险、可容忍偏差率、可容忍错报、预期偏差率、样本规模影响因素。

**样本规模影响因素**：可容忍错报/偏差率越低、预期错报/偏差率越高、总体变异性越大、可接受抽样风险越低，样本规模越大。

## 常见考点

- 总体审计策略与具体审计计划的区别：前者宏观，后者详细。
- 审计工作底稿归档期限为审计报告日后60天内。
- 抽样风险四种：控制测试中信赖过度风险影响效果（影响审计有效性），信赖不足风险影响效率。
- 细节测试中误受风险影响效果，误拒风险影响效率。
- 影响审计有效性（效果）的风险更危险：信赖过度、误受。

## 易混点

- “总体审计策略”与“具体审计计划”：策略是方向，计划是步骤。
- “统计抽样”与“非统计抽样”：都可接受，区别在是否量化抽样风险，不是准不准。
- “信赖过度”与“误受”：前者是控制测试，后者是细节测试，都影响效果。

## 典型场景

### 场景 1：根据风险评估设计抽样方案
抓手：风险越高 → 样本规模越大 → 有效性越强。

### 场景 2：底稿缺失导致处罚
抓手：CSA 1131 + 注册会计师法第21条 + 财办23号检查。
