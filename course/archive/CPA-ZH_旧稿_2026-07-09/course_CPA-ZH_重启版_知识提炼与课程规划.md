## 二、知识点提炼规则

### 1. 什么进入课程正文

只有满足以下条件之一，才进入正文：

- 能帮助判断“谁负责、谁违规、谁需要留痕”；
- 能帮助判断财务报表如何确认、计量、列报、披露；
- 能帮助设计审计程序、评价证据、形成审计意见；
- 能帮助识别职业道德、独立性、质量管理和监管处罚风险；
- 能在实务案例中形成“事实 -> 风险 -> 规则 -> 程序 -> 证据 -> 结论”的判断链。

### 2. 什么不进入正文

以下内容不作为课程主体：

- 页面目录、文件目录、索引清单；
- 下载状态、归档路径、原始文件位置；
- 知识库维护流程、映射状态、校准状态；
- 官方链接列表和版本核验说明。

这些内容只放入附录，作为“查依据”和“核版本”的辅助材料。

### 3. 主次分级

| 等级 | 定义 | 处理方式 |
|---|---|---|
| P0 核心判断 | 影响执业责任、重大错报风险、审计意见、证券服务责任 | 必须进入正文，配案例和练习 |
| P1 高频实务 | 常见于收入、金融工具、合并、持续经营、关联方、估计等项目 | 必须进入正文或专题训练 |
| P2 支撑规则 | 用于支持 P0/P1 判断的准则、政策、职业道德要求 | 进入正文，但篇幅服从主线 |
| P3 溯源资料 | 条款页、编号页、索引、版本、官方链接 | 进入附录或脚注，不作为课程主体 |

## 三、实质知识点清单（第一轮，共 83 项）

### A. 法律责任与执业边界（15 项，P0/P1）

1. 注册会计师法定业务范围和审计报告证明力。
2. 会计师事务所统一承接业务和事务所民事责任。
3. 注册会计师资料获取权、现场查验权和客户协助义务。
4. 利害关系回避、独立性和保密义务。
5. 客户示意不实证明、故意不提供资料、不合理要求时的拒绝报告义务。
6. 按执业准则出具报告，以及“明知”和“按照准则应当知道”的责任边界。
7. 单位负责人对会计工作和会计资料真实完整负责。
8. 会计核算以实际发生经济业务为基础。
9. 禁止伪造、变造会计资料和虚假财务会计报告。
10. 内部会计监督、岗位分离和如实提供资料义务。
11. 公司治理、股东权利、董监高和实际控制人责任。
12. 公司资本真实、出资、抽逃出资、利润分配和公积金规则。
13. 公司财务会计制度、聘用会计师事务所、提供真实完整资料、不得另立账簿。
14. 证券发行和信息披露真实、准确、完整、及时、公平。
15. 证券服务机构勤勉尽责、文件保存、诚信档案、市场禁入和投资者保护。

### B. 会计准则与报表判断（17 项，P0/P1/P2）

1. 企业会计准则体系的作用：确认、计量、列报、披露。
2. 基本准则和具体准则的关系。
3. 应用指南、解释、应用案例、实施问答和其他规定的层级。
4. 收入确认：合同、履约义务、交易价格、可变对价、收入截止。
5. 金融工具确认和计量：分类、摊余成本、公允价值、预期信用损失。
6. 金融工具列报与披露：负债权益区分、风险披露。
7. 合并财务报表：控制判断、合并范围、结构化主体、实控安排。
8. 长期股权投资：控制、共同控制、重大影响、权益法和处置。
9. 租赁：承租人确认、租赁负债、使用权资产、租赁变更。
10. 资产减值：减值迹象、可收回金额、商誉减值、长期资产减值。
11. 存货、固定资产、无形资产、投资性房地产等基础资产计量。
12. 所得税和递延所得税：暂时性差异、可抵扣亏损、递延所得税资产可实现性。
13. 政府补助和专项资金：与资产相关、与收益相关、递延收益、限制条件。
14. 或有事项和重大诉讼：预计负债、或有负债、披露。
15. 职工薪酬和股份支付：短期薪酬、离职后福利、激励安排。
16. 会计政策、会计估计变更和差错更正。
17. 财务报表列报、现金流量表、分部报告和其他综合收益。

### C. 审计准则与审计方法（18 项，P0/P1）

1. 注册会计师总体目标、合理保证、职业怀疑和职业判断。
2. 业务约定、承接保持和管理层责任确认。
3. 项目质量管理、复核、底稿记录和归档。
4. 总体审计策略和具体审计计划。
5. 重要性、实际执行的重要性和错报评价。
6. 了解被审计单位及其环境、内部控制和信息系统。
7. 重大错报风险识别和评估。
8. 舞弊风险、管理层凌驾、收入确认舞弊假定。
9. 法律法规考虑和违反法规迹象处理。
10. 总体应对措施和进一步审计程序。
11. 审计证据的充分性和适当性。
12. 函证、监盘、分析程序、审计抽样和特定项目程序。
13. 会计估计审计：模型、假设、数据、专家工作、敏感性分析。
14. 关联方审计和资金占用识别。
15. 持续经营评价、重大不确定性和报告段落。
16. 集团审计、组成部分和利用他人工作。
17. 审计意见、强调事项、其他事项、非无保留意见。
18. 关键审计事项、其他信息和上市公司审计报告表达。

### D. 职业道德、独立性、政策与质量管理（13 项，P0/P1/P2）

1. 职业道德基本原则：诚信、客观公正、专业胜任能力、保密、良好职业行为。
2. 职业道德概念框架：识别威胁、评价严重程度、采取防范措施、得出结论。
3. 自身利益、自我评价、倡导、密切关系、外在压力五类威胁。
4. 客户承接、利益冲突、第二意见、收费、礼品款待等服务场景。
5. 独立性准则第1号的适用主体、适用期间和适用关系。
6. 经济利益、贷款担保、收费依赖、或有收费、逾期收费。
7. 非鉴证服务和自我评价威胁。
8. 长期关系、关键审计合伙人轮换和冷却。
9. 项目签发前独立性关闭。
10. 财会监督协同和监管事项跟踪。
11. 规范审计秩序：低价竞争、买卖报告、挂名执业、超能力承接。
12. 事务所许可、注册资格、诚信档案和监督检查。
13. 检查清单化：所级治理、项目承接、人员胜任、底稿报告、整改闭环。

### E. 实务专题矩阵（14 项，P1/P2）

1. 收入确认错报风险。
2. 金融工具估值与减值。
3. 合并范围与控制判断。
4. 持续经营与重大不确定性。
5. 关键审计事项。
6. 证券服务责任。
7. 关联方及资金占用。
8. 资产减值。
9. 利润分配和权益交易。
10. 所得税和递延所得税。
11. 政府补助和专项资金。
12. 或有事项和重大诉讼。
13. 职工薪酬。
14. 长期股权投资。

### F. 实务能力、案例与工具（6 项，P1/P2/P3）

1. 审计计划、底稿撰写、抽样、证据评价、复核和报告。
2. 案例分析模板：事实背景、关键风险、适用规则、审计程序、证据、判断过程、结论。
3. 复杂交易、管理层判断、舞弊风险、监管问询和证据冲突处理。
4. RPA、数据清洗和智能化财务应用。
5. 知识库维护、版本核验、官方来源追踪。
6. 行业历史和制度演进。

## 四、依赖关系

### 基础层

先学责任主体、报表目标、审计目标、职业道德和独立性。没有这些基础，学习具体准则会变成背条文。

### 中间层

再学会计准则和审计准则：

- 会计准则回答“报表应当如何表达业务”；
- 审计准则回答“注册会计师如何获得证据并发表意见”。

### 高级层

最后进入实务专题和案例：

- 从收入、金融工具、合并、持续经营、关联方等高频专题训练综合判断；
- 从案例中练习“事实 -> 风险 -> 规则 -> 程序 -> 证据 -> 结论”。

## 五、主要易混概念

| 易混概念 | 核心区别 |
|---|---|
| 知识库目录 vs 课程知识 | 目录只是找资料的入口；课程知识必须能形成判断。 |
| 法律责任 vs 审计风险 | 法律责任关注谁违反义务；审计风险关注重大错报和未恰当应对的风险。 |
| 管理层责任 vs 注册会计师责任 | 管理层负责报表和资料真实完整；注册会计师负责按准则取证并发表恰当意见。 |
| 会计准则 vs 审计准则 | 会计准则规定报表怎么做；审计准则规定审计怎么做。 |
| 充分性 vs 适当性 | 充分性看证据数量；适当性看证据质量和相关可靠程度。 |
| 重大错报风险 vs 检查风险 | 前者是报表本身可能错；后者是程序未发现错。 |
| 审计程序执行了 vs 审计证据支持结论 | 做过程序不等于证据足以支持报告。 |
| 关键审计事项 vs 非无保留意见 | 关键审计事项是沟通重大审计关注；非无保留意见是报表或范围问题影响意见。 |
| 应用指南/解释/问答 vs 准则正文 | 补充资料帮助理解和应用；不能替代准则正文和正式规则层级判断。 |
| 版本核验 vs 正文学习 | 版本核验是引用时的可靠性控制，不是课程正文主线。 |

## 六、重启版课程结构建议

### 总课程：CPA-ZH 注册会计师执业知识重启版

目标：建立完整判断框架，解释每门课如何互相连接。

### 第一门：法律责任与执业边界

重点：四部核心法律、责任风险总表、证券服务责任、客户资料受限、虚假报告、勤勉尽责。

正文主线：谁负责 -> 谁配合 -> 谁禁止 -> 谁报告 -> 谁赔偿。

### 第二门：会计准则与报表判断

重点：确认、计量、列报、披露；收入、金融工具、合并、租赁、减值、所得税、政府补助、或有事项、长期股权投资。

正文主线：业务事实 -> 会计单元 -> 确认条件 -> 计量基础 -> 列报披露 -> 易错处理。

### 第三门：审计准则与取证报告

重点：职业怀疑、风险评估、重要性、审计证据、函证、监盘、估计、关联方、持续经营、集团审计、审计意见、关键审计事项。

正文主线：风险 -> 程序 -> 证据 -> 复核 -> 报告。

### 第四门：职业道德、独立性与质量管理

重点：职业道德基本原则、威胁和防范措施、独立性准则第1号、非鉴证服务、收费、长期关系、事务所检查和质量管理。

正文主线：威胁识别 -> 严重程度评价 -> 防范措施 -> 退出或继续 -> 留痕。

### 第五门：实务专题与案例训练

重点：14 个专题矩阵和已加工案例卡片。

正文主线：事实背景 -> 风险识别 -> 法律责任 -> 会计判断 -> 审计程序 -> 证据结论 -> 底稿复盘。

### 附录：查依据、核版本、用索引

只放 P3 内容：条款页、编号页、官方链接、版本核验、来源目录、知识库维护方法。

## 七、拟采用的课程写法

每个正文知识点必须写成以下结构：

1. **它解决什么实务问题**；
2. **涉及谁的责任或判断**；
3. **规则实质是什么**；
4. **审计或会计落点是什么**；
5. **底稿、证据或披露应如何体现**；
6. **常见误判是什么**；
7. **用一个小情景检验理解**。

示例，不作为正文：

| 知识点 | 不合格写法 | 重启版写法 |
|---|---|---|
| 注册会计师法第20条 | 第20条规定拒绝不当报告。 | 当客户要求删除保留事项、拒绝提供关键资料或要求报告不能正确表达时，注册会计师不能只做“解释说明”，而要升级为范围受限、管理层诚信、业务保持和报告意见判断。 |
| 收入准则 | CAS 14 规定收入确认。 | 先识别合同和履约义务，再判断控制权转移、交易价格和可变对价，最后落到截止、真实性、合同资产负债和披露。 |
| 审计证据 | 审计证据要充分适当。 | 证据充分性不是“底稿很多”，适当性要看证据与认定相关、来源可靠、是否能支持结论；客户口头解释不能替代外部证据。 |
