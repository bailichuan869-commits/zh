# Python 第 20 课：Markdown 结构化写作和 AI 提示词

## 今天先认识一种 AI 很爱用的写作格式

上一节我们用 AkShare 获取了 A 股报表数据。

下一节会讲 MinerU 文档解析 API。这个工具可以把 PDF、图片、Word 等文档解析成结构化结果，其中最常见的一种结果就是 Markdown。

所以今天先补一节小基础：

> Markdown 是一种用纯文本表达文档结构的写法。

你可能已经见过它了。

AI 回答里经常会出现这些符号：

```markdown
# 标题

## 小标题

- 第一项
- 第二项

| 字段 | 含义 |
|---|---|
| name | 姓名 |
| amount | 金额 |
```

这些符号不是乱码，也不是需要删掉的多余字符。

它们是在告诉你：

```text
哪里是标题
哪里是列表
哪里是表格
哪里是代码
哪里是引用
```

今天这节课的目标很简单：

> 看懂 AI 输出里的 Markdown，并能自己写出一份简单的 Markdown 笔记。

## 为什么现在要学 Markdown

我们马上要进入文档解析 API。

很多文档解析工具不是直接帮你做一份漂亮的 Word，而是先把文档变成结构化文本。

比如一份 PDF 被解析后，可能会变成这样：

```markdown
# 审计报告

## 一、管理层责任

- 编制财务报表
- 设计和维护内部控制

## 二、注册会计师责任

| 项目 | 内容 |
|---|---|
| 审计目标 | 获取合理保证 |
| 审计依据 | 中国注册会计师审计准则 |
```

如果你不认识 Markdown，第一眼可能会觉得这些符号有点奇怪。

但看懂以后就会发现：

- `#` 表示标题。
- `-` 表示列表。
- `|` 表示表格。
- 三个反引号表示代码块或原样文本块。

下一节再看到 MinerU 输出 Markdown，你就能知道它不是在“弄乱文档”，而是在把文档结构提取出来，方便后面继续交给 AI 处理。

## Markdown 是什么

Markdown 是一种轻量级标记语言。

简单说，它让你用普通文本写出有结构的文档。

比如标题不用手动调字号，而是写：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

列表不用点工具栏按钮，而是写：

```markdown
- 第一项
- 第二项
- 第三项
```

表格也可以用纯文本表达：

```markdown
| 科目 | 金额 | 说明 |
|---|---:|---|
| 管理费用 | 12000 | 本月报销 |
| 销售费用 | 8500 | 推广支出 |
```

Markdown 的重点不是“立刻变漂亮”。

它的重点是：

> 先把内容结构写清楚。

后面你可以把它复制到笔记软件、README、网页、文档工具，或者继续交给 AI 处理。

## Markdown 和 AI 有什么关系

AI 很常用 Markdown，因为 Markdown 很适合表达结构。

比如：

```text
标题清楚
列表清楚
表格清楚
代码边界清楚
引用和正文清楚
```

所以你让 AI 输出方案、表格、代码、课程大纲时，它经常会默认使用 Markdown。

你写提示词时，也可以主动要求它这样输出：

```text
请用 Markdown 输出：
1. 先给一个二级标题
2. 再用表格列出字段
3. 最后用代码块给出示例 JSON
```

这样 AI 的回答通常会更整齐，也更容易复制、修改和复用。

## 最常用的 Markdown 语法

下面这些先掌握就够用了。

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

`#` 越多，标题级别越低。

写课程笔记、项目说明、README 时，通常用到三级标题就够了。

### 列表

无序列表：

```markdown
- 安装 Python
- 创建虚拟环境
- 安装依赖
```

有序列表：

```markdown
1. 打开项目文件夹
2. 运行程序
3. 检查输出结果
```

如果只是列要点，用 `-`。

如果强调步骤顺序，用 `1. 2. 3.`。

### 加粗和行内代码

```markdown
这是 **重要内容**。

请运行 `python main.py`。
```

加粗适合强调关键词。

行内代码适合表示命令、文件名、字段名和函数名。

### 代码块

代码块用三个反引号包起来。

````markdown
```python
print("Hello Markdown")
```
````

也可以换成 JSON：

````markdown
```json
{
  "status": "success",
  "amount": 100
}
```
````

代码块对 AI 很重要。

它等于告诉 AI：

> 这一段是代码或原始文本，请按原样理解，不要和正文混在一起。

### 表格

```markdown
| 字段 | 含义 | 示例 |
|---|---|---|
| stock | 股票代码 | sh600519 |
| symbol | 报表类型 | 资产负债表 |
| output | 输出文件 | reports.xlsx |
```

表格自己手敲有点麻烦。

实际使用时，可以直接让 AI 帮你生成：

```text
请把下面这些字段整理成 Markdown 表格：
字段名、含义、示例、是否必填
```

### 引用

```markdown
> API 就是别人提供好的一个网址，我们按它的规则传参数，它返回一段数据。
```

引用适合放定义、提醒、结论或别人的原话。

## 动手写一份 Markdown 笔记

现在新建一个文件：

```text
markdown_demo.md
```

把下面这段内容放进去：

````markdown
# 我的第一篇 Markdown 笔记

## 今天学到什么

- Markdown 可以用纯文本表达结构。
- AI 经常用 Markdown 输出答案。
- 文档解析工具也经常输出 Markdown。

## 常用语法

| 语法 | 作用 |
|---|---|
| `#` | 标题 |
| `-` | 列表 |
| `**文字**` | 加粗 |
| ``` | 代码块 |

## Python 示例

```python
print("Hello Markdown")
```
````

然后把这份笔记发给 AI，让它做两件事：

```text
请基于这份 Markdown 笔记，帮我扩写成一篇课程总结。

再帮我改写成一份可以发给同事看的 Markdown 说明文。
```

你会发现，Markdown 不是为了写符号。

它真正的作用是：

> 让内容结构更容易被人和 AI 复用。

## Markdown 的优点和限制

Markdown 的优点：

- 简单，几分钟就能上手。
- 文件是纯文本，适合长期保存。
- 很适合写笔记、README、提示词、项目说明。
- 适合 AI 读取和继续加工。
- 可以转换为 HTML、PDF、Word 等格式。

Markdown 的限制：

- 不适合做非常复杂的版式设计。
- 不同工具对表格、脚注、数学公式等扩展语法支持不完全一样。
- 如果要做正式排版，最后仍可能需要 Word、PPT 或专业排版工具。

可以这样理解：

```text
Markdown 负责结构。
Word / PPT / 网页负责最终呈现。
AI 负责在结构化内容上继续加工。
```

## 和下一节 MinerU 的关系

下一节我们会讲 MinerU 文档解析 API。

它的价值不是“把 PDF 变成另一份 PDF”，而是：

> 把难处理的文档，解析成更容易被 AI 继续处理的结构化文本。

Markdown 正好是这种结构化文本的常见形式。

所以学习顺序是：

```text
先看懂 Markdown
再看懂文档解析 API 为什么输出 Markdown
最后让 AI 基于 Markdown 做摘要、提取字段、生成底稿说明
```

## 做完以后你应该能

- 看懂 AI 输出里的 `#`、`-`、`|`、三个反引号等符号。
- 用 Markdown 写一份简单课堂笔记。
- 让 AI 按 Markdown 输出表格、代码块和文档结构。
- 说明为什么文档解析工具常把结果输出为 Markdown。
- 说清 Markdown 适合结构化写作，不等于最终精美排版。
