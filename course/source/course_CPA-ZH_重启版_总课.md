## 第0章：课程导引

### 如何使用本课程

本课程不是 CPA 六科通用培训课，而是把 CPA-ZH 现有知识库中最贴近 CPA 考试重点和注册会计师执业判断的内容组织成学习路径。

学习时要按三层使用：

1. **先看总课**：知道 CPA-ZH 能学什么、不能学什么。
2. **再学五门主课**：从会计、审计、法律责任、职业道德、实务案例逐步推进。
3. **最后回知识库查依据**：条款页、编号页、官方链接只作为溯源工具，不当作正文学习对象。

### 学习方法建议

- 不背目录，背判断链。
- 不先问“这个页面在哪里”，先问“这个事项怎么判断”。
- 每学一个知识点，都用一句话说出：它影响确认计量、审计证据、报告意见、法律责任还是独立性。
- 遇到复杂事项，用固定路径拆解：事实 -> 风险 -> 规则 -> 程序 -> 证据 -> 结论。

### 课程结构说明

本重启版课程按 CPA 考试重点和 CPA-ZH 覆盖度交叉确定：

- 第一门：会计准则与报表判断。
- 第二门：审计准则与风险导向审计。
- 第三门：公司证券法律责任与审计连接。
- 第四门：职业道德、独立性与质量管理。
- 第五门：CPA-ZH 实务专题与综合案例。
- 附录：索引、版本核验和官方来源。

### 推荐工具

- `course_CPA-ZH_重启版_CPA考试重点对照与知识点重定.md`：判断课程范围和重点。
- CPA-ZH 知识库中的专题页：用于回查准则、法律和案例。
- 官方大纲：用于判断考试要求和能力等级。

## 第1章：为什么不能把 CPA-ZH 当成完整 CPA 六科课

### 学习目标

- [ ] 理解 CPA-ZH 与 CPA 六科考试范围的关系。
- [ ] 能区分“知识库覆盖强项”和“考试缺口”。
- [ ] 能避免把知识库目录误当成学习重点。

### 核心内容

CPA 专业阶段有六科：会计、审计、财务成本管理、公司战略与风险管理、经济法、税法。CPA-ZH 当前并没有完整覆盖六科。

CPA-ZH 当前覆盖强的是：

- 企业会计准则、解释、应用案例、实施问答；
- 中国注册会计师执业准则；
- 注册会计师法、会计法、公司法、证券法；
- 职业道德守则和独立性准则；
- 监管政策、质量检查、实务专题和少量案例。

CPA-ZH 当前覆盖弱的是：

- 税法全体系；
- 财务成本管理；
- 公司战略与风险管理主体知识；
- 经济法中合同、物权、合伙、破产、票据、反垄断等内容。

所以，本课程的定位应当是：

> 用 CPA 考试重点校准 CPA-ZH，把它建设成会计、审计、公司证券法律责任、职业道德独立性和综合案例判断课程。

### 记忆辅助

#### 对比表格

| 项目 | 完整 CPA 六科课 | CPA-ZH 重启版课程 |
|---|---|---|
| 覆盖目标 | 覆盖会计、审计、财管、战略、经济法、税法 | 覆盖 CPA-ZH 已有且与考试高相关的内容 |
| 强项 | 全科系统训练 | 会计、审计、公司证券责任、职业道德和案例 |
| 风险 | 内容庞杂 | 容易误把目录当知识 |
| 正确定位 | 应试全覆盖 | 重点知识库课程和执业判断训练 |

#### 一句话总结

CPA-ZH 不是六科全集，而是 CPA 考试中“会计 + 审计 + 执业责任 + 案例判断”的高价值子集。

### 本章小结

1. 课程必须承认 CPA-ZH 的边界。
2. CPA-ZH 强在会计、审计和执业判断，不强在税法、财管和战略全量内容。
3. 课程正文只讲实质知识，索引和目录放到附录。

### 知识检测

1. 判断题：CPA-ZH 当前可以直接当作完整 CPA 六科课程使用。  
2. 单选题：CPA-ZH 当前最适合优先建设的课程是：  
   A. 会计与审计判断  
   B. 完整税法  
   C. 完整财务成本管理  
   D. 完整战略管理  
3. 概念辨析：知识库覆盖强项和 CPA 考试完整范围有什么区别？

<details>
<summary>本章答案</summary>

1. 错误。  
2. A。  
3. CPA 考试完整范围包括六科；CPA-ZH 当前只是其中一部分内容覆盖较强，不能把缺口当作已覆盖。

</details>

## 第2章：用 CPA 考试重点重新确定 CPA-ZH 学习主线

### 学习目标

- [ ] 理解为什么要用官方大纲能力等级校准知识点。
- [ ] 能说明 P0/P1/P2/P3 的分级规则。
- [ ] 能判断一个知识点是否应进入正文。

### 核心内容

CPA 官方大纲的能力等级比知识库页面数量更重要。

- **等级 1**：理解概念。
- **等级 2**：能在简单职业环境中应用。
- **等级 3**：能在复杂职业环境中综合运用。

本课程优先纳入等级 3 和综合阶段会反复调用的内容。再看 CPA-ZH 是否已有足够资料支撑。

知识点分级如下：

- **P0 核心章节**：长期股权投资、合并报表、金融工具、收入、资产减值、审计风险、审计证据、关键审计事项、独立性等。
- **P1 重点专题**：存货、固定资产、所得税、政府补助、关联方、持续经营、证券服务责任等。
- **P2 支撑知识**：基本准则、应用指南、法律版本核验、政策背景。
- **P3 附录资料**：索引、目录、下载状态、文件路径、维护流程。

判断一个知识点是否进入正文，要问六个问题：

1. 是否影响确认、计量、列报、披露？
2. 是否影响重大错报风险？
3. 是否影响审计程序和证据？
4. 是否影响审计报告？
5. 是否影响法律责任？
6. 是否影响职业道德或独立性？

### 记忆辅助

#### 对比表格

| 分级 | 判断标准 | 课程处理 |
|---|---|---|
| P0 | 大纲等级高、综合阶段常用、CPA-ZH 覆盖强 | 正文核心章节 |
| P1 | 高频实务专题或重要支撑 | 正文重点专题 |
| P2 | 帮助理解 P0/P1 | 简讲或穿插 |
| P3 | 索引、来源、版本、路径 | 附录 |

#### 口诀

先看大纲等级，再看综合案例；能落判断进正文，只能查找进附录。

### 本章小结

1. 课程重点不是按页面多少决定，而是按考试能力和实务判断价值决定。
2. P0/P1 是正文主体。
3. P3 不再写成课程正文。

### 知识检测

1. 判断题：一个准则编号页资料很多，就一定应成为正文核心章节。  
2. 多选题：以下哪些问题可以帮助判断知识点是否进入正文？  
   A. 是否影响审计证据  
   B. 是否影响报告意见  
   C. 是否只是下载路径  
   D. 是否影响确认计量  
3. 情景判断：如果某资料只是官方链接和下载状态，应放在哪里？

<details>
<summary>本章答案</summary>

1. 错误。  
2. A、B、D。  
3. 放入附录或来源说明，不作为正文知识点。

</details>

## 第3章：五门主课的学习顺序

### 学习目标

- [ ] 理解为什么第一门先学会计准则。
- [ ] 能说明五门课之间的依赖关系。
- [ ] 能按自身目标选择学习路径。

### 核心内容

重启版课程采用五门主课。

第一门是**会计准则与报表判断**。原因是 CPA 考试中会计是核心基础，且 CPA-ZH 对企业会计准则覆盖最强。长期股权投资、合并报表、金融工具、收入和资产减值都是等级高、综合阶段常用、实务判断密集的内容。

第二门是**审计准则与风险导向审计**。会计判断回答报表应当怎么表达，审计判断回答注册会计师如何证明这个表达是否恰当。

第三门是**公司证券法律责任与审计连接**。这门不冒充完整经济法，而是聚焦 CPA-ZH 覆盖强的注册会计师法、会计法、公司法、证券法。

第四门是**职业道德、独立性与质量管理**。它不是附属内容，而是决定项目能不能接、能不能继续、能不能签发的底线。

第五门是**实务专题与综合案例**。把前四门知识放进收入、金融工具、合并、持续经营、关联方、关键审计事项等专题中训练。

### 记忆辅助

#### 对比表格

| 课程 | 解决的问题 | 典型输出 |
|---|---|---|
| 会计准则 | 报表应如何表达业务 | 会计处理和披露判断 |
| 审计准则 | 如何取证并发表意见 | 程序、证据、报告 |
| 法律责任 | 谁负责、谁违规、谁赔偿 | 责任链和审计收口 |
| 职业道德独立性 | 能否承接、保持、签发 | 独立性和质量结论 |
| 实务案例 | 如何综合运用 | 案例分析和底稿思路 |

#### 路线图

业务事实 -> 会计表达 -> 审计证明 -> 法律责任 -> 独立性质量 -> 案例结论。

### 本章小结

1. 第一门先学会计，是因为会计是 CPA 考试和综合案例的基础。
2. 审计课程建立在会计判断之上。
3. 法律、职业道德和案例训练是执业判断的外层约束和综合应用。

### 知识检测

1. 单选题：为什么重启版第一门先学会计？  
   A. CPA-ZH 对会计覆盖强，且会计是考试和案例基础  
   B. 法律不重要  
   C. 审计可以不学  
   D. 因为会计目录最多  
2. 判断题：职业道德和独立性只是审计课程之后的附录。  
3. 排序题：请排序：审计证明、业务事实、案例结论、会计表达。

<details>
<summary>本章答案</summary>

1. A。  
2. 错误。  
3. 业务事实 -> 会计表达 -> 审计证明 -> 案例结论。

</details>

## 第4章：每个知识点都要落到职业判断

### 学习目标

- [ ] 掌握“事实 -> 风险 -> 规则 -> 程序 -> 证据 -> 结论”的分析链。
- [ ] 能把准则条文转化为考试和实务判断。
- [ ] 能识别空泛课程表述。

### 核心内容

以后每章都按同一套问题写：

1. 事实是什么？
2. 风险在哪里？
3. 用什么规则？
4. 做什么程序？
5. 要什么证据？
6. 形成什么结论？

例如，“长期股权投资”不能写成“CAS 2 规定长期股权投资”。合格写法应当讲清：投资方是否控制、共同控制或重大影响；适用成本法、权益法还是金融工具准则；处置或转换时个别报表和合并报表有什么不同；审计上要看协议、章程、董事会席位、实际决策记录和被投资单位报表。

### 记忆辅助

#### 对比表格

| 写法 | 问题 | 是否合格 |
|---|---|---|
| CAS 2 是长期股权投资准则 | 只是目录说明 | 不合格 |
| 先判断控制、共同控制、重大影响，再选择成本法、权益法或金融工具路径 | 能指导判断 | 合格 |
| 合并报表关注控制 | 仍偏空 | 不够 |
| 控制要看权力、可变回报、运用权力影响回报，不能只看持股比例 | 能应对案例 | 合格 |

#### 一句话总结

能做判断的才是课程正文，只能定位资料的放进附录。

### 本章小结

1. 本课程写法以职业判断为中心。
2. 准则目录不是知识点，判断路径才是知识点。
3. 每个重点都要能落到证据、披露或报告。

### 知识检测

1. 判断题：只要列出准则名称和适用范围，就已经完成课程讲解。  
2. 填空题：本课程的综合分析链是事实 -> 风险 -> 规则 -> 程序 -> 证据 -> ____。  
3. 情景判断：客户说其持股 40% 所以一定是重大影响，你还应追问什么？

<details>
<summary>本章答案</summary>

1. 错误。  
2. 结论。  
3. 应追问董事会席位、表决权安排、合同权利、实际决策参与、其他股东分散程度、是否存在控制或共同控制安排。

</details>

## 第5章：CPA-ZH 当前缺口和补课边界

### 学习目标

- [ ] 能说清 CPA-ZH 当前不能覆盖哪些 CPA 科目。
- [ ] 能避免把缺口内容强行写成课程。
- [ ] 能确定后续补充知识库的方向。

### 核心内容

CPA-ZH 当前不适合直接生成完整税法、财务成本管理、战略和完整经济法课程。

税法只适合在本轮课程中讲所得税会计、递延所得税和税会差异案例。财务成本管理基本缺失。战略只适合吸收治理、风险和监管交叉内容。经济法只适合聚焦公司法、证券法、会计法和注册会计师法。

这不是缺点，而是课程边界。边界清楚，课程才不会虚胖。

### 记忆辅助

#### 对比表格

| 缺口 | 当前处理 | 后续补充方向 |
|---|---|---|
| 税法 | 只讲所得税会计和税会差异 | 建立税种专题 |
| 财管 | 暂不写正文 | 建立财务分析、估值、资本预算资料 |
| 战略 | 只讲治理和风险交叉 | 建立战略分析和风险管理体系 |
| 经济法其他部分 | 只讲公司证券责任 | 补合同、物权、破产、票据等 |

#### 一句话总结

缺口不硬补，强项先写深。

### 本章小结

1. CPA-ZH 重启版不是完整 CPA 六科课程。
2. 当前先写会计、审计、法律责任、职业道德和案例。
3. 税法、财管、战略、经济法缺口需要另建资料。

### 知识检测

1. 判断题：CPA-ZH 当前可以直接生成完整财务成本管理课程。  
2. 单选题：所得税和递延所得税在本轮课程中应放在：  
   A. 会计准则与报表判断  
   B. 完整税法课  
   C. 财务成本管理课  
   D. 战略课  
3. 简答题：为什么明确缺口比假装覆盖更重要？

<details>
<summary>本章答案</summary>

1. 错误。  
2. A。  
3. 明确缺口可以避免课程误导学习者，也能指导后续知识库补充。

</details>
