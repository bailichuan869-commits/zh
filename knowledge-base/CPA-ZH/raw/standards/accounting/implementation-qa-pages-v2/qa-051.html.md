# 问：社会资本方执行《企业会计准则解释第14号》时，社会资本方应当如何对PPP项目合同进行...

答：根据《企业会计准则解释第 14 号》（财会〔 2 0 21 〕 1 号）的相关规定，社会资本方应当按照重要性原则，在附注中披露各项 PPP 项目合同的相关信息，或者将一组具有类似性质的 PPP 项目合同合并披露。一组具有类似性质的 PPP 项目是指一组包含类似性质服务的 PPP 项目合同（如高速公路收费、污水处理服务、垃圾处理项目等）。例如，社会资本方同时承接多项高速公路收费的 PPP 项目合同，则社会资本方可以将该类合同的会计信息和合同信息 分别 进行合并披露。
