# VBA第17课：加载项实战 5：重命名和拆分工作簿

## 这一节要做什么

这一节进入“工作簿”分组，做两个常用功能：

```text
重命名工作簿
拆分工作簿
```

这两个功能都和当前打开的工作簿有关。

- `重命名工作簿`：把当前工作簿改成一个新文件名。
- `拆分工作簿`：把当前工作簿里的每个可见 Sheet 拆成单独工作簿。

## 本节你会学到

- 为什么打开中的工作簿不能直接改名。
- 重命名工作簿本质上是“另存为 + 删除旧文件”。
- 怎么避免误操作插件本体。
- 拆分工作簿时为什么要求当前工作簿先保存。
- 拆分时要不要包含隐藏 Sheet。
- 加载项功能应该在普通工作簿中测试，而不是直接对插件文件测试。

## 功能 1：重命名工作簿

正常情况下，一个正在打开的工作簿不能直接在文件夹里重命名，因为 Excel 正在占用它。

所以“重命名工作簿”的实现逻辑其实是：

```text
输入新文件名
  ↓
把当前工作簿另存为新名称
  ↓
删除旧名称的文件
  ↓
当前工作簿变成新文件
```

## 添加重命名工作簿按钮

在“工作簿”分组里添加按钮：

```text
重命名工作簿
```

给 AI 的功能说明可以写：

```text
重命名当前打开的用户工作簿。
使用另存为的方式，将当前工作簿保存为用户指定的新名称。
保存成功后删除原工作簿文件。
只在当前工作簿同级目录下改名，不更换保存目录。
不能重命名加载项本身。
```

注意最后一句很重要：

> 不能重命名加载项本身。

因为加载项按钮是在 `final.xlam` 里运行的，我们真正要处理的是用户当前打开的普通工作簿。

## 让 AI 先确认细节

导出设计后，让 AI 先 plan：

```text
实现功能：重命名工作簿。
先用 plan 模式。
```

AI 可能会问：

### 删除旧文件前要不要二次确认

这里可以按自己的习惯选择。

如果希望最省事，可以选择：

```text
输入新名称后直接执行重命名和删除旧文件。
```

如果希望更谨慎，可以选择：

```text
删除旧文件前再确认一次。
```

### 是否允许更换目录

本节选择：

```text
只在同目录改名，不更换保存目录。
```

如果要换目录，那其实更像“另存为”，不是快速重命名。

## 测试重命名工作簿

这个功能不要直接在 `final.xlsm` 上测试。

因为 `final.xlsm` 是插件开发文件。

更合理的测试方式：

1. 把工具另存为加载宏 `.xlam`。
2. 在 Excel 加载项中加载它。
3. 新建或打开一个普通工作簿。
4. 保存这个普通工作簿。
5. 点击 `重命名工作簿`。
6. 输入新名称。
7. 检查文件夹里的文件名是否已变化。

如果 AI 写得比较稳，它会判断：

```text
当前工作簿是加载项本身时，不允许重命名。
```

这是正确的保护。

## 功能 2：拆分工作簿

第二个功能是：

```text
拆分工作簿
```

它的作用是：

> 把当前工作簿中的每个可见 Sheet 单独保存成一个工作簿。

比如当前工作簿里有：

```text
Sheet1
Sheet2
Sheet3
```

执行拆分后，会在同级目录生成类似：

```text
原工作簿名_Sheet1.xlsx
原工作簿名_Sheet2.xlsx
原工作簿名_Sheet3.xlsx
```

每个新工作簿只包含对应的一个 Sheet。

## 添加拆分工作簿按钮

在“工作簿”分组里添加按钮：

```text
拆分工作簿
```

给 AI 的功能说明可以写：

```text
将当前工作簿中的所有可见 Sheet 拆分出来。
每个 Sheet 保存为一个新的工作簿。
新工作簿保存到当前工作簿同级目录下。
每个新工作簿只包含一个 Sheet。
隐藏 Sheet 不拆分。
不能拆分加载项本身。
```

## 拆分前要确认工作簿已保存

如果用户只是按 `Ctrl + N` 新建了一个工作簿，但还没有保存，它是没有文件路径的。

没有路径，就不知道拆分出来的文件应该保存到哪里。

所以拆分前要判断：

```text
当前工作簿必须先保存。
```

如果没保存，应该提示用户先保存。

## 测试拆分工作簿

测试步骤：

1. 打开一个普通工作簿。
2. 保存到某个文件夹。
3. 新建几个 Sheet。
4. 隐藏其中一个 Sheet。
5. 点击 `拆分工作簿`。
6. 检查同级目录是否生成多个新工作簿。

正常结果：

- 每个可见 Sheet 生成一个新工作簿；
- 每个新工作簿只包含一个 Sheet；
- 隐藏 Sheet 不生成；
- 文件名包含原工作簿名和 Sheet 名。

## 给按钮加图标

功能完成后，再给两个按钮加图标：

- 重命名：可以搜索 `重命名`、`编辑`；
- 拆分：可以搜索 `拆分`、`一对多`。

建议继续保持同一风格：

- 线条风就都用线条风；
- 填充风就都用填充风；
- 色系尽量统一；
- 图标尺寸建议 64 像素。

## 本节记住这五点

1. 打开中的工作簿不能直接改名，重命名本质是另存为后删除旧文件。
2. 加载项按钮要操作用户工作簿，不要误操作插件本体。
3. 拆分工作簿前，当前工作簿必须已经保存。
4. 拆分时要明确是否包含隐藏 Sheet，本节选择只拆分可见 Sheet。
5. 测试加载项功能时，最好加载成 `.xlam` 后在普通工作簿中测试。

## 课后练习

给“拆分工作簿”增加一个确认提示：

```text
即将把当前工作簿中的 N 个可见 Sheet 拆分为单独工作簿，是否继续？
```

完成标准：

1. AI 先用 plan 模式规划。
2. 统计可见 Sheet 数量。
3. 用户确认后再拆分。
4. 拆分完成后提示生成了多少个文件。
