# VBA第13课：加载项实战 1：套 ROUND、提取字符、清除非公式

## 这一节要做什么

前面我们已经把功能区设计器、按钮、菜单、下拉框、输入框、复选框、窗体、加载宏发布都讲了一遍。

从这一节开始，我们进入加载项实战。

这节课先做“公式函数”这一组常用功能：

```text
添加 ROUND
提取数字 / 英文 / 中文
清除非公式
```

这几个功能都很适合放进 Excel 加载项里，平时做底稿、改模板、清洗数据时会经常用到。

## 本节你会学到

- 怎么从零创建一个实战加载项项目。
- 怎么按功能组规划加载项按钮。
- 为什么建议“加一个功能，调试一个功能”。
- 怎么实现“添加 ROUND”。
- 怎么用菜单收纳“提取数字 / 英文 / 中文”。
- 怎么处理 AI 第一次实现不准的问题。
- 为什么提取中文时可以让 AI 改用正则。
- 怎么实现“清除非公式”。
- 怎么给按钮补图标，让工具更像成品。

## 实战功能规划

这次实战来自常见小帮手需求。

常见功能可以先按模块分组：

| 分组 | 常见功能 |
| --- | --- |
| 公式函数 | 套 ROUND、提取文本、清除非公式、批量更换链接、绝对引用/相对引用转换 |
| 工作表 | 批量删表、生成目录、另存 Sheet |
| 工作簿 | 重命名工作簿等 |
| 格式与打印 | 自定义格式、打印相关处理 |
| 通用 | 批量改文件名、批量改文件夹名 |

这节课先从“公式函数”组开始。

虽然这些需求看起来不少，但大部分都在 VBA 能力范围内。

VBA 不仅能操作 Excel，也能操作一些系统文件，例如改文件名、改文件夹名。简单网络请求也可以做，只是本阶段先聚焦 Excel 内部工具。

## 第一步：创建实战项目

先用功能区设计器创建一个新项目。

项目名可以叫：

```text
my VBA addin
```

也就是“我的 VBA 加载项”。

建议养成习惯：

> 每做一个新的加载项，都先创建一个独立项目。

这样项目配置、工作簿、AI 说明、备份都不会混在一起。

## 第二步：创建功能分组

在功能区里创建 5 个分组：

```text
公式函数
工作表
工作簿
格式与打印
通用
```

顺序可以按你的使用频率调整。

如果“公式函数”最常用，就放在最前面。

内部 ID 可以改，也可以不改。

如果想让 AI 更容易理解，也可以把 ID 改得更有语义，例如：

```text
group_formula
group_sheet
group_workbook
```

但对普通使用来说，显示名称更重要。

## 建议：一个功能调试完，再加下一个

按钮可以一次性全加完，也可以一个个加。

实战里更推荐：

```text
加一个功能
  ↓
导出设计
  ↓
让 AI 实现
  ↓
打开 Excel 测试
  ↓
确认没问题
  ↓
再加下一个功能
```

这样做的好处是：

- 出问题时更容易定位；
- 不会多个未完成按钮互相干扰；
- AI 每次处理的上下文更清楚；
- 你能一步步确认功能质量。

## 功能 1：添加 ROUND

先在“公式函数”分组里添加一个按钮。

按钮名称：

```text
添加 ROUND
```

按钮大小可以选普通小按钮。

如果后面按钮很多，小按钮更节省空间。

给 AI 的功能说明可以写：

```text
对当前选中区域的单元格添加 ROUND 公式。
保留两位小数。
遇到空单元格则跳过。
不要影响未选中的区域。
```

可以把内部 ID 改成更好理解的名称，例如：

```text
btn_round
```

配置好后，导出设计。

## 让 AI 实现添加 ROUND

用 VS Code 打开项目根目录。

启动 AI 终端，说：

```text
实现添加 ROUND 功能。
先用 plan 模式。
```

AI 的计划里应该能看到：

- 它识别到“添加 ROUND”按钮；
- 它知道按钮对应的回调；
- 它会遍历当前选区；
- 空单元格跳过；
- 给单元格添加 `ROUND(...,2)`；
- 注入 `final.xlsm` 并验证。

确认计划没问题后，让 AI 执行。

完成后打开 `final.xlsm` 测试：

1. 输入几个数字和小数。
2. 选中区域。
3. 点击“添加 ROUND”。
4. 检查公式是否正确包上 `ROUND`。

## 功能 2：提取文本

提取文本不适合只做成一个按钮，因为它有多个子功能。

更适合做成菜单：

```text
提取文本
  提取数字
  提取英文
  提取中文
```

也就是说：

- “提取文本”是菜单；
- “提取数字 / 英文 / 中文”是菜单下面的按钮。

## 配置提取文本菜单

在“公式函数”组里添加一个菜单：

```text
提取文本
```

在菜单下添加 3 个按钮：

```text
提取数字
提取英文
提取中文
```

给 AI 的功能说明可以分别写：

```text
提取选中区域单元格中的数字。
将提取的内容填充到用户指定的起始单元格中。
```

```text
提取选中区域单元格中的英文。
将提取的内容填充到用户指定的起始单元格中。
```

```text
提取选中区域单元格中的中文。
将提取的内容填充到用户指定的起始单元格中。
```

这里要注意一个设计选择：

> 提取结果不要直接覆盖原单元格，更适合让用户指定输出位置。

直接覆盖风险更高。

所以可以让宏弹出一个选择框，让用户选择结果输出的起始单元格。

## 导出并让 AI 实现提取功能

确认前一个功能已经完成后，再导出设计。

然后让 AI 实现：

```text
继续实现提取数字、提取英文、提取中文。
请用中文写计划。
先用 plan 模式。
```

AI 的计划里应该包括：

- 遍历当前选区；
- 根据按钮类型提取数字、英文或中文；
- 弹出选择框，让用户选择输出起始单元格；
- 按原选区形状或顺序输出提取结果；
- 空单元格跳过或输出空值；
- 注入并构建。

如果 AI 自动验证时报错，原因可能是：

> 功能里弹出了选择单元格的输入框，自动化验证无法点击这个框。

这种情况只要手动打开 Excel 测试即可。

## 手动测试提取功能

准备一些混合文本，例如：

```text
ABC123中文
审计A100
客户XYZ金额999
```

测试提取数字：

1. 选中这些单元格。
2. 点击 `提取文本 → 提取数字`。
3. 选择输出起始单元格。
4. 检查是否输出数字部分。

测试提取英文：

1. 点击 `提取文本 → 提取英文`。
2. 选择输出位置。
3. 检查是否输出英文部分。

测试提取中文：

1. 点击 `提取文本 → 提取中文`。
2. 选择输出位置。
3. 检查是否输出中文部分。

## 如果提取中文失败怎么办

提取中文有时第一次实现会失败。

常见表现：

- 中文提取不出来；
- 输出为空；
- 弹窗文字变成问号；
- 有空格或混合字符时识别不稳定。

这时不要急着自己改代码。

可以把现象告诉 AI：

```text
提取中文失效了。
例如单元格内容是“ABC123中文”，没有提取出中文。
另外 inputbox 的提示文字变成问号。
请检查原因并修复。
```

如果仍然不稳定，可以进一步要求：

```text
请改用正则表达式提取中文。
```

对于提取数字、英文、中文这类文本处理功能，正则通常更稳。

修复后再重新打开 `final.xlsm` 手动测试。

## 功能 3：清除非公式

第三个功能是：

```text
清除非公式
```

它的作用是：

> 选中一个区域后，把不是公式的内容清除掉，只保留公式。

这个功能在做模板时很有用。

比如一个底稿模板里：

- 有些单元格是手工填写的值；
- 有些单元格是公式；

如果你想清空数据但保留公式，就可以用这个功能。

## 配置清除非公式按钮

在“公式函数”组里添加一个按钮：

```text
清除非公式
```

短提示：

```text
清除非公式
```

详细提示或 AI 说明：

```text
清除选中区域中不是公式的值。
跳过空单元格。
保留公式。
保留格式和批注。
不要影响未选中的区域。
```

配置后，关闭 `final.xlsm`，导出设计。

## 让 AI 实现清除非公式

在 AI 终端中说：

```text
继续实现清除非公式。
先用 plan 模式。
```

计划里重点看：

- 遍历选中区域；
- 空单元格跳过；
- 有公式的单元格保留；
- 没有公式且非空的单元格清除内容；
- 保留格式和批注；
- 不处理未选中区域。

确认后让 AI 执行。

## 测试清除非公式

在工作表里准备：

```text
普通值
普通值
=A1+B1
普通值
```

选中这个区域，点击：

```text
清除非公式
```

正常结果：

- 普通值被清除；
- 公式保留下来；
- 格式尽量保持不变。

这个功能常用于：

```text
清空模板输入区，但保留公式区。
```

```text
再补图标和界面细节
```

## 常见问题

### 为什么不一次性把所有按钮都加完

一次性加完也可以。

但实战中更推荐一个个加、一个个测。

这样出错时更容易定位，也更容易知道是哪个功能导致的问题。

### 提取结果为什么不直接覆盖原单元格

覆盖原值风险比较高。

更稳的方式是：

```text
用户选择输出起始单元格
```

这样原始数据还在，结果另放一边，方便检查。

### AI 自动验证提取功能时超时怎么办

如果功能里弹出了让用户选择单元格的框，自动验证可能点不了。

这种情况可以手动打开 Excel 测试。

### 中文提取失败怎么办

让 AI 检查提取逻辑，并要求：

```text
使用正则表达式提取中文。
```

同时注意 `.bas` 编码问题，避免中文提示变成问号。

### 清除非公式会不会删掉公式

正常实现应该不会。

测试时一定要准备公式单元格，确认公式被保留。

## 本节记住这五点

1. 实战项目先分组，再一个功能一个功能实现。
2. 功能说明写清楚，AI 才能更稳定地生成代码。
3. 提取类功能不要轻易覆盖原数据，建议输出到用户指定位置。
4. 中文处理不稳定时，可以要求 AI 使用正则。
5. 功能先跑通，再补图标和界面美化。
