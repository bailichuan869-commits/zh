# 问：银行收回已核销的贷款，应当如何进行会计处理？

答：银行收回已核销的以摊余成本计量的贷款，按实际收到的金额，借记“贷款”科目，贷记“贷款损失准备”科目；借记“存放中央银行款项”等科目，贷记“贷款”科目；借记“贷款损失准备”科目，贷记“信用减值损失”科目；或者采用简化处理，即借记“存放中央银行款项”等科目，贷记“信用减值损失”科目。
