# CPA-ZH 全新重构课程大纲

> **状态**：全新重构版。此前所有课程正文、目录式草稿和重启版试生成内容均不作为本版课程结构依据。  
> **课程定位**：本课程不是 CPA 考试课程，也不以应试通过为目标；CPA 考试能力等级仅作为判断知识点重要性、复杂度和讲解深度的外部校准器。  
> **课程目标**：基于 CPA-ZH 知识库，建立注册会计师执业判断课程体系，使学习者能够把业务事实、会计规则、审计程序、证据链、法律责任、职业道德和报告结论连成完整判断。  
> **输出形态**：Markdown 课程群。后续正文按章生成，每章必须写成可学习的知识讲义，不得写成目录说明。

## 一、重构原则

### 1. 摒弃旧稿

本版不沿用以下旧思路：

- 不按知识库目录顺序机械排课。
- 不把法律、准则、政策、案例写成“资料介绍”。
- 不把 CPA-ZH 课程伪装成完整 CPA 六科课程。
- 不把 CPA 考试重点当成课程目标。
- 不为了覆盖面牺牲知识讲解深度。
- 不写“某页包含什么内容”式说明，而要直接讲知识本身。

旧稿中已经写出的课程文件只作为历史记录，不作为本版结构依据。后续正式正文应另起新文件，避免在旧稿上修修补补。

### 2. 课程真正服务的能力

课程要培养的不是“知道资料在哪里”，而是以下六种能力：

| 能力 | 学习者最终要能做到 |
|---|---|
| 事实识别 | 从合同、交易、组织架构、资金流、沟通记录中提取关键事实。 |
| 规则适用 | 判断应适用会计准则、审计准则、法律条款、职业道德还是政策监管口径。 |
| 会计判断 | 判断确认、计量、列报、披露是否恰当。 |
| 审计应对 | 识别重大错报风险，设计程序，评价证据充分性和适当性。 |
| 责任判断 | 区分管理层责任、治理层责任、注册会计师责任、事务所责任和证券服务责任。 |
| 结论表达 | 用“事实 -> 风险 -> 规则 -> 证据 -> 判断 -> 结论”的结构形成可复核结论。 |

### 3. CPA 考试能力等级的使用方式

CPA 考试大纲只用于校准课程深度，不用于决定课程范围。

| CPA 能力等级 | 在本课程中的含义 | 课程写法 |
|---|---|---|
| 等级 1：理解 | 概念、定义、基本原则。 | 讲清楚“是什么”和“为什么重要”，配基础例子。 |
| 等级 2：应用 | 能在单一实务场景中作出判断。 | 必须写判断条件、步骤、证据、典型错法。 |
| 等级 3：综合 | 能在复杂场景中联动会计、审计、法律和职业判断。 | 必须写完整案例链、风险链、证据链、报告或责任后果。 |

本课程的分级不是“考试分数权重”，而是“执业判断训练强度”。

### 4. CPA-ZH 内容边界

CPA-ZH 当前强项：

- 企业会计准则、解释、实施问答、应用案例和其他规定；
- 中国注册会计师执业准则、应用指南和审计主题导航；
- 会计法、注册会计师法、公司法、证券法及条款级索引；
- 职业道德守则、独立性准则第1号及相关应用指南；
- 注册会计师行业政策、事务所监管、诚信建设和监督检查；
- 收入、金融工具、合并范围、持续经营、关键审计事项、关联方、资产减值、所得税、政府补助、或有事项、长期股权投资等专题矩阵；
- 已加工的实务案例卡片。

CPA-ZH 当前弱项：

- 不足以覆盖完整税法课程；
- 不足以覆盖完整财务成本管理课程；
- 不足以覆盖完整公司战略与风险管理课程；
- 经济法中合同、物权、合伙、破产、票据、反垄断等并非知识库强项；
- 部分会计主题已有准则页但尚缺足够案例和专题页，需要在课程中标注“基础覆盖”或“待扩展”。

## 二、知识点分级

### P0：课程核心，必须详细讲

P0 知识点必须满足至少两项：

- CPA 考试能力等级通常较高，或综合阶段/实务案例中反复调用；
- CPA-ZH 已有较完整的准则、法律、审计、专题或案例支撑；
- 能形成完整执业判断链；
- 错误处理可能导致重大错报、审计失败、信息披露责任或证券服务责任。

P0 正文写作要求：

- 不少于“概念 -> 判断框架 -> 典型场景 -> 易错点 -> 审计证据 -> 案例训练”六部分；
- 每章必须有比较表；
- 每章必须有情景判断题；
- 每章至少给一个“错误判断如何一步步发生”的反面例子；
- 每章要明确底稿证据和报告/责任影响。

P0 知识群：

| 知识群 | 核心知识 | CPA-ZH 主要支撑 |
|---|---|---|
| 收入确认与错报风险 | 五步法、履约义务、控制权转移、时点/时段、可变对价、合同资产负债、总额净额、售后回购、截止和真实性。 | CAS 14、收入确认错报风险专题、收入案例、审计证据和函证准则。 |
| 金融工具估值与减值 | 金融资产分类、业务模式、SPPI、摊余成本、公允价值、预期信用损失、金融负债与权益工具、披露。 | CAS 22、CAS 37、金融工具专题、会计估计审计、专家工作。 |
| 长期股权投资与控制判断 | 控制、共同控制、重大影响、权益法、成本法、转换、处置、内部重组、合营安排。 | CAS 2、CAS 33、长期股权投资专题、长投案例。 |
| 企业合并与合并财务报表 | 合并范围、控制三要素、结构化主体、委托代理、内部交易抵销、非控制性权益、丧失控制。 | CAS 33、合并范围专题、集团审计准则。 |
| 资产减值与重大估计 | 资产组、可收回金额、商誉减值、公允价值、使用价值、关键假设、敏感性、专家工作。 | CAS 8、资产减值专题、CSA 1321、CSA 1421。 |
| 所得税与递延所得税 | 暂时性差异、递延所得税资产可实现性、税会差异、所得税费用、税务不确定性。 | CAS 18、所得税专题、税会差异案例。 |
| 持续经营 | 亏损、债务违约、现金流压力、融资依赖、重大不确定性、报告段落。 | 持续经营专题、CSA 1324、审计报告准则。 |
| 关联方及资金占用 | 关联方识别、完整性、资金流水、非经营性占用、实控人安排、披露。 | 关联方专题、CSA 1323、公司法、证券法。 |
| 会计估计审计 | 模型、假设、数据、管理层偏向、区间估计、专家工作、披露。 | CSA 1321、CSA 1421、金融工具/减值/所得税专题。 |
| 审计证据与核心程序 | 充分性、适当性、函证、监盘、分析程序、抽样、外部证据、直接证据。 | CSA 1301、1311、1312、1313、1314。 |
| 风险导向审计 | 审计目标、职业怀疑、重大错报风险识别、风险应对、控制测试、实质性程序、错报评价。 | CSA 1101、1211、1231、1251。 |
| 舞弊与法律法规 | 收入舞弊假定、管理层凌驾、违法违规迹象、沟通、程序、报告后果。 | CSA 1141、1142、会计法、证券法。 |
| 审计报告与关键审计事项 | 意见类型、强调事项、其他事项、关键审计事项、其他信息、报告沟通。 | CSA 1501、1503、1504、1521。 |
| 证券服务责任 | 勤勉尽责、真实准确完整、重大遗漏、连带赔偿、资料保存、公众公司审计责任。 | 证券法、证券服务责任专题、责任风险总表。 |

## 三、课程总结构

本课程设计为“1 门总课 + 6 门主课 + 1 门案例训练课 + 附录”的课程群。

### 总课：注册会计师执业判断总览

定位：建立课程的总判断模型，不讲目录，不讲检索，直接讲“注册会计师如何形成可复核判断”。

核心问题：

- 什么是执业判断？
- 为什么会计、审计、法律、职业道德不能分开学？
- CPA 考试能力等级为什么只能作为重要性参考？
- 一个实务问题如何从事实走到结论？
- CPA-ZH 能覆盖哪些能力，不能覆盖哪些能力？

建议章节：

1. 执业判断的基本链条：事实 -> 风险 -> 规则 -> 证据 -> 结论。
2. 会计判断、审计判断、法律责任和职业道德的关系。
3. 知识分级：P0/P1/P2/P3 如何决定学习深度。
4. 财务报表项目不是孤立科目：收入、金融工具、合并、减值如何互相影响。
5. 审计不是程序清单：风险如何驱动证据。
6. 责任不是法条背诵：谁负责、为什么负责、如何证明勤勉尽责。
7. 案例表达模板：事实、争议、规则、证据、判断、结论、复盘。

## 四、第一门主课：会计准则与报表判断

### 课程定位

本课不是会计分录课，而是“业务事实如何进入财务报表”的判断课。每章都要讲：

- 交易或事项的经济实质是什么；
- 适用哪项准则；
- 如何确认、计量、列报、披露；
- 管理层常见错法是什么；
- 审计上需要什么证据；
- 错误处理可能造成什么报表后果。

### 建议章节

#### 第1章：会计判断方法论

深度：P2 基础，但必须写扎实。

必须讲：

- 会计准则解决确认、计量、列报、披露问题；
- 会计信息质量要求如何影响判断；
- 个别报表和合并报表的区别；
- 会计政策、会计估计和会计差错的区别；
- “事实 -> 准则 -> 条件 -> 金额 -> 披露 -> 证据”的七步法。

#### 第2章：收入确认与合同资产负债

深度：P0，必须详细。

必须讲：

- 收入五步法；
- 合同是否真实、可执行、有商业实质；
- 履约义务拆分；
- 某一时点和某一时段确认；
- 控制权转移；
- 可变对价和重大融资成分；
- 主要责任人与代理人；
- 合同资产、应收账款、合同负债；
- 售后回购、销售退回、质保、预售、定制产品、海外销售；
- 截止、真实性、完整性、退货和期后事项；
- 收入案例训练。

#### 第3章：金融工具确认、计量、减值与列报

深度：P0，必须详细。

必须讲：

- 金融资产、金融负债、权益工具；
- 业务模式；
- 合同现金流量特征；
- 摊余成本、FVOCI、FVTPL；
- 实际利率法；
- 公允价值层次、估值模型和参数；
- 预期信用损失三阶段；
- 金融资产转移和终止确认；
- 永续债、优先股、可转债、回售权、保护性条款；
- 金融工具披露；
- 估值和减值审计证据。

#### 第4章：长期股权投资、合营安排与权益法

深度：P0，必须详细。

必须讲：

- 控制、共同控制、重大影响；
- 成本法和权益法；
- 联营企业、合营企业、共同经营；
- 初始计量和后续计量；
- 内部交易未实现损益；
- 股权变化、追加投资、处置和转换；
- 同一控制下内部重组；
- 个别报表和合并报表的处理差异；
- 投资协议、章程、董事席位、决策记录等证据。

#### 第5章：企业合并与合并财务报表

深度：P0，必须详细。

必须讲：

- 企业合并类型；
- 合并范围；
- 控制三要素；
- 结构化主体；
- 委托代理关系；
- 潜在表决权；
- 合并抵销逻辑；
- 内部交易未实现损益；
- 非控制性权益；
- 丧失控制权；
- 集团架构和合并过程证据。

#### 第6章：资产减值、商誉减值和公允价值估计

深度：P0，必须详细。

必须讲：

- 减值迹象；
- 可收回金额；
- 公允价值减处置费用；
- 使用价值；
- 资产组和资产组组合；
- 商誉分摊；
- 关键假设和敏感性；
- 管理层偏向；
- 估值专家；
- 披露要求。

#### 第7章：所得税、递延所得税和税会差异

深度：P0/P1，视知识库材料写详细。

必须讲：

- 资产负债表债务法；
- 暂时性差异；
- 递延所得税资产和负债；
- 可抵扣亏损；
- 递延所得税资产可实现性；
- 所得税费用；
- 税会差异案例；
- 盈利预测、纳税申报、税务检查证据。

#### 第8章：租赁、政府补助和专项资金

深度：P1，重点讲复杂判断。

必须讲：

- 租赁识别；
- 租赁期；
- 使用权资产和租赁负债；
- 售后租回；
- 与资产相关和与收益相关政府补助；
- 递延收益；
- 限制性条件；
- 免费使用资产是否属于政府补助；
- 补助文件、拨款、验收、使用限制证据。

#### 第9章：或有事项、重大诉讼、职工薪酬和股份支付

深度：P1。

必须讲：

- 预计负债确认条件；
- 或有负债披露；
- 未决诉讼和律师函；
- 担保和亏损合同；
- 短期薪酬、离职后福利、辞退福利；
- 股份支付等待期、服务条件、业绩条件；
- 会计估计和披露证据。

#### 第10章：财务报表列报、政策估计变更、差错更正和期后事项

深度：P1。

必须讲：

- 报表列报和附注；
- 重要会计政策；
- 重大判断和估计不确定性；
- 会计政策变更；
- 会计估计变更；
- 前期差错更正；
- 资产负债表日后调整事项和非调整事项；
- 审计调整和报告影响。

## 五、第二门主课：审计准则与风险导向审计

### 课程定位

本课不是审计程序清单课，而是“风险如何驱动程序，证据如何支撑结论”的课程。

每章都要讲：

- 审计目标是什么；
- 哪些事项会导致重大错报风险；
- 注册会计师应如何设计程序；
- 什么证据更可靠；
- 底稿如何留下判断轨迹；
- 证据不足时报告如何变化。

### 建议章节

#### 第1章：审计目标、合理保证和职业怀疑

深度：P0/P2。

必须讲总体目标、合理保证、重大错报、职业怀疑、职业判断、审计固有限制、管理层责任和注册会计师责任。

#### 第2章：承接保持、业务约定和计划审计工作

深度：P1。

必须讲客户诚信、独立性初筛、业务约定条款、总体策略、具体计划、项目组资源和时间安排。

#### 第3章：重大错报风险识别和评估

深度：P0，必须详细。

必须讲了解被审计单位及其环境、内部控制、认定层次风险、特别风险、舞弊风险、法律法规风险、风险评估程序和底稿记录。

#### 第4章：风险应对、控制测试和实质性程序

深度：P0。

必须讲总体应对、进一步审计程序、控制测试、实质性分析程序、细节测试、不可预见性、错报评价。

#### 第5章：审计证据、函证、监盘、分析程序和抽样

深度：P0，必须详细。

必须讲充分性、适当性、证据来源、函证控制、替代程序、存货监盘、分析程序预期值、抽样风险、样本评价。

#### 第6章：舞弊、管理层凌驾和法律法规

深度：P0。

必须讲收入舞弊假定、管理层凌驾、分录测试、会计估计偏向、异常交易、违法违规迹象、沟通和报告。

#### 第7章：会计估计、关联方、持续经营和期后事项

深度：P0。

必须讲估计模型、假设、数据、专家、关联方完整性、资金占用、持续经营重大不确定性、期后事项程序。

#### 第8章：集团审计和利用他人工作

深度：P1/P0。

必须讲组成部分、集团项目组责任、重要组成部分、组成部分注册会计师、内部审计人员、专家工作。

#### 第9章：审计报告、关键审计事项和其他信息

深度：P0。

必须讲意见类型、保留/否定/无法表示、强调事项、其他事项、关键审计事项、其他信息责任。

#### 第10章：底稿、复核、质量管理和监管检查

深度：P1。

必须讲底稿目标、记录要求、复核、归档、项目质量管理、项目质量复核、监督检查常见问题。

## 六、第三门主课：法律责任与证券服务责任

### 课程定位

本课不是法条背诵课，而是“责任如何在财务报告和审计工作中发生”的课程。

每章都要讲：

- 责任主体是谁；
- 法定义务是什么；
- 违反义务通常怎样发生；
- 注册会计师应如何识别和应对；
- 底稿如何证明勤勉尽责；
- 报告和法律后果是什么。

### 建议章节

#### 第1章：责任地图总论

讲管理层责任、治理层责任、单位负责人责任、注册会计师责任、事务所责任、证券服务机构责任。

#### 第2章：会计法中的真实完整责任

讲会计资料真实完整、实际经济业务、财务报告、资料提供、虚假报告、单位负责人责任。

#### 第3章：注册会计师法中的执业边界和报告责任

讲业务范围、审计报告证明效力、资料获取、拒绝不当报告、按准则执业、事务所法律责任。

#### 第4章：公司法中的治理、资本和财务会计责任

讲公司治理、股东和实际控制人、董监高责任、出资、减资、利润分配、财务会计制度、聘用事务所。

#### 第5章：证券法中的信息披露责任

讲真实准确完整、重大事项、虚假记载、误导性陈述、重大遗漏、控股股东和实际控制人责任。

#### 第6章：证券服务机构勤勉尽责

深度：P0，必须详细。

讲证券服务机构职责、勤勉尽责、资料保存、连带赔偿、免责逻辑、底稿证据链、公众公司审计风险。

#### 第7章：法律责任与审计报告联动

讲法律风险如何影响审计计划、证据评价、意见类型、关键审计事项、其他信息和业务保持。

## 七、第四门主课：职业道德、独立性与质量控制

### 课程定位

本课不是“职业道德口号课”，而是“能不能承接、能不能继续、能不能签发”的底线课程。

### 建议章节

#### 第1章：职业道德基本原则

讲诚信、客观公正、专业胜任能力和勤勉尽责、保密、良好职业行为。

#### 第2章：职业道德概念框架

讲不利影响识别、评价和防范，利益冲突，压力，诱惑，违反法规行为。

#### 第3章：独立性总论

讲独立性实质和形式、审计和审阅业务独立性、网络事务所、公众利益实体。

#### 第4章：经济利益、贷款担保和商业关系

深度：P0/P1。

讲直接经济利益、重大间接经济利益、贷款担保、商业关系、家庭成员关系。

#### 第5章：收费、薪酬、人员交流和长期关系

讲逾期收费、或有收费、低价竞争、关键审计合伙人轮换、前员工加入客户。

#### 第6章：非鉴证服务

讲会计服务、估值服务、税务服务、内审服务、信息系统服务、管理职能和自我评价威胁。

#### 第7章：事务所质量管理和诚信监管

讲质量管理体系、项目质量复核、诚信建设、监督检查、执业许可和整改。

## 八、第五门主课：政策监管与事务所治理

### 课程定位

本课把政策文件转化为事务所和项目组能执行的要求。政策不是背文件名，而是理解监管为什么这样查、事务所如何落地。

### 建议章节

1. 财会监督顶层设计：监督谁、监督什么、如何协同。
2. 规范财务审计秩序：低价竞争、买卖报告、挂名执业、网络售卖报告。
3. 事务所执业许可和日常监管：准入、变更、分所、人员和质量控制。
4. 监督检查办法：检查程序、重点事项、整改、处理处罚。
5. 诚信建设：诚信档案、信用监管、联合惩戒。
6. 证券发行项目专项口径：以研发人员及研发投入为例，讲政策指引如何变成核查程序。
7. 政策执行检查清单：事务所层面和项目层面如何留痕。

## 九、第六门主课：实务专题与综合案例

### 课程定位

本课用于把前面所有知识整合成场景训练。每个专题都按同一模板写：

```text
场景 -> 关键事实 -> 重大错报风险 -> 会计规则 -> 审计程序 -> 证据评价 -> 法律/道德/报告影响 -> 结论
```

### 建议专题

| 专题 | 训练重点 |
|---|---|
| 收入确认综合案例 | 合同、履约义务、控制权、截止、函证、退货、舞弊。 |
| 金融工具估值与减值案例 | 分类、估值、ECL、专家工作、敏感性、披露。 |
| 合并范围与结构化主体案例 | 控制三要素、合同安排、委托代理、集团审计。 |
| 长投内部重组案例 | 商业实质、账面价值结转、公允价值误用、投资收益。 |
| 所得税和递延所得税案例 | 暂时性差异、可抵扣性、盈利预测、税会差异。 |
| 政府补助案例 | 免费使用资产、限制条件、递延收益、披露。 |
| 持续经营案例 | 债务违约、现金流、融资计划、报告段落。 |
| 关联方和资金占用案例 | 实控人、异常流水、披露、证券责任。 |
| 重大诉讼案例 | 预计负债、律师函、或有负债、报告影响。 |
| 证券服务责任案例 | 勤勉尽责、底稿证据、信息披露一致性、连带责任抗辩。 |

## 十、正文写作深度标准

### 1. 每章固定结构

每章正式正文必须包含：

1. 学习目标；
2. 业务场景引入；
3. 核心概念和定义；
4. 判断框架；
5. 典型场景；
6. 易错点；
7. 审计程序和证据；
8. 法律、职业道德或报告影响；
9. 记忆辅助；
10. 本章小结；
11. 知识检测和答案。

### 2. P0 章节最低内容密度

P0 章节不得少于以下内容：

- 1 张判断流程图；
- 2 张以上对比表；
- 3 个以上典型场景；
- 1 个完整案例；
- 1 组审计证据清单；
- 1 组常见错法；
- 10 道以上知识检测题；
- 答案必须解释理由。

### 3. 不允许出现的写法

- “本章介绍 CAS 14 的资料分布”；
- “该准则主要包括若干内容”；
- “学习者应自行查阅知识库”；
- “法律条款规定了相关责任”但不解释责任如何发生；
- “审计应获取充分适当证据”但不说明具体证据是什么；
- “详见某页面”作为正文替代。

### 4. 推荐表达模板

每个关键知识点使用以下表达：

```text
先讲场景：企业遇到了什么事情。
再讲问题：这件事为什么会影响报表或审计。
再讲规则：准则、法律或职业道德要求什么。
再讲判断：满足什么条件，如何区分相似概念。
再讲证据：底稿中要拿什么材料支持判断。
最后讲错法：常见错误如何导致错报、报告风险或责任风险。
```

## 十一、课程维护规则

### 1. 版本维护

- 后续正文文件应使用“全新重构”命名。
- 旧稿保留但不继续维护。
- 每次新增章节都应同步更新总大纲中的完成状态。
- 当 CPA-ZH 新增专题或案例时，先判断分级，再决定纳入哪门课。

### 2. 新知识入课判断

新增知识点按以下顺序判断：

1. 是否属于 CPA-ZH 已有或计划维护范围；
2. 是否能形成执业判断；
3. 是否有准则、法律、政策或案例依据；
4. 是否对应 P0/P1/P2/P3；
5. 应进入主课、案例课还是附录。

### 3. 与 CPA 考试大纲的关系

每年 CPA 考试大纲更新后，只做三件事：

- 校准哪些知识点需要提升或降低分级；
- 校准哪些新知识点应补入课程；
- 校准综合能力训练是否缺关键场景。

不得因为大纲变化把课程改成应试目录。

---

## 十二、优先生成顺序

建议按以下顺序生成正式正文：

1. 总课：注册会计师执业判断总览。
2. 第一门第1章：会计判断方法论。
3. 第一门第2章：收入确认与合同资产负债。
4. 第二门第1章：审计目标、合理保证和职业怀疑。
5. 第二门第3章：重大错报风险识别和评估。
6. 第四门第1-3章：职业道德、概念框架和独立性总论。
7. 第三门第1章：责任地图总论。
8. 第六门第1个综合案例：收入确认综合案例。

理由：

- 先建立总判断模型；
- 再建立会计判断和审计判断两条主线；
- 同步嵌入职业道德和法律责任；
- 最后用案例把知识压实。
