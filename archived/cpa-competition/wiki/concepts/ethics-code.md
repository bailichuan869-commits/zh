# 中国注册会计师职业道德守则

## 定义

《中国注册会计师职业道德守则》是规范注册会计师职业行为的基本准则，确立职业道德基本原则和应对威胁的防范机制。

## 说明

职业道德守则是行业自律的核心。它把抽象的“诚信”转化为可操作的基本原则，并要求注册会计师识别威胁、评估影响、采取防范措施。独立性作为基本原则之一，在审计和审阅业务中被进一步强化（见独立性准则第1号）。

## 核心原则（六大基本原则）

| 原则 | 含义 | 典型违反 |
|------|------|----------|
| 诚信 | 诚实正直，不参与虚假误导 | 出具虚假报告、协助造假 |
| 客观公正 | 不偏不倚，不受不当影响 | 利益冲突下发表意见 |
| 职业胜任能力 | 保持专业知识和技能 | 承接超出能力业务 |
| 保密 | 对执业中获知信息保密 | 泄露客户商业秘密 |
| 职业行为 | 维护行业形象，不损害公众利益 | 贬损同行、夸大宣传 |
| 独立性 | 审计审阅业务中保持实质和形式独立 | 与客户有利益关系 |

## 威胁与防范框架

| 威胁类型 | 说明 | 示例 |
|----------|------|------|
| 自身利益威胁 | 因自身利益影响判断 | 持有客户股票 |
| 自我评价威胁 | 评价自己工作成果 | 审计自己设计的内控 |
| 倡导威胁 | 过度推广客户利益 | 担任客户辩护人 |
| 密切关系威胁 | 因熟悉或关系影响判断 | 亲属在客户任职 |
| 外在压力威胁 | 受胁迫无法客观 | 客户以解聘施压 |

## 结构与步骤

| 模块 | 说明 |
|------|------|
| 基本原则 | 六大原则，适用于所有业务 |
| 威胁识别 | 识别五类威胁对原则的影响 |
| 防范措施 | 采取防范措施消除或降至可接受水平 |
| 不可接受情形 | 无法消除威胁时应拒绝或终止业务 |
| 业务承接与保持 | 以职业道德为前提承接业务 |

## 常见考点

- 六大基本原则的名称和含义，尤其独立性、保密、诚信。
- 五类威胁的识别：自身利益、自我评价、倡导、密切关系、外在压力。
- 当威胁无法消除或降至可接受水平时，应拒绝承接或终止业务。
- 保密原则有例外：法律法规要求披露、行业自律检查、司法程序等。
- 职业道德守则适用于所有注册会计师业务，不仅限审计。

## 易混点

- “实质独立”与“形式独立”：实质是精神状态，形式是第三方合理认知。两者都需满足。
- “保密”不等于“绝对不披露”：法定披露、授权披露、行业检查等属例外。
- 职业道德守则（普适）与独立性准则第1号（专门针对审计审阅）是层级关系，不是替代关系。

## 典型场景

### 场景 1：注册会计师持有客户股票
抓手：自身利益威胁 → 独立性原则 → 应在承接前处置。

### 场景 2：审计客户是注册会计师亲属任职企业
抓手：密切关系威胁 → 评估是否可降至可接受水平，否则回避。
