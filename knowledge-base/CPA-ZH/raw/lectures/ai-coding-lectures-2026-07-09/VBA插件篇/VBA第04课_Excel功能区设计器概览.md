# VBA第04课：Excel 功能区设计器概览

## 这一节要做什么

从这一节开始，我们正式进入 Excel 加载项制作。

不过这一节先不写业务代码，而是先熟悉功能区设计器。

以前要做 Excel 自定义功能区，需要手写 `customUI.xml`，还要手写按钮回调。现在我们先用设计器把界面搭出来：

```text
选项卡 → 分组 → 按钮 → 提示文字 → 给 AI 的功能说明
```

## 本节你会学到

- 怎么激活和打开功能区设计器。
- 设计器主界面每个区域是做什么的。
- 怎么创建一个加载项项目。
- 怎么添加选项卡、分组、按钮、下拉框等控件。
- 怎么配置按钮名称、图标、大小和提示。
- 什么是“给 AI 的功能说明”。
- 怎么预览当前设计。
- `project.json` 是什么。

## 第一步：激活功能区设计器

第一次打开功能区设计器时，需要先激活。

流程是：

1. 复制机器码。
2. 发给老师。
3. 拿到激活码。
4. 粘贴激活码完成注册。

激活后，就可以进入设计器主界面。

## 第二步：认识主界面

设计器主界面可以分成几个区域。

### 1. 项目操作区

这里一般包括：

- 创建项目；
- 打开项目；
- 保存项目。

后面我们会用“项目”的方式管理加载项，而不是零散地改文件。

### 2. 项目路径和导出区

这里可以看到当前项目路径，也可以进行：

- 预览当前工作区；
- 导出设计；
- 生成最终工作簿。

预览用于快速看界面效果，导出用于生成后面真正要使用的文件。

### 3. 中间预览区

中间会显示当前功能区的大概样子。

例如：

```text
智能工具
  数据处理组
    自动排序
```

你可以直观看到：

- 选项卡在哪里；
- 分组在哪里；
- 按钮放在哪个组里。

### 4. 控件区和节点导航

左侧可以添加控件，例如：

- 选项卡；
- 分组；
- 按钮；
- 输入框；
- 下拉框。

节点导航会显示它们之间的层级关系：

```text
选项卡
  分组
    按钮
    下拉框
```

### 5. 属性面板

选中某个按钮后，右侧可以配置按钮属性。

常见字段包括：

- 显示名称；
- 图标；
- 显示尺寸；
- 回调过程；
- 短提示；
- 详细提示；
- 给 AI 的功能说明。

## 第三步：配置一个按钮

我们以“添加 ROUND”按钮为例。

可以这样配置：

| 字段 | 示例 |
| --- | --- |
| 显示名称 | 添加 ROUND |
| 图标 | 选择一个内置图标，或导入图片 |
| 显示尺寸 | 大按钮 |
| 短提示 | 添加 ROUND |
| 详细提示 | 对选中的区域添加 ROUND 公式，保留两位小数 |
| 给 AI 的功能说明 | 对选中区域添加 ROUND 公式，保留两位小数，跳过空单元格 |

这里要特别注意“给 AI 的功能说明”。

它不是给用户看的，而是后面给 AI 看的。

后面让 AI 实现按钮功能时，AI 会读取这些说明，知道这个按钮到底要做什么。

## 显示名称、提示、AI 说明的区别

| 字段         | 给谁看         | 用来做什么               |
| ---------- | ----------- | ------------------- |
| 显示名称       | 使用 Excel 的人 | 按钮上显示的文字            |
| 短提示        | 使用 Excel 的人 | 鼠标悬停时出现的标题          |
| 详细提示       | 使用 Excel 的人 | 鼠标悬停时出现的详细解释        |
| 给 AI 的功能说明 | AI          | 让 AI 理解这个按钮应该实现什么功能 |

不要只写按钮名称。

如果你希望 AI 后面写得更准，最好把需求写清楚。

## 第四步：预览功能区

配置好按钮后，点击：

```text
预览
```

设计器会打开一个临时 Excel。

在这个 Excel 里，你可以看到刚刚设计的功能区，例如：

```text
智能工具 → 数据处理组 → 添加 ROUND
```

把鼠标放到按钮上，可以看到短提示和详细提示。

不过这时点击按钮通常还不能真正运行，因为我们只是设计了界面，还没有写按钮背后的 VBA 功能。

先记住：

> 预览主要用来检查界面长什么样，不代表功能已经实现。

## 第五步：创建加载项项目

点击：

```text
创建项目
```

选择一个保存位置，例如：

```text
AI coding study
```

项目名可以叫：

```text
VBA add in
```

设计器会自动创建一个项目文件夹。

## project.json 是什么

创建项目后，文件夹里会出现：

```text
project.json
```

它是当前功能区项目的配置文件。

里面会保存：

- 有哪些选项卡；
- 有哪些分组；
- 有哪些按钮；
- 按钮名称；
- 图标；
- 提示信息；
- 给 AI 的功能说明；
- 回调过程信息。

以后你重新打开设计器，只要打开这个 `project.json`，之前的设计就能恢复。

## 本节记住这五点

1. 功能区设计器用来可视化设计 Excel 自定义功能区。
2. 一个加载项项目由一个项目文件夹管理。
3. `project.json` 保存当前设计。
4. “给 AI 的功能说明”会影响后面 AI 写代码的质量。
5. 预览只能检查界面，按钮功能要后面再实现。

## 课后练习

创建一个自己的功能区项目，至少包含：

- 1 个选项卡：智能工具；
- 1 个分组：数据处理；
- 2 个按钮：自动排序、添加 ROUND；
- 每个按钮都填写短提示、详细提示和给 AI 的功能说明；
- 点击预览，确认 Excel 中能看到这个功能区。
