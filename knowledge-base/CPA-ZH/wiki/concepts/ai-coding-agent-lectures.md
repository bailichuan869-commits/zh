# Agent 篇讲义

## 学习目标

## CPA-ZH 落地点

| 主题 | 可落地用途 |
|---|---|
| Skill 使用和创建 | 为会计准则咨询、底稿复核、案例卡片加工建立专用 Skill |
| Excel Agent | 读取和复核 Excel 底稿、生成辅助分析、定位异常数据 |
| 浏览器接管 | 在登录态网站或监管网站中辅助抓取页面、核验链接 |
| 本地知识库 | 理解 CPA-ZH 的 raw/wiki/cache/search 分层 |
| LLM-WIKI | 支撑新增资料、交叉引用、来源说明和健康检查 |
