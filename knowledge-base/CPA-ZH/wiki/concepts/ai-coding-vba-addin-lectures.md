# VBA 插件篇讲义

## 学习目标

VBA 插件篇围绕 Excel 加载项、功能区按钮、菜单、下拉框、窗体、工程保护和常见底稿处理功能展开。它适合把审计人员日常 Excel 操作沉淀为按钮化、菜单化、可分发的工具。

## CPA-ZH 落地点

| 主题 | 可落地用途 |
|---|---|
| 功能区与按钮 | 把高频底稿动作做成菜单和按钮，降低重复操作 |
| 下拉框、输入框、复选框 | 为底稿工具增加参数输入和状态保存 |
| VBA 窗体 | 承载更复杂的交互式审计小工具 |
| 工程保护边界 | 理解插件分发、源码保护和可维护性取舍 |
| 加载项实战 | ROUND、提取字符、清除非公式、批量链接、生成目录、断链删表、拆分工作簿等 |

## 后续加工

1. 按“底稿整理、公式处理、链接处理、工作表管理、格式输出”重组实战功能。
2. 为每个加载项功能补充适用场景、输入范围、风险点和人工复核要求。
3. 与 Python 篇形成 VBA/Python 选型对照表。
