# 中国注册会计师独立性准则第1号

全称：《中国注册会计师独立性准则第1号——财务报表审计和审阅业务对独立性的要求》。

本准则由财政部以财会〔2024〕29号印发，配套应用指南由中国注册会计师协会于 2026-02-13 发布并自发布之日起施行。2026 应用指南生效后，《中国注册会计师职业道德守则（2020）》中的第4号“审计和审阅业务对独立性的要求”同时废止。

## 核心定位

独立性准则第1号把职业道德中的独立性要求具体化到财务报表审计和审阅业务。它回答三个问题：

- 谁需要保持独立性；
- 在哪些期间、哪些关系、哪些服务中需要保持独立性；
- 当存在威胁时，哪些情形可以采取防范措施，哪些情形必须禁止或退出。

## 高频独立性威胁

| 威胁类型 | 典型事项 | 审计处理 |
|---|---|---|
| 自身利益 | 持有客户权益、收费依赖、或有收费、贷款担保 | 处置利益、调整收费安排、退出业务 |
| 自我评价 | 同时提供记账、估值、内控设计、系统实施等服务 | 评估是否禁止；不能降至可接受水平时不得承接或继续 |
| 倡导 | 代表客户融资、诉讼、推广证券发行 | 避免替客户立场背书 |
| 密切关系 | 长期服务、亲属在客户任职、关键岗位熟悉关系 | 轮换、回避、额外复核 |
| 外在压力 | 客户以解聘、压价、拖欠费用施压 | 升级沟通、质量复核、必要时终止业务 |

## 项目执行检查

| 节点 | 检查问题 | 留痕材料 |
|---|---|---|
| 客户承接 | 是否存在经济利益、亲属关系、商业关系或非鉴证服务冲突 | 独立性调查表、客户关系清单 |
| 项目组安排 | 项目组成员、网络所和专家是否独立 | 项目组独立性声明、网络所确认 |
| 非鉴证服务 | 是否为审计客户提供可能产生自我评价威胁的服务 | 非鉴证服务清单、合伙人审批 |
| 收费安排 | 是否存在收费依赖、或有收费、逾期收费影响 | 收费分析、治理层沟通 |
| 长期关系 | 关键审计合伙人是否需要轮换或冷却 | 任职年限台账、轮换计划 |
| 报告签发 | 独立性事项是否在签发前关闭 | 签发前独立性确认、复核结论 |

## 维护提示

- 独立性判断应同时看准则正文和应用指南；应用指南用于解释和举例，不增加额外要求。
- 职业道德守则第4号已被替代，历史页面仅用于理解版本演进。
- 本页后续应与第四板块的客户承接模板、独立性底稿模板和监管处罚案例联动。
