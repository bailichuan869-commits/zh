# qa-106

答：根据《企业会计准则第2号——长期股权投资》
第十一条并参考应用指南，对于被投资单位除净损益、其他综合收益以及利润分配以外所有者权益的其他变动，应当按持股比例计算应享有的份额，调整长期股权投资的账面价值，同时调整资本公积（其他资本公积）。当联营企业发生同一控制下企业合并时，投资方应基于联营企业合并日的所有者权益净变动额计算其享有的净资产份额，相应调整长期股权投资的账面价值，同时调整资本公积（其他资本公积）；但是对于联营企业因同一控制下企业合并还原被合并方合并日前留存收益、其他综合收益等引发的资本公积与留存收益、其他综合收益等的重分类调整，投资方无需就此对长期股权投资的账面价值进行调整。
