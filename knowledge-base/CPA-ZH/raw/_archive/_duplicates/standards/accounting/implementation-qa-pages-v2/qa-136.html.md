# qa-136

问：企业在执行《企业会计准则第14号——收入》（财会〔2017〕22号）时，对于给予客户的现金折扣应当如何进行会计处理？
答：企业在销售商品时给予客户的现金折扣，应当按照《企业会计准则第14
号——收入》（财会〔
2017〕22
号）中关于可变对价的相关规定进行会计处理。
