# qa-140

答：
根据《企业会计准则第
14号——收入》（财会〔2017〕
22号）的有关规定，通常情况下，企业商品或服务的控制权转移给客户之前、为了履行客户合同而发生的运输活动不构成单项履约义务，相关运输成本应当作为合同履约成本，采用与商品或服务收入确认相同的基础进行摊销计入当期损益。该合同履约成本应当在确认商品或服务收入时结转计入“主营业务成本”或“其他业务成本”科目，并在利润表“营业成本”项目中列示。
