# 企业会计准则体系

## 定义

企业会计准则是规范企业财务报告确认、计量、列报和披露的统一标准，由基本准则、具体准则、应用指南和解释公告构成。

## 说明

会计法回答“必须真实核算”，企业会计准则回答“怎么核算才算真实可比”。它是审计的标尺——审计意见是“报表是否符合企业会计准则”，因此注册会计师必须熟悉准则体系。竞赛把它列入法规与准则板块，说明准则层是执业判断的依据层。

## 核心原则

1. **层级递进**：基本准则统驭，具体准则细化，应用指南和解释补充。
2. **原则导向**：以原则为主，要求职业判断，不是纯规则清单。
3. **趋同国际**：与IFRS持续趋同，保留国情适配。
4. **动态更新**：新业务、新业态推动准则持续修订。

## 结构与步骤

| 层级 | 说明 | 示例 |
|------|------|------|
| 基本准则 | 统驭性原则，确立目标、假设、要素 | 《企业会计准则——基本准则》 |
| 具体准则 | 各类业务确认计量列报 | 收入、金融工具、租赁、所得税等42项 |
| 应用指南 | 操作性指引 | 各准则应用指南 |
| 解释公告 | 答复实务问题 | 企业会计准则解释第1-17号等 |

## 高频具体准则

| 准则 | 主题 | 审计关注 |
|------|------|----------|
| CAS14 | 收入 | 收入确认时点、履约义务、可变对价 |
| CAS22/23/24 | 金融工具 | 分类、减值、套期 |
| CAS21 | 租赁 | 使用权资产、租赁负债 |
| CAS18 | 所得税 | 递延所得税、暂时性差异 |
| CAS2 | 长期股权投资 | 成本法、权益法、转换 |
| CAS8 | 资产减值 | 减值测试、商誉减值 |
| CAS36 | 关联方披露 | 关联方识别、交易披露 |
| CAS20 | 企业合并 | 同一控制与非同一控制 |

## 常见考点

- 基本准则确立会计要素（资产、负债、所有者权益、收入、费用、利润）和确认计量原则。
- 收入准则（CAS14）五步法：识别合同、识别履约义务、确定交易价格、分摊交易价格、确认收入。
- 金融工具“三分类”和预期信用损失减值模型。
- 租赁准则下承租人不再区分经营租赁和融资租赁，统一确认使用权资产。
- 商誉减值不得转回，且需进行减值测试。
- 关联方披露要求识别关联关系和关联交易。

## 易混点

- “基本准则”与“具体准则”：前者是统驭原则，后者是具体业务规则。
- “同一控制下企业合并”与“非同一控制”：前者按账面价值，后者按公允价值。
- “收入”准则新旧版：新收入准则（CAS14修订）用五步法替代原建造合同。

## 典型场景

### 场景 1：收入确认时点争议
抓手：CAS14五步法，判断是时点确认还是时段确认。

### 场景 2：商誉减值是否计提
抓手：CAS8减值测试，先分摊商誉到资产组，再测试可收回金额。
