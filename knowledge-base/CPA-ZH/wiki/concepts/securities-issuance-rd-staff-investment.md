## 使用场景

该指引适合在以下场景中作为监管口径入口：

| 场景 | 关注重点 |
|---|---|
| IPO 或再融资申报 | 研发人员口径、研发投入归集、研发费用真实性和完整性 |
| 高新技术或科创属性论证 | 研发团队稳定性、研发活动与主营业务匹配性 |
| 研发费用审计 | 人员工时、薪酬分摊、材料和折旧摊销归集、资本化与费用化边界 |
| 申报文件披露复核 | 研发人员数量、研发投入金额、研发费用率、同行业可比性 |
| 监管问询回复 | 研发项目、人员、投入和成果之间的匹配关系 |

## 规则框架

根据证监会官网原文页，本指引主要包括五个部分：

| 部分 | 核心内容 |
|---|---|
| 研发人员认定 | 明确研发人员范围，关注非全时研发人员、受托研发人员和聘用形式 |
| 研发投入认定 | 明确研发投入计算口径，覆盖薪酬、共用资源、国拨研发项目、受托研发、委外研发和研发产出产品 |
| 相关内控要求 | 要求发行人建立研发活动、人员认定、项目管理、人员管理和研发支出归集相关内控制度 |
| 核查要求 | 要求保荐机构、申报会计师和发行人律师围绕研发活动、人员、投入、内控和披露发表核查意见 |
| 信息披露 | 要求在招股说明书中披露研发人员口径、人员结构、研发投入口径、金额和构成等信息 |

## 关键口径

| 事项 | 监管关注 |
|---|---|
| 非全时研发人员 | 需要关注研发工时占比和实际贡献，不能简单按部门或头衔认定 |
| 劳务派遣或其他合同人员 | 原则上研发人员应与发行人签订劳动合同；其他形式需要审慎论证合理性 |
| 研发投入计算 | 原则上以本期费用化研发费用与本期资本化开发支出之和为基础 |
| 共用资源费用 | 设备、产线、场地等共用资源需有准确记录和合理分配标准 |
| 国拨研发项目 | 需结合项目目的、成果权属和适用准则判断研发支出核算 |
| 受托研发 | 若发行人无法控制研发成果，相关支出原则上不得计入研发投入 |
| 委外研发 | 需关注真实性、必要性、公允性、成果归属和是否存在虚构研发支出 |
| 研发过程产出产品 | 产出产品或副产品应按相关准则确认资产、收入和成本，原则上其成本不得计入研发投入 |

## 审计关注点

在使用本规则处理研发费用底稿时，可将本页作为索引入口，重点关注以下事项：

| 关注点 | 底稿动作 |
|---|---|
| 研发人员认定口径 | 核对花名册、岗位职责、劳动合同、社保薪酬、研发项目参与记录 |
| 研发人员数量变化 | 分析期初期末人数、平均人数、核心研发人员变动和离职原因 |
| 研发投入归集范围 | 复核人工、材料、折旧摊销、委外研发、测试费等归集口径 |
| 研发费用分摊 | 检查工时记录、项目台账、费用分摊方法和一致性 |
| 资本化与费用化边界 | 连接 [[concepts/accounting-standards/cas-06]]，检查研究阶段和开发阶段划分依据 |
| 披露一致性 | 核对招股说明书、审计报告、研发费用明细表、所得税加计扣除资料之间是否一致 |
