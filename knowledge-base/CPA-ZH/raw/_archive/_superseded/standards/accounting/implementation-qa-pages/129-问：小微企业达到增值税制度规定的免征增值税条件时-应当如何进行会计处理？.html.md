# 问：小微企业达到增值税制度规定的免征增值税条件时-应当如何进行会计处理？

问：小微企业达到增值税制度规定的免征增值税条件时，应当如何进行会计处理？
答：对于小微企业达到增值税制度规定的免征增值税条件时，应当按照《增值税会计处理规定》（财会〔
2016〕22
号）的相关规定进行会计处理，将有关应交增值税转入“其他收益”科目。
