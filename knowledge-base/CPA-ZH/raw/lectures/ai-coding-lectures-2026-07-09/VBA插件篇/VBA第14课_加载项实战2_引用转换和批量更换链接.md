# VBA第14课：加载项实战 2：引用转换和批量更换链接

## 这一节要做什么

上一节我们完成了“公式函数”组里的几个常用功能：

```text
添加 ROUND
提取数字 / 英文 / 中文
清除非公式
```

这一节继续完善“公式函数”组，再做两个功能：

```text
相对引用 / 绝对引用互转
批量更换外部链接
```

这两个功能都和公式有关，但复杂度不一样。

引用转换比较简单；批量更换链接会涉及交互设计、映射表、外部链接识别和替换。

## 本节你会学到

- 怎么用菜单收纳一组互转功能。
- 怎么实现相对引用和绝对引用互转。
- 为什么要优先使用 Excel 自带 COM 接口，而不是自己用正则硬改公式。
- 怎么设计“批量更换链接”的交互流程。
- 怎么把当前工作簿的外部链接输出成映射表。
- 怎么根据映射表批量替换外部链接。
- 怎么测试外部链接是否真的替换成功。
- 为什么要多问 AI：“有没有更好的实现方法？”

## 功能 1：相对引用和绝对引用互转

Excel 公式里经常会出现相对引用和绝对引用。

例如：

```excel
=A1
=$A$1
```

它们的区别是：

- `A1`：相对引用；
- `$A$1`：绝对引用。

这一节做两个按钮：

```text
相对引用转绝对引用
绝对引用转相对引用
```

## 第一步：用菜单收纳引用转换

因为这是两个互相关联的功能，所以更适合放在一个菜单里。

在“公式函数”分组里新增一个菜单：

```text
相对绝对转换
```

菜单下面放两个按钮：

```text
相对引用转绝对引用
绝对引用转相对引用
```

给 AI 的功能说明可以分别写：

```text
将选中区域单元格中的相对引用公式转为绝对引用公式。
跳过空单元格和非公式单元格。
不要影响未选中的区域。
```

```text
将选中区域单元格中的绝对引用公式转为相对引用公式。
跳过空单元格和非公式单元格。
不要影响未选中的区域。
```

配置后，关闭 `final.xlsm`，导出设计。

## 第二步：让 AI 实现引用转换

用 VS Code 打开项目根目录。

在 AI 终端中说：

```text
实现相对引用转绝对引用，以及绝对引用转相对引用。
先用 plan 模式。
```

这里有一个实战经验：

AI 可能会先想到用正则表达式去改公式文本。

正则也能做，但不一定最稳。

因为 Excel 自己就有处理引用类型的能力。

所以可以继续追问：

```text
这个功能除了正则，还有没有更好的实现方式？
能不能使用 Excel 自带的 COM 接口？
```

对于引用转换这种功能，更推荐使用 Excel 自带能力，而不是自己解析公式字符串。

## 为什么优先用 Excel 自带接口

公式引用看起来只是字符串，但实际会遇到很多复杂情况：

- 跨工作表引用；
- 带工作簿名的外部引用；
- 混合引用，例如 `$A1`、`A$1`；
- 函数嵌套；
- 区域引用；
- 表格引用；
- 名称引用。

如果只用正则，很容易漏掉边界情况。

Excel 自己提供的接口更了解公式结构，所以通常更可靠。

这就是实战里很重要的一点：

> AI 能写代码，但你要学会判断它用的方法是不是合适。

## 第三步：测试引用转换

打开：

```text
workbooks/final.xlsm
```

在单元格里输入一个公式：

```excel
=A1
```

向下或向右复制几格。

选中这些公式区域，点击：

```text
相对绝对转换 → 相对引用转绝对引用
```

正常结果应该变成类似：

```excel
=$A$1
```

再点击：

```text
相对绝对转换 → 绝对引用转相对引用
```

正常结果应该回到类似：

```excel
=A1
```

测试通过后，这个功能就完成了。

## 功能 2：批量更换外部链接

第二个功能更复杂。

很多 Excel 文件里会引用其他工作簿。

例如：

```excel
='D:\项目\旧文件.xlsx'!A1
```

如果文件迁移、重命名、路径变化，就需要批量把旧链接换成新链接。

手动一个个改很麻烦。

所以我们做一个：

```text
批量更换链接
```

## 先设计交互流程

批量更换链接不要直接做成一个按钮就完事。

更合理的是分成两步：

```text
获取当前链接
  ↓
用户填写新链接
  ↓
开始更换链接
```

所以这里继续用菜单。

在“公式函数”组里新增菜单：

```text
批量更换链接
```

菜单下放两个按钮：

```text
获取当前链接
开始更换链接
```

## 为什么要分成两个按钮

因为工具需要先知道当前工作簿里有哪些外部链接。

用户也需要一个地方填写：

```text
旧链接 → 新链接
```

所以第一步是生成一张映射表。

映射表可以长这样：

| 源链接 | 新链接 | 状态 |
| --- | --- | --- |
| D:\旧文件1.xlsx | D:\新文件1.xlsx | 待更换 |
| D:\旧文件2.xlsx | D:\新文件2.xlsx | 待更换 |

用户在 `新链接` 列填好新路径后，再点击“开始更换链接”。

## 配置“获取当前链接”

按钮名称：

```text
获取当前链接
```

给 AI 的功能说明可以写：

```text
获取当前工作簿中所有外部 Excel 文件链接。
新建一个工作表，用来输出链接映射表。
A 列表头为“源链接”。
B 列表头为“新链接”。
C 列表头为“状态”。
将当前工作簿中的旧链接填充到 A 列。
C 列默认填充“待更换”。
```

建议输出到新工作表，而不是当前工作表。

原因是：

> 当前工作表可能已经有业务数据，直接写 A 列可能覆盖用户内容。

## 配置“开始更换链接”

按钮名称：

```text
开始更换链接
```

给 AI 的功能说明可以写：

```text
读取链接映射表。
将 A 列中的源链接替换为 B 列中的新链接。
替换成功后，将 C 列状态改为“已完成”。
如果替换失败，将 C 列状态改为“替换失败”，并保留错误信息。
跳过 B 列为空的行。
```

配置好两个按钮后，关闭 `final.xlsm`，导出设计。

## 让 AI 先规划链接替换

在 AI 终端中说：

```text
计划实现“获取当前链接”和“开始更换链接”。
先写计划，先问我需要确认的问题，不要直接写代码。
```

AI 可能会问：

### 链接指的是哪种链接

这里要明确：

```text
公式中引用其他 Excel 文件形成的外部链接。
```

不是网页超链接，也不是数据连接。

### 链接映射表输出到哪里

建议选择：

```text
新建一个工作表输出映射表。
```

避免覆盖当前工作表数据。

### 新链接从哪里来

建议选择：

```text
用户在映射表 B 列中填写新链接。
```

不要每个链接都弹窗让用户一个个选，这样太麻烦。

## 再次提醒：优先使用 COM 接口

AI 可能会先用正则扫描公式，再替换公式里的路径。

这种方式能做，但不够稳。

对于外部链接，Excel 本身也有专门的链接管理和更换方法。

所以你可以继续问：

```text
除了正则替换公式字符串，是否可以使用 Excel 自带的 COM 接口来获取和更换链接？
请优先使用更可靠的 COM 接口。
```

这类问题要多问。

尤其是涉及 Excel 内部能力时，很多功能 Excel 自己已经提供了接口。

## 测试批量更换链接

测试这个功能时，需要准备带外部链接的工作簿。

可以这样做：

1. 新建几个测试工作簿，例如：

```text
副本2.xlsx
副本3.xlsx
```

2. 在 `final.xlsm` 里写公式引用这些文件。

例如：

```excel
='D:\测试\副本2.xlsx'!A1
='D:\测试\副本3.xlsx'!A1
```

3. 保存并关闭被引用的工作簿。
4. 在加载项里点击：

```text
批量更换链接 → 获取当前链接
```

正常结果：

- 新建一个链接映射表；
- A 列列出当前工作簿里的外部链接；
- B 列留给用户填写新链接；
- C 列显示“待更换”。

## 填写新链接并开始更换

在映射表里填写新链接。

例如：

| 源链接 | 新链接 | 状态 |
| --- | --- | --- |
| D:\测试\副本2.xlsx | D:\测试\新副本2.xlsx | 待更换 |
| D:\测试\副本3.xlsx | D:\测试\新副本3.xlsx | 待更换 |

然后点击：

```text
批量更换链接 → 开始更换链接
```

正常结果：

- 链接被替换；
- 状态列变成“已完成”；
- 如果失败，对应行显示“替换失败”。

## 验证链接是否真的换了

更换完成后，不要只看提示框。

还要检查公式里引用的路径是否真的变化。

可以选中公式单元格，查看公式栏。

也可以用 Excel 的快捷键追踪引用。

测试重点：

- 旧路径是否已经被替换；
- 新路径是否正确；
- 多个链接是否都处理了；
- 状态列是否更新；
- 没填写新链接的行是否被跳过。

## 给菜单补图标

功能完成后，再给菜单补图标。

例如：

- “相对绝对转换”可以用“引用”相关图标；
- “批量更换链接”可以用“链接”相关图标。

可以到阿里巴巴矢量图标库搜索：

```text
引用
链接
```

下载统一风格的 PNG 图标。

建议使用相同色系，例如灰色系，让整个加载项看起来更统一。

补完图标后，记得重新导出设计。

如果导出失败，先检查 `final.xlsm` 是否还开着。

## 导出设计会不会覆盖已写代码

正常情况下，导出设计主要更新：

- 功能区 XML；
- 按钮回调；
- 图标资源；
- 项目说明。

不会覆盖已经写好的业务实现代码。

所以按钮图标和菜单设计调整后，可以重新导出设计。

但导出前仍然要关闭 `final.xlsm`。

## 常见问题

### AI 为什么总喜欢用正则

因为很多公式本质上是文本，AI 很容易想到“扫描字符串并替换”。

但 Excel 公式并不只是普通文本。

遇到引用、链接、名称、工作表、工作簿路径时，优先问问：

```text
Excel 有没有现成 COM 接口？
```

### 正则一定不能用吗

不是。

简单文本处理可以用正则。

但涉及 Excel 内部结构时，COM 接口通常更稳。

### 获取链接时为什么要新建工作表

为了避免覆盖当前工作表内容。

映射表是一个中间表，新建出来更安全。

### 为什么批量更换链接要分两步

因为用户需要确认旧链接和新链接的对应关系。

直接一键替换风险太高。

分成：

```text
获取当前链接 → 填写新链接 → 开始更换链接
```

更安全，也更容易检查。

### 替换后状态显示失败怎么办

检查：

- 新链接路径是否存在；
- 新链接是否拼写正确；
- 文件是否被移动；
- 工作簿是否有权限访问；
- B 列是否为空。

## 本节记住这五点

1. 两个互转功能适合放进同一个菜单。
2. 引用转换优先使用 Excel 自带接口，不要盲目正则改公式。
3. 批量链接替换要先生成映射表，再执行替换。
4. AI 给出的方案可以用，但要多问“有没有更好的实现方式”。
5. 功能完成后再补图标和界面细节。

## 课后练习

给“公式函数”组继续补一个功能：

```text
检查外部链接
```

功能说明可以写：

```text
扫描当前工作簿中的所有外部链接。
新建一个工作表输出链接清单。
列出链接路径、引用次数、是否能访问。
如果链接不可访问，将状态标记为“不可访问”。
```

完成标准：

1. 在“公式函数”组里新增按钮。
2. 写清楚给 AI 的功能说明。
3. 导出设计。
4. 让 AI 先用 plan 模式。
5. 优先询问是否可以使用 Excel COM 接口。
6. 打开 `final.xlsm` 手动验证。
