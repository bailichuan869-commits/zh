# Agent第03课：Excel Agent 使用入门

## 这一节要做什么

前面我们已经讲过 Agent 的基本概念，也讲过 Skill 如何把一类任务的经验沉淀下来。

这一节开始看一个更具体的 Agent：

```text
CPH 里的 Excel Agent
```

它不是普通聊天窗口，而是一个带有 Excel 工具、财务查询工具、账套查询工具、VBA/Python 扩展能力的智能助手。

这一节先不追求把所有功能都学完，而是先知道：

> Excel Agent 能做什么，以及它适合放在哪些财审工作场景里。

## 本节你会学到

- 怎么打开 Excel Agent。
- Excel Agent 自带哪些工具能力。
- 怎么让它查看当前选区并写入数据。
- 怎么让它生成透视表、图表和分析说明。
- 怎么把一次成功的分析流程沉淀成 Skill。
- `/` 和 `@` 两种交互方式有什么区别。
- 怎么查询 A 股上市公司报表。
- 怎么用区域引用让 AI 帮你写公式。
- 怎么让 Agent 查询本地账套。
- 什么时候用内置工具，什么时候让它写 VBA 或 Python。

## 打开 Excel Agent

在 CPH 工具里，进入：

```text
通用 → 智能助手
```

Excel 左侧会出现一个侧边栏。

这个侧边栏就是 Excel Agent 的对话入口。

你可以直接在这里输入需求，例如：

```text
模拟一组销售数据，填写在当前选中的区域。
```

Agent 会根据当前 Excel 环境和它拥有的工具，去判断应该怎么完成任务。

## 先问它有哪些能力

可以先点击或输入：

```text
我有哪些能力
```

Excel Agent 会根据系统提示词和工具 schema，列出它当前能调用的工具。

常见能力包括：

- 读取当前工作簿；
- 读取当前选区；
- 写入单元格；
- 操作 Sheet；
- 操作名称区域；
- 设置格式；
- 创建透视表；
- 创建图表；
- 筛选排序；
- 复制数据到新表；
- 使用 Excel 公式进行计算；
- 查询 A 股上市公司报表；
- 查询本地账套；
- 写 SQL；
- 写 VBA；
- 写 Python；
- 执行命令行；
- 加载 Skill。

这些能力的核心是：

> Agent 不只是会回答，它能通过工具操作 Excel 和本地数据。

## 为什么要有 Excel 计算器

大模型直接算数时可能会错。

所以 Excel Agent 里专门准备了 Excel 计算相关能力。

它可以生成一个 Excel 计算过程，用公式来完成计算。

这样有两个好处：

- 计算结果可追溯；
- 你可以看到公式过程，而不是只相信模型口算。

在财审场景里，这一点很重要。

不要让模型凭感觉算数，尽量让它用 Excel、SQL 或代码来算。

## 示例 1：生成一组销售数据

先在 Excel 中选中一个区域。

然后输入：

```text
模拟一组销售数据，填写在当前的区域。
```

Agent 会读取当前选区，知道你选中了哪里。

然后调用写入工具，把销售数据写入选中的区域。

写完后，你可以继续要求：

```text
日期列格式有问题，帮我调整一下。
再加一个好看点的样式。
加一个合计行，用公式。
```

它可能会继续：

- 修改日期格式；
- 加粗表头；
- 设置边框；
- 设置居中；
- 添加合计公式；
- 给合计行加底色。

如果模型比较快但不够细，你可以继续提醒它修正。

## 模型选择：速度和质量要权衡

课程里演示时使用了速度较快的模型。

这类模型特点是：

- 反应快；
- 成本低；
- 干活麻利；
- 但有时不够仔细。

更强的模型可能：

- 一次成功率更高；
- 图表、格式、复杂逻辑更稳；
- 但速度慢、成本高。

所以不是所有任务都必须用最强模型。

可以按任务选择：

| 场景 | 推荐 |
| --- | --- |
| 简单写入、简单格式 | 快速模型 |
| 复杂分析、复杂图表 | 更强模型 |
| 关键底稿、重要输出 | 更强模型 + 人工复核 |

## 示例 2：创建透视表、图表和分析说明

在已有销售数据的基础上，可以继续要求：

```text
创建一个透视表。
再创建一个图。
写一个分析说明。
```

Agent 可能会：

1. 读取数据区域。
2. 创建透视表。
3. 把销售区域放到列字段。
4. 把商品名称放到行字段。
5. 汇总销售额。
6. 创建柱状图。
7. 在图表下方写分析说明。

如果图表选区不对，可以直接指出：

```text
这个图好像没有选择正确的数据区域，请重新创建。
```

Agent 会继续调用工具修正。

这就是 Agent 的特点：

> 它可以在一次任务中多轮观察、行动和修正。

## 把成功流程沉淀为 Skill

如果你觉得这次分析流程以后还会重复使用，可以把它沉淀成 Skill。

例如：

```text
把刚刚的流程写为一个分析销售费用的 Skill。
```

Agent 会调用 Skill Creator，把刚才的流程整理成一个 Skill。

Skill 中可能包括：

- 数据要求；
- 生成表格；
- 美化表格；
- 创建透视表；
- 创建图表；
- 编写分析说明；
- 输出格式；
- 注意事项。

以后遇到类似任务，就可以直接引用这个 Skill。

这样你就不是每次重新写提示词，而是在沉淀一套可复用的方法。

## `/`：调用 Skill

在对话框中输入：

```text
/
```

可以召唤当前可用的 Skill。

例如：

- 查询功能手册；
- Skill Creator；
- 账套 Viewer；
- 你自己沉淀的销售分析 Skill。

如果你想问某个插件功能怎么用，可以使用功能手册类 Skill。

如果你想把流程沉淀成 Skill，可以使用 Skill Creator。

`/` 更像是：

```text
我要加载一份操作手册。
```

## `@`：强制指定工具

除了 `/` 引用 Skill，还可以用：

```text
@
```

来指定某个工具。

正常情况下，Agent 会自动判断要不要调用工具。

但如果它没有主动调用，你可以强制指定。

例如：

```text
@查询A股上市公司报表 查询贵州茅台的报表
```

或者：

```text
@VBA 帮我设置每个 Sheet 打印为一页
```

`@` 更像是：

```text
我明确指定你用这个工具。
```

## 示例 3：查询 A 股上市公司报表

Excel Agent 中可以接入 A 股上市公司报表查询能力。

例如：

```text
查询贵州茅台最近几期的财务报表，并写入 Excel。
```

Agent 可以调用报表查询工具，把数据写入多个 Sheet。

常见输出可能包括：

- 资产负债表；
- 利润表；
- 现金流量表；
- 最近几期数据。

这类工具的价值是：

> 不需要手动去网页下载、复制、整理，Agent 可以直接把结构化结果写入 Excel。

## 示例 4：区域引用，让 AI 写公式

Excel Agent 里有一个很实用的能力：

```text
区域引用
```

你可以先选中一个区域，点击引用。

再选中另一个区域，继续引用。

比如：

- 区域 1：需要填写公式的空白区域；
- 区域 2：数据源区域。

然后输入：

```text
按区域 2 的数据，填写区域 1 的公式。
```

Agent 会读取两个区域的结构，理解字段关系，然后尝试写公式。

比如生成：

- `SUMIF`；
- `VLOOKUP`；
- `XLOOKUP`；
- 汇总公式；
- 分类统计公式。

这个功能适合：

- 写复杂公式；
- 看不清字段关系时让 AI 判断；
- 让 AI 根据样例结构补公式。

## 示例 5：查询本地账套

如果已经通过看账工具导入了账套数据库，Agent 也可以查询本地账套。

可以使用账套相关 Skill，例如：

```text
/账套 Viewer
```

然后输入：

```text
看一下账套里面管理费用的情况。
```

Agent 可能会：

1. 查看数据库结构；
2. 判断序时账表在哪里；
3. 写 SQL 查询管理费用；
4. 汇总明细科目；
5. 分析金额变动；
6. 把结果写入当前 Sheet。

如果它找错表或字段，可以继续纠正。

这类能力的关键是：

> Agent 可以自己写 SQL 去账套里取数，再把结果写回 Excel。

## 示例 6：用 VBA 扩展能力

如果现有工具不够用，可以让 Agent 临时写 VBA。

例如：

```text
@VBA 帮我设置一下打印格式，每个 Sheet 都只有一页。
```

Agent 会生成并执行 VBA 代码，批量设置打印缩放。

执行这类操作时通常会要求你确认。

因为 VBA 能修改工作簿，甚至影响很多 Sheet。

使用时要注意：

- 先在测试文件上运行；
- 看清楚它要做什么；
- 重要文件先备份；
- 必要时只允许本次执行。

## 示例 7：用 Python 扩展到 Excel 之外

如果任务超出 Excel，比如操作文件夹、处理大量文件、调用外部程序，也可以让 Agent 写 Python。

但前提是：

```text
你的电脑需要安装 Python 环境。
```

Python 能力更强，风险也更大。

它可能操作本地文件、文件夹和系统环境。

所以使用 Python 时更要谨慎：

- 先确认代码意图；
- 先用测试目录；
- 不要直接处理正式资料；
- 对删除、移动、覆盖等操作特别小心。

## Excel Agent 的工作方式

你可以把 Excel Agent 理解成：

```text
对话入口
  ↓
模型理解任务
  ↓
读取当前 Excel 环境
  ↓
按需调用工具
  ↓
写回 Excel
  ↓
你检查结果并继续反馈
```

它不是一次就一定完美。

你需要像带助理一样：

- 给清楚目标；
- 看它做出的结果；
- 指出哪里不对；
- 让它继续修；
- 把稳定流程沉淀成 Skill。

## 什么时候适合用 Excel Agent

适合：

- 需要读取当前 Excel 内容；
- 需要快速生成示例数据；
- 需要写公式；
- 需要创建透视表；
- 需要生成图表；
- 需要查账套；
- 需要查外部财务报表；
- 需要把分析结果写回 Excel；
- 需要临时写 VBA 或 Python 完成任务。

不适合：

- 完全不允许出错的正式结果；
- 没有人复核的关键底稿；
- 大批量不可逆操作；
- 你完全不知道它在做什么的危险操作。

Agent 是助理，不是无人驾驶。

## 使用建议

### 1. 先选区域，再提需求

如果任务和当前区域有关，先选中区域。

再说：

```text
对当前选区执行……
```

这样 Agent 更容易知道范围。

### 2. 让它先说明计划

复杂任务可以先说：

```text
先说明你准备怎么做，不要直接写入。
```

这样更安全。

### 3. 重要数据先备份

涉及写入、覆盖、删除、重命名时，先备份。

### 4. 工具不够时再用 VBA / Python

优先使用内置工具。

内置工具更可控。

工具做不到，再考虑 VBA 或 Python。

### 5. 好流程要沉淀为 Skill

如果一套流程你会重复使用，就把它沉淀成 Skill。

不要每次重新从零提示。

## 本节记住这七点

1. Excel Agent 是 Excel 里的智能助手入口。
2. 它的能力来自模型、提示词、工具和 Skill。
3. 它可以读取当前选区，也可以写回 Excel。
4. `/` 用来调用 Skill，`@` 用来指定工具。
5. 区域引用很适合让 AI 帮你写复杂公式。
6. 查询账套、查询报表、写 VBA/Python 都是工具能力。
7. Agent 做完结果后一定要检查，稳定流程要沉淀成 Skill。

## 课后练习

用 Excel Agent 完成一个小任务。

建议任务：

```text
生成一组销售数据，创建透视表和图表，并写一段分析说明。
```

完成后继续做：

1. 让它调整表格格式。
2. 如果图表不对，指出问题并让它修正。
3. 把这套流程沉淀成一个 Skill。
4. 重新开一个会话，尝试调用这个 Skill。

练习重点不是一次成功，而是体验：

```text
提出需求 → Agent 调工具 → 你检查结果 → 修正 → 沉淀 Skill
```
