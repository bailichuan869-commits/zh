# 案例分析

## 定位

用于沉淀审计实务案例、监管处罚案例、复杂会计处理案例和综合执业能力训练案例。

案例库采用两层维护：

| 层级 | 位置 | 用途 |
|---|---|---|
| 原始资料层 | `raw/cases/` | 保留用户提供的原文件，不直接改写 |
| 案例卡片层 | `wiki/cases/` 或专题页 | 提炼事实、规则、判断、审计应对和可复用经验 |

## 推荐模板

1. 事实背景；
2. 关键风险；
3. 适用法规、准则或政策；
4. 审计程序与证据；
5. 判断过程；
6. 结论与责任；
7. 可复用经验。

## 分类标签

后续案例卡片建议同时按以下维度打标签：

| 维度 | 示例 |
|---|---|
| 会计主题 | 收入确认、政府补助、长期股权投资、固定资产、所得税 |
| 审计主题 | 风险识别、审计证据、会计估计、管理层判断、底稿留痕 |
| 风险类型 | 截止、完整性、准确性、分类、列报、独立性、职业道德 |
| 资料来源 | 内部研讨、监管处罚、项目复盘、底稿复核、公开案例 |
| 加工状态 | raw-imported、case-card-drafted、reviewed、linked-to-standards |
