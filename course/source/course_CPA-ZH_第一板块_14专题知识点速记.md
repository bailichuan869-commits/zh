## 1. 收入确认错报风险

### 1）一句话定位与常见触发场景

收入审计的实质是回答：**客户合同中的履约义务是否真实完成，控制权是否在正确期间转移，确认金额是否恰当。** 常见触发场景包括期末突击销售、提前确认、虚构或循环交易、平台及代理模式、售后回购、重大退货权、可变对价和合同变更。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/revenue-recognition-misstatement.md)；法律责任重点见[会计法第3条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-003.md)、[第9条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-009.md)、[证券法第197条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-197.md)。

### 2）核心会计判断及对应 CAS

- 按“识别合同 -> 识别履约义务 -> 确定交易价格 -> 分摊交易价格 -> 履约时确认收入”的五步法判断，入口为[CAS 14 收入](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-14.md)。
- 关键不是发票或回款，而是商品或服务的**控制权转移**；同时区分时点履约和时段履约。
- 可变对价只在“极可能不会发生重大转回”的范围内计入交易价格。
- 合同资产取决于除时间以外的其他条件，应收款主要只剩时间条件；合同负债是已收或应收对价但尚未履约。
- 列报和披露连接[CAS 30 财务报表列报](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-30.md)。

### 3）主要错报风险与易错点

- **发生、截止风险：**虚构客户或订单、期末提前发货、验收条件未满足、期后退货未反映。
- **准确性风险：**可变对价估计偏乐观，折扣、返利、退货和重大融资成分遗漏。
- **分类风险：**主要责任人与代理人判断错误，净额收入做成总额；合同资产与应收款混列。
- **易错点：**“开票、发货、收款”都不是自动确认收入的充分条件，必须回到合同和控制权。

### 4）审计程序、关键证据及对应 CSA

- 将收入视为舞弊风险的推定起点，识别管理层凌驾和异常分录：[CSA 1141](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1141.md)、[CSA 1211](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1211.md)。
- 检查合同、订单、发货、签收或验收、发票、回款及期后退货，实施双向截止测试：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)、[CSA 1313](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1313.md)。
- 对应收账款和合同资产实施函证并调查差异：[CSA 1312](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1312.md)。
- 对新模式、异常毛利、期末大额或手工分录开展针对性程序，并核对年报其他信息。

### 5）底稿闭环与报告影响

底稿最短闭环：**合同条款 -> 履约义务 -> 控制权证据 -> 收入分录 -> 回款 -> 期后退货**。重大事项形成单独判断备忘；若属于审计中最重要事项，考虑[CSA 1504 关键审计事项](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1504.md)；错报未调整或证据受限时回到[CSA 1501](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1501.md)评价意见影响。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先合同，分义务；定价格，再分摊；看控制，才确认。”

| 易混项 | 判断抓手 |
|---|---|
| 合同资产 vs 应收款 | 收款权是否还取决于除时间以外的条件 |
| 主要责任人 vs 代理人 | 向客户转让前是否控制承诺的商品或服务 |

1. **判断题：**客户已全额付款，企业即使尚未履约也可以确认收入。
2. **情景题：**12月30日发货、次年1月5日验收，合同约定验收后客户才取得控制权。收入应在哪个年度确认？

<details><summary>答案</summary>

1. 错。收款不等于履约，通常先确认合同负债。  
2. 次年。控制权在验收时转移，不能仅按发货日确认。

</details>

## 2. 金融工具估值与减值

### 1）一句话定位与常见触发场景

金融工具专题要从**合同权利义务**出发，依次判断分类、计量、减值、终止确认和披露。高频场景包括债权投资分类、应收款预期信用损失、公允价值估值、非活跃市场报价、可转债和永续债的负债权益区分。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/financial-instruments-valuation-impairment.md)；法律责任重点见[会计法第13条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-013.md)、[证券法第163条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-163.md)。

### 2）核心会计判断及对应 CAS

- 金融资产分类同时看**业务模式**和**合同现金流量特征（SPPI）**，入口为[CAS 22 金融工具确认和计量](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-22.md)。
- 预期信用损失（ECL）是对未来信用损失的概率加权估计，不是等到实际违约才计提。
- 公允价值估值应识别活跃市场、估值技术、关键输入和层次；模型复杂不等于结果可靠。
- 从发行方合同义务判断金融负债还是权益工具，列报入口为[CAS 37 金融工具列报](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-37.md)。

### 3）主要错报风险与易错点

- 分类依据与企业真实持有和管理方式不一致，或SPPI判断缺少合同条款支持。
- ECL阶段划分、违约概率、损失率、前瞻性情景和管理层覆盖调整过度乐观。
- 采用不可观察参数但缺少敏感性分析，选择性使用市场报价。
- 只看工具名称判断“股或债”，忽略发行人是否承担交付现金的合同义务。

### 4）审计程序、关键证据及对应 CSA

- 获取金融工具清单并逐项勾稽合同、业务模式、现金流量特征、计量属性和报表列示。
- 测试估值模型、数据、假设、阶段划分和前瞻性调整，关注管理层偏向：[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)。
- 必要时利用专家并评价其胜任能力、客观性和工作恰当性：[CSA 1421](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1421.md)。
- 以市场数据、外部评级、期后回款等证据验证模型输入：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。

### 5）底稿闭环与报告影响

底稿最短闭环：**合同条款 -> 分类依据 -> 模型与数据 -> 关键参数 -> 敏感性 -> 会计分录及披露**。对管理层覆盖调整、非活跃市场报价和重大敏感性结果单独形成判断；重大复杂估值通常需要同步评价关键审计事项和披露充分性。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先看合同定权义，再看模式和现金；模型数据双验证，负债权益看偿付。”

| 易混项 | 判断抓手 |
|---|---|
| 已发生损失 vs 预期信用损失 | 是否包含前瞻性、概率加权的未来损失 |
| 金融负债 vs 权益工具 | 发行人是否有不可避免的交付现金义务 |

1. **判断题：**未发生实际逾期，就无须确认预期信用损失。
2. **单选题：**判断债权金融资产分类时最核心的组合是：A.票面名称和期限；B.业务模式和SPPI；C.管理层意图和信用评级。

<details><summary>答案</summary>

1. 错。ECL本身就是前瞻性损失模型。  
2. B。

</details>

## 3. 政府补助和专项资金

### 1）一句话定位与常见触发场景

先判断取得的资源是否属于政府补助，再判断附带条件是否满足、与资产还是收益相关、何时确认及如何列报。常见场景包括产业扶持款、设备补助、研发专项资金、稳岗补贴、附验收或绩效条件的拨款。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/government-grants-special-funds.md)；法律责任重点见[会计法第9条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-009.md)、[第20条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-020.md)。

### 2）核心会计判断及对应 CAS

- 政府补助是企业从政府无偿取得的货币性或非货币性资产，不包括政府作为所有者投入的资本。
- 确认前需满足两个条件：企业能够满足所附条件，且能够收到补助；入口为[CAS 16 政府补助](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-16.md)。
- 与资产相关的补助按准则允许的方法递延配比或冲减资产账面价值；与收益相关的补助按补偿期间计入损益。
- 政府采购或购买服务若存在客户合同和对价交换，应先考虑[CAS 14](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-14.md)，不能仅因付款方是政府就按补助处理。

### 3）主要错报风险与易错点

- 仅凭批文或到账即确认，未评价验收、投入、就业或资金用途等附带条件。
- 将政府资本性投入误作补助，或将政府购买服务误作补助。
- 与资产相关、与收益相关分类错误，递延收益摊销期间与受益期间不匹配。
- 期末集中确认大额补助调节业绩，退回义务和专项资金限制披露不足。

### 4）审计程序、关键证据及对应 CSA

- 检查批文、申报材料、拨款流水、验收文件和资金使用台账：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 逐项复核条件是否满足、确认时点、分类及摊销基础，对估计运用[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)。
- 对期末大额确认、异常会计分录和业绩承诺项目关注舞弊风险：[CSA 1141](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1141.md)。
- 核对财务报表、政府公示、项目验收和年报其他信息的一致性。

### 5）底稿闭环与报告影响

底稿最短闭环：**政策和批文 -> 附带条件 -> 到账及使用 -> 验收证据 -> 分类与摊销 -> 披露**。存在退回可能时同步评价[CAS 13 或有事项](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-13.md)；重大未调整错报或披露不足进入审计意见评价。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先辨政府何身份，再看条件能否成；资产收益分两路，确认摊销要配比。”

| 易混项 | 判断抓手 |
|---|---|
| 政府补助 vs 政府采购 | 无偿取得，还是向政府交付商品或服务换取对价 |
| 与资产相关 vs 与收益相关 | 是否用于购建或形成长期资产 |

1. **判断题：**补助资金到账即表明所有附带条件已经满足。
2. **情景题：**政府按合同购买企业的数据服务，价格与市场一致，应优先按政府补助还是客户合同收入判断？

<details><summary>答案</summary>

1. 错。到账与满足条件是两个判断。  
2. 客户合同收入，优先按交易实质和CAS 14判断。

</details>

## 4. 职工薪酬

### 1）一句话定位与常见触发场景

职工薪酬审计要确认企业因职工提供服务承担的全部对价是否在正确期间、按正确金额计入正确项目。范围包括短期薪酬、离职后福利、辞退福利、其他长期福利、奖金、社保公积金，以及与股份支付和人员成本资本化的交叉事项。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/employee-benefits.md)；法律责任重点见[会计法第9条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-009.md)、[公司法第208条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-208.md)。

### 2）核心会计判断及对应 CAS

- 职工薪酬是企业为获得职工服务或解除劳动关系给予的各种形式报酬或补偿，入口为[CAS 9 职工薪酬](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-09.md)。
- 短期薪酬通常随服务期间确认；辞退福利要看企业是否已不能单方面撤回解除劳动关系计划。
- 设定提存计划以应缴存金额确认；涉及设定受益计划时关注精算假设及重新计量。
- 人员成本是费用化还是资本化，取决于职工服务的受益对象和相关资产准则，不取决于部门名称。

### 3）主要错报风险与易错点

- 少计未付奖金、社保公积金、年假等义务，或跨期计提和支付。
- 辞退计划尚可撤回却提前确认，或已不可撤回却延迟确认。
- 将日常管理或低效工时包装为研发、在建工程或存货成本。
- 高管奖金与业绩指标挂钩造成舞弊诱因；股份支付误混入普通薪酬。

### 4）审计程序、关键证据及对应 CSA

- 勾稽花名册、劳动合同、薪酬政策、考勤、工资表、银行流水及社保公积金记录：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 测试入离职、薪酬变更、审批、工资计算和付款控制：[CSA 1231](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1231.md)。
- 对奖金、辞退福利和长期激励检查批准程序、支付条件、截止及期后支付。
- 关注管理层奖金带来的舞弊动机，并测试人员成本资本化的工时和受益对象。

### 5）底稿闭环与报告影响

底稿最短闭环：**人员清单 -> 合同与政策 -> 考勤及工资计算 -> 审批 -> 银行支付 -> 成本费用分配**。重大未计提义务影响负债完整性；资本化不当影响资产、费用和利润，均需评价调整及报告后果。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“服务在哪期，薪酬归哪期；能否再撤回，决定辞退时点；资本化看受益，不看部门名。”

| 易混项 | 判断抓手 |
|---|---|
| 短期薪酬 vs 辞退福利 | 是换取职工服务，还是换取职工离职 |
| 费用化 vs 资本化人员成本 | 相关服务是否直接形成符合条件的资产 |

1. **判断题：**研发部门全部人员工资都应资本化。
2. **情景题：**企业已向职工公布不可撤回的裁员方案，预计支付补偿。是否仍等到实际付款才确认？

<details><summary>答案</summary>

1. 错。应按工作内容、受益对象及资本化条件判断。  
2. 否。达到辞退福利确认条件时即确认负债和费用。

</details>

## 5. 利润分配和权益交易

### 1）一句话定位与常见触发场景

本专题连接公司法和会计列报：先判断分配、增减资或融资安排是否合法有效，再判断经济实质属于权益交易、损益交易还是金融负债。常见场景包括弥补亏损、提取公积金、分红、回购、减资、可转债、永续债和优先股。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/profit-distribution-equity-transactions.md)；法律责任重点见[公司法第210条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-210.md)、[第211条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-211.md)、[第214条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-214.md)。

### 2）核心会计判断及对应 CAS

- 利润分配应以依法确定的可供分配利润和有效决议为基础，并遵循弥补亏损、提取法定公积金等法定顺序。
- 与所有者以其所有者身份进行的交易通常直接计入权益，不确认损益；列报入口为[CAS 30](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-30.md)。
- 特殊融资工具从合同义务出发区分金融负债和权益工具：[CAS 37](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-37.md)、[CAS 22](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-22.md)。
- 长期股权投资权益法下被投资单位权益变动连接[CAS 2](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-02.md)。

### 3）主要错报风险与易错点

- 未弥补亏损或未履行法定程序即分配，公积金提取和使用不合规。
- 将所有者身份交易计入损益，或把与所有者身份无关的利益输送隐藏在权益中。
- 回购股份、减资及权益变动列报错误；决议、账务处理和现金支付不一致。
- 仅凭“永续债、优先股”等名称分类，忽略强制付息、赎回和交付现金义务。

### 4）审计程序、关键证据及对应 CSA

- 获取章程、董事会和股东会决议、利润分配方案、权益登记及支付流水：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 将未分配利润、公积金、回购库存股与所有者权益变动表勾稽一致。
- 对异常权益交易关注管理层凌驾、关联安排和利润调节：[CSA 1141](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1141.md)、[CSA 1211](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1211.md)。
- 逐条阅读特殊工具合同，必要时利用估值或法律专家：[CSA 1421](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1421.md)。

### 5）底稿闭环与报告影响

底稿最短闭环：**可分配利润 -> 法定顺序 -> 有效决议 -> 会计分录 -> 资金支付 -> 权益列报披露**。违法或超额分配、以公积金弥补亏损、回购和特殊权益工具应形成法律与会计双重判断；重大错报或披露不足进入报告评价。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先补亏，再提取，后分红；看身份定权益，看义务分股债。”

| 易混项 | 判断抓手 |
|---|---|
| 权益交易 vs 损益交易 | 交易对手是否以所有者身份参与 |
| 金融负债 vs 权益工具 | 发行人是否承担不可避免的现金交付义务 |

1. **判断题：**名称为“永续债”的工具必然列作权益工具。
2. **单选题：**判断一项股东交易是否直接计入权益，首先关注：A.金额大小；B.股东是否以所有者身份交易；C.是否已付款。

<details><summary>答案</summary>

1. 错。分类取决于合同义务。  
2. B。

</details>

## 6. 合并范围与控制判断

### 1）一句话定位与常见触发场景

合并范围判断的核心不是持股比例，而是投资方是否拥有对被投资方的**控制**。高频场景包括低于半数表决权却实际控制、结构化主体、代持、一致行动、委托代理、潜在表决权、控制权取得或丧失。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/consolidation-scope-control.md)；法律责任重点见[公司法第57条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-057.md)、[第110条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-110.md)、[证券法第78条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-078.md)。

### 2）核心会计判断及对应 CAS

- 控制同时具备三要素：对被投资方拥有权力；因参与其活动而享有可变回报；有能力运用权力影响回报金额。入口为[CAS 33 合并财务报表](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-33.md)。
- 权力来自当前能力而非形式权利，须识别相关活动、谁决定相关活动以及权利是否实质性。
- 结构化主体通常不能仅按表决权判断，应看合同安排、风险承担、回报和决策机制。
- 个别报表长期股权投资核算连接[CAS 2](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-02.md)，合并列报连接[CAS 30](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-30.md)。

### 3）主要错报风险与易错点

- 机械使用“持股超过50%”标准，忽略潜在表决权、董事会席位、委托代理或事实控制。
- 为规避合并而设置代持、结构化主体或复杂协议，实际决策与书面安排不一致。
- 合并范围变动时点错误；取得或丧失控制权的会计处理、披露不完整。
- 组成部分资料不完整，合并抵销、内部交易及未实现损益遗漏。

### 4）审计程序、关键证据及对应 CSA

- 获取并交叉核对集团架构图、工商信息、投资协议、章程、股东会和董事会记录、资金往来及实际决策记录。
- 识别合并范围重大错报风险：[CSA 1211](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1211.md)；关注关联方和实际控制人：[CSA 1323](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1323.md)。
- 对组成部分确定重要性、参与其风险评估并复核工作：[CSA 1401 集团审计](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1401.md)。
- 对未纳入主体逐一记录排除理由，对合并调整和抵销分录实施测试。

### 5）底稿闭环与报告影响

底稿最短闭环：**主体清单 -> 相关活动 -> 权力来源 -> 可变回报 -> 影响回报能力 -> 合并结论 -> 抵销及披露**。资料受限可能构成审计范围限制；重大范围错报未调整时，按[CSA 1501](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1501.md)评价意见类型。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“有权力，享回报，能用权力改回报，三项同时才控制。”

| 易混项 | 判断抓手 |
|---|---|
| 控制 vs 重大影响 | 能主导相关活动，还是只能参与财务和经营决策 |
| 委托人 vs 代理人 | 决策者是否主要代表其他方行使权力 |

1. **判断题：**持股不超过50%就一定不能控制被投资单位。
2. **情景题：**投资者只持有40%表决权，但其他股权高度分散，其长期主导董事会和相关活动。是否应直接排除控制？

<details><summary>答案</summary>

1. 错。持股比例只是证据之一。  
2. 不应。须结合其他股东分散程度、历史表决和实际决策等判断事实控制。

</details>

## 7. 长期股权投资

### 1）一句话定位与常见触发场景

长期股权投资专题先判断投资方与被投资方的关系，再确定个别报表核算方法，并处理处置、减值及合并报表衔接。高频场景包括控制、共同控制、重大影响、权益法调整、内部重组和丧失控制权。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/long-term-equity-investments.md)；法律责任重点见[公司法第57条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-057.md)、[第208条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-208.md)、[证券法第85条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-085.md)。

### 2）核心会计判断及对应 CAS

- [CAS 2 长期股权投资](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-02.md)规范对子公司、合营企业和联营企业投资的确认、计量、权益法和处置。
- **共同控制**要求相关活动决策必须经分享控制权的参与方一致同意；**重大影响**是参与决策但不控制或共同控制。
- 对子公司投资在个别报表通常采用成本法；对合营、联营企业投资采用权益法，并调整被投资方净利润和其他权益变动。
- 控制判断和合并报表连接[CAS 33](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-33.md)；减值连接[CAS 8](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-08.md)。

### 3）主要错报风险与易错点

- 控制、共同控制、重大影响判断与章程、协议或实际决策不一致。
- 权益法未调整会计政策差异、资产公允价值影响、内部未实现交易或利润分配。
- 处置或持股比例变化时会计核算切换错误，丧失控制权时点不准确。
- 投资出现持续亏损、经营恶化等迹象却未测试减值。

### 4）审计程序、关键证据及对应 CSA

- 核验投资协议、章程、董事会席位、表决权安排、实际决策记录、工商信息和被投资方报表：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 对控制关系执行集团审计程序：[CSA 1401](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1401.md)；识别特殊关系和安排：[CSA 1323](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1323.md)。
- 重新计算权益法调整，检查其他综合收益、利润分配和内部交易抵销。
- 对减值模型和重大估计运用[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)，必要时利用专家。

### 5）底稿闭环与报告影响

底稿最短闭环：**投资文件 -> 关系判断 -> 核算方法 -> 后续调整 -> 减值 -> 处置及披露**。处置和丧失控制权要同时评价个别报表、合并报表和披露。知识库另有[内部重组确认案例](../../knowledge-base/CPA-ZH/wiki/cases/2026-07-first-issue-long-term-equity-investment-confirmation.md)可用于情景复习。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先定关系再定方法：控制看合并，共同控制看一致，重大影响看参与。”

| 关系 | 决策能力 | 典型个别报表核算 |
|---|---|---|
| 控制 | 主导相关活动 | 成本法，并编制合并报表 |
| 共同控制 | 相关活动须参与方一致同意 | 权益法 |
| 重大影响 | 能参与但不能主导 | 权益法 |

1. **判断题：**持有20%以上表决权就必然具有重大影响。
2. **情景题：**投资方能任命多数董事并主导相关活动，应先判断采用权益法还是先判断是否控制？

<details><summary>答案</summary>

1. 错。比例是推定线索，还要看实质证据。  
2. 先判断是否控制；关系判断决定后续核算路径。

</details>

## 8. 关联方及资金占用

### 1）一句话定位与常见触发场景

本专题要识别谁能控制、共同控制、重大影响企业，或属于关键管理人员及其关系网络，并判断异常往来是否构成非经营性资金占用、违规担保或利益输送。高频信号包括大额无息往来、长期挂账、无商业实质交易、期末归还后期后反向流出。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/related-parties-fund-occupation.md)；法律责任重点见[会计法第3条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-003.md)、[公司法第140条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-140.md)、[证券法第78条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-078.md)。

### 2）核心会计判断及对应 CAS

- [CAS 36 关联方披露](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-36.md)要求识别关联方关系、关联交易、未结算项目及必要披露。
- 关联方判断看控制、共同控制、重大影响、关键管理人员及密切家庭成员等实质关系，不以工商登记或企业自报清单为限。
- 资金占用不是普通会计分类：要结合交易背景、商业实质、资金最终去向、定价、期限和审批判断。
- 合并范围连接[CAS 33](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-33.md)，往来款减值连接[CAS 22](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-22.md)。

### 3）主要错报风险与易错点

- 管理层提供的关联方清单不完整，隐瞒代持、一致行动或关键管理人员关系企业。
- 虚构贸易背景，将资金拆借包装为采购、预付款、工程款或其他应收款。
- 期末临时归还制造余额为零假象，期后快速转出；违规担保或代垫费用未披露。
- 认为交易价格公允就无须披露，或认为纳入合并范围就不再需要识别关联关系。

### 4）审计程序、关键证据及对应 CSA

- 将股权结构、董监高名单、工商信息、会议记录、银行流水、往来明细、合同和担保资料交叉核验。
- 依[CSA 1323 关联方](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1323.md)实施询问、检索和异常交易测试，不能只依赖管理层声明。
- 对往来实施函证并核对银行流水、交易对手和资金最终流向：[CSA 1312](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1312.md)、[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 关注管理层凌驾、非正常重大交易和期后反向资金流：[CSA 1141](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1141.md)。

### 5）底稿闭环与报告影响

底稿最短闭环：**关系网络 -> 交易清单 -> 商业实质 -> 资金流向 -> 审批定价 -> 会计处理 -> 披露及期后检查**。上市公司项目还应将清单与公告、监管问询、年报其他信息和函证结果进行一致性检查；重大遗漏可能影响关键审计事项或审计意见。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“关系看实质，交易看背景，资金看去向，期末看回流，披露看完整。”

| 易混项 | 判断抓手 |
|---|---|
| 关联交易 vs 普通交易 | 双方是否存在控制、共同控制、重大影响或关键管理关系 |
| 资金占用 vs 经营往来 | 是否有真实业务、合理定价期限及与业务匹配的资金流 |

1. **判断题：**关联交易按市场价格进行，就可以不披露关联方关系。
2. **情景题：**控股股东年末归还大额占款，次年初又以“预付款”转出。审计应只看年末余额吗？

<details><summary>答案</summary>

1. 错。公允定价不当然免除关联方披露。  
2. 不应。应追查期后反向流出、交易实质和资金最终去向。

</details>

## 9. 资产减值

### 1）一句话定位与常见触发场景

资产减值关注资产账面价值能否通过使用或出售收回，核心是减值迹象识别、测试单元选择和估计可靠性。范围包括商誉、固定资产、无形资产、在建工程、使用权资产、长期股权投资、存货和金融资产，但三类资产适用的减值模型不同。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/asset-impairment.md)；法律责任重点见[会计法第9条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-009.md)、[证券法第80条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-080.md)、[第197条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-197.md)。

### 2）核心会计判断及对应 CAS

- 长期资产按[CAS 8 资产减值](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-08.md)比较账面价值与可收回金额；可收回金额取公允价值减处置费用后的净额与预计未来现金流量现值两者较高者。
- 不能独立产生现金流入的资产应纳入合理的资产组；商誉需分摊至受益资产组或资产组组合并至少每年测试。
- 存货按[CAS 1 存货](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-01.md)比较成本与可变现净值。
- 金融资产按[CAS 22](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-22.md)采用预期信用损失模型。
- 商誉减值不得转回；其他长期资产满足条件时可转回，但不超过假设未计提减值时的账面价值。

### 3）主要错报风险与易错点

- 忽略停产、闲置、技术淘汰、持续亏损、市值下跌等减值迹象。
- 资产组划分过大，用盈利项目掩盖亏损项目；商誉分摊缺乏一致基础。
- 现金流预测、增长率、折现率或市场数据过度乐观，预测与批准预算不一致。
- 将长期资产、存货和金融资产三套模型混用，或违规转回商誉减值。

### 4）审计程序、关键证据及对应 CSA

- 获取经营数据、预算批准、历史预测偏差、期后销售或回款和外部市场证据。
- 评价模型、数据、假设、管理层偏向和敏感性分析：[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)。
- 必要时使用估值专家并复核折现率、增长率和可比数据：[CSA 1421](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1421.md)。
- 对存货核对库龄、周转和期后售价；对应收款核对账龄、信用风险和期后回款。

### 5）底稿闭环与报告影响

底稿最短闭环：**减值迹象 -> 测试单元 -> 模型 -> 预测现金流或售价 -> 参数及外部证据 -> 敏感性 -> 分录和披露**。商誉和重大估计往往属于高风险领域，可能进入关键审计事项；计提不足、违规转回或证据受限均需评价意见影响。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“长期看可收回，存货看可变现，金融看预期损失；商誉年年测，减了不回头。”

| 模型 | 比较或估计基础 | 典型对象 |
|---|---|---|
| CAS 8 | 账面价值 vs 可收回金额 | 固定资产、无形资产、商誉 |
| CAS 1 | 成本 vs 可变现净值 | 存货 |
| CAS 22 | 概率加权的预期信用损失 | 应收款、债权投资 |

1. **判断题：**商誉没有明显减值迹象时可以不做年度减值测试。
2. **单选题：**长期资产可收回金额是：A.两种估值孰低；B.两种估值孰高；C.账面价值减折旧。

<details><summary>答案</summary>

1. 错。商誉至少每年进行减值测试。  
2. B。

</details>

## 10. 所得税和递延所得税

### 1）一句话定位与常见触发场景

所得税专题把税法计税基础与会计账面价值连接起来，重点判断当期所得税、暂时性差异、递延所得税资产可实现性及不确定税务事项。高频场景包括可抵扣亏损、税收优惠、资产减值、租赁、企业合并和税务稽查。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/income-tax-deferred-tax.md)；法律责任重点见[会计法第13条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-013.md)、[公司法第208条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-208.md)、[证券法第80条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-080.md)。

### 2）核心会计判断及对应 CAS

- **暂时性差异**是资产或负债账面价值与计税基础之间的差额，入口为[CAS 18 所得税](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-18.md)。
- 应纳税暂时性差异通常形成递延所得税负债；可抵扣暂时性差异在未来很可能取得足够应纳税所得额时确认递延所得税资产。
- 可抵扣亏损和税款抵减还要考虑到期期限、适用主体、税法限制和未来盈利来源。
- 递延所得税通常跟随基础交易计入损益、其他综合收益或权益，不能一律计入所得税费用。
- 重大税务争议还需连接[CAS 13](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-13.md)评价负债或披露。

### 3）主要错报风险与易错点

- 将永久性差异错误确认递延所得税；计税基础或适用税率使用错误。
- 对连续亏损企业过度确认递延所得税资产，盈利预测缺少可实现证据。
- 忽略亏损到期、税收优惠条件、不同纳税主体之间不可随意抵销等限制。
- 税务稽查和争议未计提或披露，递延所得税去向与基础交易不一致。

### 4）审计程序、关键证据及对应 CSA

- 将纳税申报表、税务文件、暂时性差异明细、可抵扣亏损到期表和所得税分录勾稽一致：[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 复核递延所得税资产可实现性所依赖的盈利预测、历史准确性和可执行经营计划：[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)。
- 将盈利预测与持续经营评估相互校验：[CSA 1324](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1324.md)。
- 对税务争议获取税务机关文件、外部税务意见和期后进展，并评价披露。

### 5）底稿闭环与报告影响

底稿最短闭环：**账面价值与计税基础 -> 暂时性差异 -> 税率及到期 -> 未来应纳税所得额 -> 递延所得税分录 -> 列报披露**。若未来盈利预测同时支撑持续经营和递延所得税资产，应保证假设一致；重大估计可能形成关键审计事项。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“账税一比较，暂差就出现；负债看应纳，资产看可抵；可抵能否认，未来利润来作证。”

| 易混项 | 判断抓手 |
|---|---|
| 暂时性差异 vs 永久性差异 | 未来期间差异是否会转回 |
| 递延所得税资产确认 vs 仅披露 | 是否很可能取得足够应纳税所得额 |

1. **判断题：**存在可抵扣暂时性差异就必须全额确认递延所得税资产。
2. **情景题：**企业连续亏损但预测下一年巨额盈利，应接受预测并确认全部递延所得税资产吗？

<details><summary>答案</summary>

1. 错。还要满足可实现性条件。  
2. 不应直接接受。需结合历史预测偏差、订单、产能、融资和税法限制取得充分证据。

</details>

## 11. 或有事项和重大诉讼

### 1）一句话定位与常见触发场景

本专题处理过去事项造成但金额或结果不确定的义务和潜在权利，核心是区分预计负债、或有负债、或有资产和仅需披露事项。常见场景包括未决诉讼、担保、产品质保、亏损合同、环境义务、赔偿和重大承诺。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/contingencies-major-litigation.md)；法律责任重点见[会计法第19条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-019.md)、[证券法第85条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-085.md)、[第197条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-197.md)。

### 2）核心会计判断及对应 CAS

- 预计负债确认需同时满足：存在现时义务；履行很可能导致经济利益流出；金额能够可靠计量。入口为[CAS 13 或有事项](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-13.md)。
- 或有负债是潜在义务，或现时义务但流出不是很可能或金额不能可靠计量，通常不确认但需按要求披露。
- 或有资产通常不确认；经济利益流入很可能时披露，基本确定时才确认相关资产。
- 最佳估计数要结合结果区间、单项或多项义务、风险和不确定性，不能简单采用管理层希望值。

### 3）主要错报风险与易错点

- 诉讼、担保或承诺清单不完整，管理层隐瞒现时义务。
- 将“很可能”和“基本确定”混淆，预计负债确认门槛或或有资产确认过于激进。
- 只取得律师函但未评价律师掌握信息的完整性、独立性和法律判断基础。
- 期后判决、和解或赔付信息未用于调整估计和披露。

### 4）审计程序、关键证据及对应 CSA

- 获取诉讼清单、律师函、法院文书、担保合同、董事会记录、管理层评估和期后进展。
- 评价现时义务、流出可能性和金额估计，适用[CSA 1321](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1321.md)和[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)。
- 通过法务费用、银行保证、会议记录、监管公告等反向检索未列报事项。
- 检查期后事项及年报其他信息的一致性，必要时评价报告段落或意见类型。

### 5）底稿闭环与报告影响

底稿最短闭环：**事项清单 -> 过去事项和现时义务 -> 流出概率 -> 金额估计 -> 律师及期后证据 -> 确认或披露 -> 报告影响**。重大诉讼可能进一步造成持续经营不确定性；披露不足或无法获取证据时分别评价错报和范围限制。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“有现时义务、很可能流出、金额能可靠，三关全过才预计；或有资产更谨慎，基本确定才确认。”

| 项目 | 是否确认 | 核心条件 |
|---|---|---|
| 预计负债 | 是 | 现时义务、很可能流出、可靠计量 |
| 或有负债 | 通常否 | 潜在义务，或确认条件未全部满足 |
| 或有资产 | 通常否 | 基本确定流入时转为确认资产 |

1. **判断题：**诉讼败诉概率很可能且金额能可靠估计，但管理层尚未付款，因此不确认负债。
2. **情景题：**企业胜诉获得赔偿的可能性为“很可能”但尚非基本确定，应确认资产还是披露？

<details><summary>答案</summary>

1. 错。付款不是确认前提，满足三项条件即确认预计负债。  
2. 通常披露或有资产，不确认资产。

</details>

## 12. 持续经营与重大不确定性

### 1）一句话定位与常见触发场景

持续经营审计要判断企业在可预见未来能否继续经营、管理层采用持续经营基础是否适当，以及重大不确定性是否充分披露。触发因素包括连续亏损、流动性紧张、债务违约、融资失败、主要业务停滞、重大诉讼和关键客户流失。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/going-concern-uncertainty.md)；法律责任重点见[会计法第20条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/accounting-law/accounting-law-article-020.md)、[公司法第209条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/company-law/company-law-article-209.md)、[证券法第82条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-082.md)。

### 2）核心会计判断及对应 CAS

- 管理层首先负责评价持续经营能力并决定持续经营会计基础是否适当；报表列报和披露入口为[CAS 30](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-30.md)。
- **重大不确定性**是相关事项或情况的潜在影响和发生可能性，使报表使用者对持续经营能力产生重大疑虑。
- 采用持续经营基础不适当与存在重大不确定性是两个问题：前者影响报表编制基础，后者重点评价披露和报告。
- 重大诉讼、担保和承诺连接[CAS 13](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-13.md)。

### 3）主要错报风险与易错点

- 管理层评价期间不足，现金流预测忽略债务到期、违约条款或营运资金需求。
- 融资、资产处置、股东支持等应对计划缺少可执行证据，只停留在意向层面。
- 把“存在重大不确定性”误认为必然发表保留或否定意见。
- 把“持续经营重大不确定性”段落与强调事项段混同，或用关键审计事项替代必要报告。

### 4）审计程序、关键证据及对应 CSA

- 按[CSA 1324 持续经营](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1324.md)评价管理层评估、应对计划和重大不确定性。
- 检查现金流预测、债务到期表、融资协议、违约豁免、订单、经营计划、股东支持能力和期后现金流。
- 将预测与历史实现情况、预算批准、其他会计估计和外部约束交叉验证。
- 按[CSA 1501](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1501.md)、[CSA 1503](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1503.md)确定报告分流，并核对其他信息。

### 5）底稿闭环与报告影响

底稿最短闭环：**风险迹象 -> 管理层评价 -> 现金流及融资证据 -> 应对计划可执行性 -> 重大不确定性结论 -> 披露 -> 报告分流**。持续经营基础不适当通常导致否定意见；基础适当且重大不确定性充分披露时设置专门段落；披露不足则形成非无保留意见。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先看基础对不对，再看疑虑重不重，最后看披露够不够。”

| 情形 | 报告方向 |
|---|---|
| 持续经营基础不适当 | 否定意见 |
| 基础适当、重大不确定性且披露充分 | 无保留意见并设置“与持续经营相关的重大不确定性”段落 |
| 重大不确定性披露不足 | 保留或否定意见，视广泛性而定 |

1. **判断题：**只要存在持续经营重大不确定性，就必须发表非无保留意见。
2. **情景题：**重大不确定性披露充分，注册会计师仍应使用强调事项段代替专门段落吗？

<details><summary>答案</summary>

1. 错。披露充分时通常仍为无保留意见并设置专门段落。  
2. 不应。应使用“与持续经营相关的重大不确定性”专门段落。

</details>

## 13. 关键审计事项

### 1）一句话定位与常见触发场景

关键审计事项（KAM）是从与治理层沟通过的事项中选出的、对本期财务报表审计最为重要的事项。常见候选包括收入、复杂估值、商誉减值、重大并购、合并范围和高风险诉讼，但“重大”不等于自动成为KAM。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/key-audit-matters.md)；法律责任重点见[证券法第78条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-078.md)、[第163条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-163.md)、[第197条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-197.md)。

### 2）核心会计判断及对应 CAS

- KAM本身不是会计处理规则，而是审计报告沟通机制；候选事项仍须回到相关会计准则判断，例如收入[CAS 14](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-14.md)、金融工具[CAS 22](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-22.md)、合并范围[CAS 33](../../knowledge-base/CPA-ZH/wiki/concepts/accounting-standards/cas-33.md)。
- KAM不能替代管理层在财务报表中的披露，不能替代非无保留意见，也不能替代持续经营专门段落。
- 选取时重点考虑特别风险、重大管理层判断、重大交易以及审计工作投入和沟通程度。

### 3）主要错报风险与易错点

- 将年年重复的通用风险模板化列为KAM，未体现本期和本项目特征。
- 报告描述无法追溯到风险评估、具体审计程序、证据和结论。
- 把审计中未解决的证据限制包装为KAM，规避修改审计意见。
- 候选清单、治理层沟通与最终报告之间缺少选择或排除依据。

### 4）审计程序、关键证据及对应 CSA

- 从治理层沟通事项出发形成候选集合：[CSA 1151](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1151.md)。
- 按[CSA 1504](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1504.md)确定最为重要的事项并撰写“为何重要、审计中如何应对”。
- 将描述中的每项应对追溯至具体程序、样本、证据和项目组结论。
- 与年报披露、审计意见、持续经营段落和其他信息保持一致：[CSA 1501](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1501.md)。

### 5）底稿闭环与报告影响

底稿最短闭环：**治理层沟通事项 -> 候选KAM -> 选择和排除理由 -> 风险评估 -> 审计应对和证据 -> 报告文字**。KAM不改变审计意见；若事项导致重大错报未调整或证据不足，应先解决意见类型，不能靠KAM段落收口。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“先沟通，再筛选；最重要，才关键；能追程序和证据，不能替代意见。”

| 易混项 | 判断抓手 |
|---|---|
| KAM vs 管理层披露 | 前者说明审计关注与应对，后者说明企业事项本身 |
| KAM vs 非无保留意见 | 前者不改变意见，后者反映重大错报或证据限制 |

1. **判断题：**无法获取充分适当审计证据时，可以把该事项列为KAM而继续发表无保留意见。
2. **情景题：**某重大事项已与治理层沟通，但审计投入和判断并不显著，是否必然列为KAM？

<details><summary>答案</summary>

1. 错。KAM不能替代恰当的意见类型。  
2. 不必然。还需判断它是否属于本期审计中最为重要的事项。

</details>

## 14. 证券服务责任

### 1）一句话定位与常见触发场景

证券服务责任专题回答注册会计师在IPO、上市公司年报、再融资和重大资产重组中，如何以充分工作和完整留痕证明勤勉尽责。核心风险是审计或鉴证文件存在虚假记载、误导性陈述或重大遗漏，以及注册会计师能否证明没有过错。

追溯：[原专题页](../../knowledge-base/CPA-ZH/wiki/concepts/first-section-topics/securities-service-liability.md)；法律责任重点见[注册会计师法第20条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/cpa-law/cpa-law-article-020.md)、[证券法第160条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-160.md)、[第163条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-163.md)、[第213条](../../knowledge-base/CPA-ZH/wiki/concepts/laws/securities-law/securities-law-article-213.md)。

### 2）核心会计判断及对应 CAS

- 本专题没有单一CAS，需按项目重大事项分别回到收入、金融工具、合并、减值等会计准则。
- 注册会计师法要求依法承办业务、遵守执业准则并拒绝不当报告；证券法强调证券服务机构勤勉尽责。
- “没有发现错报”不等于“已经勤勉尽责”；责任判断关注风险识别、程序设计执行、证据、职业判断和报告是否连贯。
- 证券项目还需关注财务报表与招股书、年报、公告、监管问询回复等其他信息的一致性。

### 3）主要错报风险与易错点

- 对高风险收入、研发投入、资金占用、复杂估值等只执行通用程序，未回应项目特有风险。
- 过度依赖管理层说明、内部材料或单一专家结论，缺少外部或相互印证证据。
- 监管问询回复、公告和财务报表相互矛盾，项目组未识别或未跟进。
- 重大判断缺少项目质量复核、治理层沟通和合伙人最终结论留痕。

### 4）审计程序、关键证据及对应 CSA

- 以重大风险为起点设计并执行程序，证据入口为[CSA 1301](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1301.md)，报告入口为[CSA 1501](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1501.md)。
- 对关键事项和其他信息分别应用[CSA 1504](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1504.md)、[CSA 1521](../../knowledge-base/CPA-ZH/wiki/concepts/audit-standards/csa-1521.md)。
- 对监管问询、公告、业务数据和报表数字建立勾稽关系，对不一致记录追问、追加程序和处理结论。
- 对重大判断保留复核轨迹、分歧解决、治理层沟通和最终批准证据。

### 5）底稿闭环与报告影响

底稿最短闭环：**重大风险 -> 程序 -> 证据 -> 结论 -> 报告和公开披露**。任何一环断裂都会削弱勤勉尽责抗辩。发现重大错报、舞弊或资料限制时，应升级沟通、追加程序并评价退出业务或修改报告，不能以客户声明代替审计证据。

### 6）记忆辅助、易混对比与快速自测

**口诀：**“风险有识别，程序有针对，证据能支撑，结论可复核，报告相一致。”

| 易混项 | 判断抓手 |
|---|---|
| 审计失败 vs 企业经营失败 | 前者看是否违反准则、未尽勤勉义务；后者本身不当然说明审计失败 |
| 管理层声明 vs 审计证据 | 声明是必要补充，不能替代应获取的其他证据 |

1. **判断题：**企业后来经营失败，必然证明注册会计师未勤勉尽责。
2. **情景题：**监管问询回复与审计底稿结论矛盾，项目组应仅保存回复文件还是追查并解决不一致？

<details><summary>答案</summary>

1. 错。应根据当时可得信息、风险应对、证据和执业准则评价。  
2. 必须追查并解决，记录追加程序、沟通和最终结论。

</details>

## 七组易混概念横向辨析

### 1. 控制、共同控制与重大影响

| 概念 | 核心能力 | 判断关键词 | 典型后果 |
|---|---|---|---|
| 控制 | 主导相关活动并影响可变回报 | 权力 + 可变回报 + 运用权力影响回报 | 纳入合并范围 |
| 共同控制 | 相关活动决策须分享控制权各方一致同意 | 合同约定 + 一致同意 | 合营投资通常采用权益法 |
| 重大影响 | 参与财务和经营决策但不能控制 | 董事席位、政策参与、重大交易等 | 联营投资通常采用权益法 |

### 2. 长期资产、存货和金融资产减值

| 对象 | 依据 | 测试核心 | 转回限制 |
|---|---|---|---|
| 长期资产和商誉 | CAS 8 | 可收回金额 | 商誉不得转回；其他资产有限额 |
| 存货 | CAS 1 | 可变现净值 | 影响因素消失时可在原计提范围转回 |
| 金融资产 | CAS 22 | 预期信用损失 | 随信用风险和预期损失变化调整 |

### 3. 预计负债、或有负债与或有资产

| 概念 | 现时或潜在 | 会计处理 |
|---|---|---|
| 预计负债 | 现时义务且很可能流出、可靠计量 | 确认负债和相关损益或资产成本 |
| 或有负债 | 潜在义务，或确认条件不全的现时义务 | 通常不确认，按要求披露 |
| 或有资产 | 可能带来经济利益流入 | 通常不确认；很可能时披露，基本确定时确认 |

### 4. KAM、持续经营专门段、强调事项段与非无保留意见

| 报告项目 | 使用条件 | 是否改变意见 |
|---|---|---|
| 关键审计事项 | 本期审计中最为重要的事项 | 否 |
| 持续经营重大不确定性段 | 基础适当、存在重大不确定性且披露充分 | 否 |
| 强调事项段 | 已在报表恰当列报或披露、对理解报表极其重要 | 否 |
| 非无保留意见 | 存在重大错报或无法获取充分适当证据 | 是 |

### 5. 政府补助与客户合同收入

| 维度 | 政府补助 | 客户合同收入 |
|---|---|---|
| 交易性质 | 政府无偿给予资源 | 向客户转让商品或服务换取对价 |
| 关键条件 | 能满足附带条件且能够收到 | 合同成立并按履约义务转移控制权 |
| 主要准则 | CAS 16 | CAS 14 |

### 6. 金融负债与权益工具

| 维度 | 金融负债 | 权益工具 |
|---|---|---|
| 核心义务 | 通常存在交付现金或其他金融资产的合同义务 | 证明扣除全部负债后的剩余权益 |
| 判断重点 | 发行方能否无条件避免现金交付 | 合同条款而非工具名称 |
| 后续影响 | 利息通常进入损益 | 分配通常作为权益分配 |

### 7. 关联交易、资金占用与普通经营往来

| 类型 | 关系或交易特征 | 审计重点 |
|---|---|---|
| 关联交易 | 交易双方存在准则定义的关联关系 | 关系完整性、交易真实性、定价与披露 |
| 资金占用 | 缺少商业实质或资金实质流向关联方 | 资金最终去向、期后回流、审批和监管披露 |
| 普通经营往来 | 有真实业务、合理条款并与资金流匹配 | 发生、完整性、截止和减值 |

## 总复习：一张表走完判断链

| 步骤 | 必答问题 | 常见底稿 |
|---|---|---|
| 1. 法律责任 | 谁负责编报、提供资料和公开披露？ | 法律条款索引、治理与沟通记录 |
| 2. 会计处理 | 交易或事项是什么，何时确认，如何计量列报？ | 会计判断备忘、分录和披露核对表 |
| 3. 审计应对 | 哪个认定可能错，程序是否针对风险？ | 风险与程序对应表、测试底稿 |
| 4. 底稿证据 | 证据是否充分适当，能否反向追溯结论？ | 合同、外部证据、复核轨迹和结论 |
| 5. 报告影响 | 错报、证据限制或重大事项如何进入报告？ | 错报汇总、意见判断、KAM及其他段落备忘 |

**30秒口述模板：**“该事项的实质是___；适用___准则；主要风险是___；我们取得___证据并执行___程序；结论为___；对报表披露和审计报告的影响是___。”

## 术语表

| 术语 | 速记定义 |
|---|---|
| 履约义务 | 合同中向客户转让可明确区分商品或服务的承诺 |
| 控制权转移 | 客户取得主导资产使用并获得其几乎全部经济利益的能力 |
| SPPI | 合同现金流量是否仅为本金及以未偿付本金为基础的利息 |
| 预期信用损失（ECL） | 对金融工具整个存续期或未来12个月信用损失的概率加权估计 |
| 控制 | 对被投资方有权力、享有可变回报且能运用权力影响回报 |
| 共同控制 | 相关活动决策必须经分享控制权的参与方一致同意 |
| 重大影响 | 对财务和经营政策有参与决策权，但不控制或共同控制 |
| 资产组 | 能独立产生现金流入的最小资产组合 |
| 可收回金额 | 公允价值减处置费用后的净额与预计未来现金流量现值孰高 |
| 暂时性差异 | 资产或负债账面价值与计税基础之间、未来会转回的差额 |
| 预计负债 | 因现时义务且很可能流出、金额可可靠计量而确认的负债 |
| 或有负债 | 潜在义务，或未满足全部确认条件的现时义务 |
| 重大不确定性 | 可能使报表使用者对持续经营能力产生重大疑虑的事项或情况 |
| 关键审计事项（KAM） | 从治理层沟通事项中选出的、本期审计中最为重要的事项 |
| 充分适当审计证据 | “充分”指数量，“适当”指相关性和可靠性 |
