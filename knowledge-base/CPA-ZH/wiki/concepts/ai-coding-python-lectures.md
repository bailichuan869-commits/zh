## CPA-ZH 落地点

| 主题 | 可落地用途 |
|---|---|
| PDF 工具链 | 合并、拆分、解析底稿附件，形成 Markdown 或索引 |
| Excel 自动化 | 读取底稿、复核公式、批量生成分析表、导出异常清单 |
| Word 自动化 | 批量处理报告、说明、复核意见和格式统一 |
| API 与数据源 | 汇率、A 股报表数据、外部信息核验 |
| Web/桌面应用 | 将临时脚本沉淀为团队可用的小工具 |
| Agent 工具设计 | 为 CPAHelper、Excel Agent 和知识库维护 Agent 定义工具边界 |
