# 独立性准则第1号——财务报表审计和审阅业务对独立性的要求

## 定义

该准则是职业道德守则的专项延伸，针对财务报表审计和审阅业务，对独立性提出具体可操作要求，涵盖网络、关联实体、合伙人轮换、非鉴证业务等。

## 说明

职业道德守则确立独立性原则，独立性准则第1号把它落地到具体场景。它把“独立”从口号变成清单——哪些利益必须处置、哪些关系必须回避、哪些服务不能同时提供、合伙人多久必须轮换。

## 核心原则

1. **实质与形式并重**：精神独立与第三方合理认知都需满足。
2. **覆盖审计客户关联实体**：独立性要求延伸至审计客户的母公司、子公司等。
3. **防范措施具体化**：通过轮换、分隔、禁止等机制降低威胁。
4. **持续全期间**：独立性要求覆盖业务承接、执行和报告全过程。

## 结构与步骤

| 模块 | 说明 | 要点 |
|------|------|------|
| 独立性框架 | 实质独立、形式独立、威胁与防范 | 总体要求 |
| 网络与关联实体 | 网络所、关联实体范围 | 独立性延伸 |
| 经济利益 | 持有客户股票、贷款、担保 | 直接或间接利益均受限 |
| 商业关系 | 与客户的联合促销、担保等 | 不得产生不当影响 |
| 家庭和个人关系 | 亲属在客户任职 | 评估密切关系威胁 |
| 非鉴证业务 | 同时提供内控设计、代账、估值等 | 部分服务产生自我评价威胁 |
| 合伙人轮换 | 项目合伙人、签字注册会计师轮换年限 | 防止长期关系威胁 |
| 薪酬与业绩评价 | 不得以非鉴证业务收入评价审计团队 | 防范自身利益 |

## 常见考点

- 独立性要求覆盖审计期间和出具报告日，且向前追溯涵盖审计涵盖的财务报表期间。
- 持有审计客户股票（包括间接通过基金等）构成自身利益威胁，应处置。
- 项目合伙人和签字注册会计师有轮换年限要求，防止长期关系威胁。
- 不得同时为审计客户提供代账、内控设计、估值等产生自我评价威胁的服务。
- 关联实体（母公司、子公司）的独立性要求与审计客户一致。
- 对公众利益实体的审计客户，独立性要求更严格。

## 易混点

- “审计期间”与“涵盖期间”：独立性要求覆盖涵盖期间（报表涵盖的财务期间）及之后。
- “网络所”不等于“分所”：网络所是共享质量控制、品牌等的多个事务所，独立性要求传导。
- “非鉴证业务”全面禁止还是部分禁止：取决于是否产生自我评价或倡导威胁，需逐项判断。

## 典型场景

### 场景 1：审计团队配偶在客户财务部任职
抓手：密切关系威胁 → 评估是否可降至可接受水平，通常应回避。

### 场景 2：事务所同时为审计客户提供内控设计
抓手：自我评价威胁 → 通常不得同时提供，或应退出审计业务。

### 场景 3：合伙人连续签字超过轮换年限
抓手：长期关系威胁 → 应按规定轮换。
