# qa-151

答：按照《企业会计准则第8号——资产减值》

**第五条** 等有关规定，资产的市价当期大幅度下跌，其跌幅明显高于因时间的推移或者正常使用而预计的下跌时，表明资产存在减值迹象。因此，本问题中，被投资单位乙公司股价在2×22年出现明显下跌且在2×22年末远低于乙公司净资产的账面价值，表明甲公司对乙公司的该项长期股权投资存在减值迹象。按照《企业会计准则第8号——资产减值》

## 第三章 等有关规定，甲公司应当对该项长期股权投资估计可收回金额，可收回金额应当根据该项长期股权投资的公允价值减去处置费用后的净额与该项长期股权投资预计未来现金流量的现值两者之间较高者确定，而不应直接采用乙公司股价计算得出。
