# VBA第18课：加载项实战 6：一键格式

## 这一节要做什么

这一节进入“格式与打印”分组，做一个比较综合的功能：

```text
一键格式
```

它不是单纯点一下按钮就结束，而是分成两个部分：

```text
一键格式配置
一键格式执行
```

先在配置窗体里设置字体、字号、边框、标题行、合计行等规则，再对选中的区域一键应用格式。

## 本节你会学到

- 为什么一键格式需要“配置 + 执行”两个入口。
- 加载项里的配置可以保存在哪里。
- 为什么可以用隐藏工作表保存配置。
- 怎么让 AI 创建一键格式配置窗体。
- 怎么手工调整 VBA 窗体布局。
- 手工改窗体后，为什么要同步 `form.json`。
- 怎么测试一键格式是否真的读取了配置。

## 一键格式要做什么

常见的一键格式可以包括：

- 通用字体；
- 通用字号；
- 是否启用千分位分隔符；
- 边框设置；
- 标题行字体；
- 标题行字号；
- 标题行字体颜色；
- 标题行填充颜色；
- 标题行是否加粗；
- 合计行是否加粗；
- 合计行是否应用双下划线。

本节不追求把所有格式都做到极致，先做出一套能用的格式配置工具。

## 添加两个按钮

在“格式与打印”分组里添加两个按钮：

```text
一键格式配置
一键格式
```

`一键格式配置` 的功能说明：

```text
点击按钮后弹出设置窗体，用于设置一键格式的配置。
配置包括字体、字号、字体颜色、是否启用千分位分隔符、边框设置、标题行格式、合计行格式等。
```

`一键格式` 的功能说明：

```text
将当前选中的单元格区域按照已保存的配置进行格式设置。
```

后面第 19 节会把这两个按钮合并成拆分按钮，这节先分开做清楚。

## 如果导出失败，检查 VBA 密码

如果之前给 `final.xlsm` 设置过 VBA 工程密码，导出设计可能失败。

原因是：

> AI 或设计器需要写入模块和回调，工程被锁住后就写不进去。

处理方法：

1. 打开 VBA 工程属性。
2. 取消查看锁定或输入密码解锁。
3. 保存。
4. 再重新导出设计。

开发阶段不建议一直锁工程。

## 配置保存在哪里

Python 篇里，我们常把配置保存到 JSON 文件。

但加载项是一个单文件工具。

如果额外再带一个 JSON 文件，发布和安装都会麻烦。

更适合的方式是：

```text
把配置保存在加载项工作簿里的隐藏工作表中。
```

加载项本质上也是一个 Excel 工作簿，只是用户平时看不到它。

所以可以在加载项内部建一张隐藏配置表：

| A列 | B列 |
| --- | --- |
| FontName | 微软雅黑 |
| FontSize | 10 |
| UseThousands | True |

这和 JSON 的 key-value 思路类似。

优点是：

- 跟着加载项一起迁移；
- 不需要额外配置文件；
- 用户看不到；
- AI 读写也比较方便。

## 让 AI 实现一键格式配置

导出设计后，在 AI 终端中说：

```text
实现功能：一键格式配置。
先用 plan 模式。
```

AI 的计划里应该包括：

- 创建隐藏配置表；
- 用 key-value 保存配置；
- 创建 `UserForm` 配置窗体；
- 窗体中包含字体、字号、千分位、边框、标题行、合计行等设置；
- 点击保存后写入配置表；
- 恢复默认和取消按钮。

确认后让 AI 执行。

## 手工调整窗体布局

AI 生成的窗体通常能用，但不一定好看。

可以按：

```text
Alt + F11
```

打开 VBA 编辑器，找到窗体，手工调整布局。

建议用分组框把配置分开：

```text
通用字体设置
边框设置
标题行设置
合计行设置
```

调整重点：

- 控件左对齐；
- 输入框宽度统一；
- 按钮大小统一；
- 分组标题清楚；
- 不要让控件挤在一起。

VBA 窗体不用追求现代 UI，清楚、能用就好。

## 手工改窗体后，要同步 form.json

这是一个很重要的坑。

AI 生成窗体时，项目里可能会有窗体结构描述文件，例如：

```text
form.json
```

如果你在 VBA 编辑器里手工调整了窗体布局，但没有告诉 AI，同步文件还是旧布局。

以后你再让 AI 修改窗体，它可能基于旧布局重新生成，把你手工调整的布局覆盖掉。

所以手工改完窗体后，要告诉 AI：

```text
我已经手工调整了窗体结构。
请把 form.json 同步成我最新设计的结构。
```

这样后续 AI 再改窗体时，才会基于你的最新版布局。

## 实现一键格式按钮

配置窗体完成后，再让 AI 实现：

```text
一键格式
```

可以说：

```text
现在开始实现一键格式按钮。
它需要读取一键格式配置，并将配置应用到当前选中区域。
```

它应该做：

- 读取隐藏配置表；
- 获取当前选区；
- 设置普通区域字体字号；
- 设置千分位格式；
- 设置边框；
- 设置标题行格式；
- 识别合计行并设置加粗、双下划线等格式。

## 测试一键格式

准备一个测试区域：

- 第一行作为表头；
- 中间几行放数据；
- 底部一行写合计；
- 数字列写一些大额数字。

先打开“一键格式配置”，设置：

- 字体；
- 字号；
- 是否启用千分位；
- 标题行字体；
- 标题行是否加粗；
- 合计行是否加粗；
- 合计行是否双下划线。

保存配置后，选中测试区域，点击：

```text
一键格式
```

检查：

- 字体字号是否变化；
- 数字是否启用千分位；
- 标题行格式是否生效；
- 合计行是否加粗；
- 合计行是否有双下划线。

## 颜色输入可以后续优化

如果窗体里让用户直接输入颜色整数，这对普通用户不友好。

后续可以让 AI 优化为：

```text
点击按钮选择颜色
```

或者提供预设颜色：

```text
浅蓝
浅灰
浅黄
无填充
```

这类细节可以后续继续迭代。

## 本节记住这五点

1. 一键格式适合拆成“配置”和“执行”两个动作。
2. 加载项配置可以保存在隐藏工作表中。
3. VBA 窗体生成后可以手工调整，不必完全依赖 AI。
4. 手工改窗体后，要让 AI 同步 `form.json`。
5. 先让功能跑通，再慢慢优化颜色、布局和细节。

## 课后练习

给一键格式配置增加一个选项：

```text
自动调整列宽
```

完成标准：

1. 在配置窗体中增加复选框。
2. 同步窗体结构描述。
3. 保存配置到隐藏配置表。
4. 一键格式执行时读取该配置。
5. 勾选后自动调整选区列宽。
