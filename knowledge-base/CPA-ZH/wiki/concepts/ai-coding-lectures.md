# AI 编程与自动化

## 定位

本页维护从 `D:\ai-coding\讲义` 导入的 AI 编程与自动化课程讲义。该板块服务于 CPA-ZH 的工具化能力建设：把 Agent 使用、Python 自动化、Excel/VBA 插件开发等内容沉淀为可检索、可复用的学习入口。

本板块不替代法规准则判断，而是回答另一个问题：如何把审计、财务和知识库工作中的重复劳动，逐步转化为脚本、工具、插件和 Agent 工作流。

## 使用建议

1. 想理解“怎么让 Agent 帮我干活”，先看 [[concepts/ai-coding-agent-lectures]]。
2. 想把重复操作做成脚本或工具，先看 [[concepts/ai-coding-python-lectures]]。
3. 想把 Excel 常用动作做成加载项按钮，先看 [[concepts/ai-coding-vba-addin-lectures]]。
4. 做审计实务工具时，应同时回到 [[concepts/intelligent-tools]]，补充数据输入、控制点、人工复核和审计证据留痕。

## 后续维护

1. 将每一课进一步提炼为“适用场景、关键概念、可复用模板、适合审计工作的落地点”。
2. 优先推进 [[concepts/ai-coding-project-roadmap]] 中的 P1 项目：CPA-ZH 入库助手、案例卡片生成助手、PDF 原文归档工具。
3. 每个工具落地前先用 [[concepts/ai-coding-risk-control-checklist]] 检查输入、输出、日志、复核和禁止边界。
4. 把已落地的自动化工具登记到 [[concepts/ai-coding-tool-registry]]，并回挂到 [[concepts/intelligent-tools]] 和具体审计流程页面。
